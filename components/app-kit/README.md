# @coopenomics/app-kit

Набор издателя приложений каталога Цифрового Кооператива. Две команды: каркас
приложения и выпуск в каталог.

```bash
npx @coopenomics/app-kit create @<кооператив>/<имя> "Заголовок" --catalog <адрес каталога>
cd <имя>
npx @coopenomics/app-kit publish
```

Команды с подставленными именем пакета и адресом каталога показывает стол
разработчика кооператива, страница «Выпуск из терминала».

## Что требуется

Node.js 18+, npm, bash, curl и запущенный Docker. На Windows команды
выполняются в WSL.

## Путь приложения

1. Стол разработчика → «Мои пакеты» → «Зарегистрировать пакет»: имя пакета и
   цена в месяц.
2. Стол разработчика → «Ключи API» → «Выпустить ключ»: ключ на этот пакет либо
   на все ваши пакеты.
3. `create` — каркас приложения в папке `<имя>`: манифест `package.json`,
   страница фронта `frontend/frame.html` и бэкенд `backend/` с Dockerfile.
4. `publish` — образ бэкенда, пакет и выпуск. При первом запуске команда
   спрашивает ключ API и сохраняет его в файле `.catalog-key` папки
   приложения.
5. Первый выпуск одобряет модератор каталога. Обновление без новых прав ядра
   каталог активирует сам.

## Переменные

| Переменная | Назначение |
| --- | --- |
| `CATALOG_URL` | адрес каталога вместо поля `catalog.url` манифеста |
| `CATALOG_PUBLISHER_TOKEN` | ключ API вместо файла `.catalog-key` (сервер сборки) |
| `RELEASE_BRIEF` | текст для модератора; без переменной — заголовок последнего коммита |

Права ядра приложение перечисляет в манифесте: `coopenomics.ports` — порты
ядра, `coopenomics.chainActions` — действия цепи. Обновление с новыми правами
ждёт согласия председателя кооператива-подписчика.

## Запуск из чекаута mono

До выпуска в npm набор работает прямо из чекаута mono. Команда `create` из
чекаута кладёт в каркас SDK приложений этого же чекаута (`backend/vendor`):
в npm такая версия SDK ещё не вышла. Переменная `APP_KIT_SDK=npm` отключает
это.

```bash
cd <чекаут mono>/components/app-kit
npm link                       # команда app-kit во всех папках
mkdir -p ~/node_modules/@coopenomics
ln -sfn "$PWD" ~/node_modules/@coopenomics/app-kit   # npx @coopenomics/app-kit вне проектов
```

Правка набора в чекауте действует сразу, пересборка не требуется. Перед
`create` соберите SDK приложений в чекауте: `pnpm -F @coopenomics/extension-sdk
run build` и `pnpm -F @coopenomics/innercoop run build`.
