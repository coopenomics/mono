# Стол заказов

Сервис коллективных закупок для пайщиков кооператива. Пайщики заказывают товары и услуги у поставщиков, кооператив принимает поставку на своём участке (пункте выдачи) и выдаёт имущество пайщикам.

- Каталог товаров и услуг с категориями, карточками и поиском.
- Коллективные заказы пайщиков одного кооперативного участка.
- Приёмка поставки на склад пункта выдачи.
- Выдача имущества пайщику по акту приёма-передачи.
- Возвраты и претензии по качеству.
- Списание товара по окончании срока годности.
- Экономика участка: членский взнос с заказов и его распределение между доверенными лицами участка.
