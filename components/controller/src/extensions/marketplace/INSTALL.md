# Установка Marketplace

Для установки не требуется ничего специального: таблицы расширения создают
его миграции при подключении к базе (`marketplace.database-migrations.ts`).

## Таблицы коэффициента экономического участия (задача 99D-22)

Миграция `1793520000000-keu-period` добавляет:

- в `marketplace_secure_due` колонки `base_amount` (стоимость заказа по
  `o.mkt.consum`) и `returned_amount` (возвращено пайщику по `o.mkt.retdue`);
- `marketplace_branch_period` — зеркало строки итога месяца участка из цепи
  (`marketplace::kuperiods`): факты, части членского взноса и экономии, ставки,
  число строк прогона и списанных строк, отметка стирания из цепи;
- `marketplace_branch_aid` — зеркало заявлений на материальную помощь по
  действиям контракта branch (подано, одобрено, выплачено, отклонено) для
  подсчёта выплаченного за месяц и занятого предела.

Зеркала заполняются слушателями действий цепи; на узле, подключённом к
кооперативу с историей, заявления до установки в зеркало не попадают — предел
месяца начинает считаться с момента установки.

## Настройки после установки

- Ставка обеспечительной части и доля инициатора в экономии — на столе
  администратора (`marketplaceSetInitiatorShare`, по умолчанию 61,8 %).
- Потолок строки резерва социально-экономического обеспечения —
  `marketplaceSetAidLimit`; при нуле предел материальной помощи не действует.
- Фонды накопления должны быть заведены в контракте fund (три стандартных —
  при старте кооператива), иначе отчислений в фонды по итогу месяца нет.
