# Образовательный мост (edubridge)

Приложение соединяет кооператив с образовательными площадками (Skillspace, GetCourse и другие).

- Каталог курсов открыт посетителю до вступления.
- Вступление — по оферте родителя-слушателя или преподавателя; ЦПП «Образование» обязательна для слушателей.
- Членский взнос — конвертацией паевого взноса из главного кошелька по заявлению; прямого платежа как членского взноса нет.
- Доступ на площадке выдаётся и отзывается автоматически по границе оплаченного периода.
- Преподаватель участвует в хозяйственной деятельности: договор УХД, взнос результатами работы (РИД), решение совета, возврат.
