# Образовательный мост

Приложение подключает к кооперативу онлайн-школы на площадках Skillspace и GetCourse. Обучение идёт по целевой потребительской программе «Образование».

- Администратор школы заводит курсы, группы и расписание занятий. Каталог курсов открыт посетителю сайта до вступления в кооператив.
- Пайщик подписывается на курс и вносит членский взнос из своего паевого взноса. Доступ к курсу на площадке кооператив выдаёт и отзывает сам по сроку оплаты.
- Преподаватель заключает с кооперативом договор участия в хозяйственной деятельности. После занятия он отчитывается, и материалы занятия поступают в кооператив его паевым взносом.
- Совет принимает решение по каждому взносу преподавателя. Паевой взнос преподаватель получает обратно деньгами по заявлению.
- Председатель видит на столе администратора курсы, учеников, взносы преподавателей и деньги программы.
