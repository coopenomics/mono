# Установка

1. Установите приложение из каталога. Совет принимает положение ЦПП «Образование» и шаблоны оферт — до этого столы пайщикам не показываются, председателю доступна только настройка.
2. В настройках укажите ключи площадок (Skillspace, GetCourse). Ключи — секреты: видны и изменяемы только председателем.
3. Задайте срок предупреждения об окончании доступа (по умолчанию 3 дня).
4. Если установлен «Благорост», опция «Связать с Благоростом» оставляет его столы только преподавателям и скрывает его оферты при вступлении.

## Школа GetCourse

1. В поле «Аккаунт GetCourse» введите имя аккаунта (`school` для `school.getcourse.ru`) либо домен школы. API-ключ создаётся в школе: «Настройки аккаунта» → «API».
2. Нажмите проверку подключения. Ответ называет число групп школы; неверный ключ даёт отказ школы.
3. Курс привязывается к группе школы: в форме курса группа выбирается из списка. Привязка — название группы, поэтому группу после привязки не переименовывают.
4. Доступ к тренингу открывает школа: в настройках тренинга укажите, что доступ имеют участники этой группы.
5. Выдача доступа добавляет ученика в группу по его почте. Новый для школы ученик расходует месячный лимит тарифа на создание пользователей.
6. Отзыв доступа добавляет ученика в группу-сигнал с названием `<название группы>:revoked`. Сама группа доступа при этом не меняется. Чтобы доступ снимался, заведите в школе процесс: по входу в группу-сигнал он исключает ученика из группы доступа. Без процесса ученик остаётся в группе доступа, и доступ снимается вручную.
7. Узел читает из школы только список групп и добавляет учеников в группы. Пользователей и группы школы он не удаляет и состав чужих групп не меняет.
