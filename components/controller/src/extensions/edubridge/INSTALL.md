# Установка

1. Установите приложение из каталога. Совет принимает положение ЦПП «Образование» и шаблоны оферт — до этого столы пайщикам не показываются, председателю доступна только настройка.
2. В настройках укажите ключи площадок (Skillspace, GetCourse). Ключи — секреты: видны и изменяемы только председателем.
3. Задайте срок предупреждения об окончании доступа (по умолчанию 3 дня).
4. Если установлен «Благорост», опция «Связать с Благоростом» оставляет его столы только преподавателям и скрывает его оферты при вступлении.
