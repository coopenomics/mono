# Приём платежей на расчётный счёт в Сбере — документация разработчика

Приложение принимает паевые взносы, которые пайщики переводят на расчётный счёт кооператива в Сбере. Оно регулярно проверяет поступления на счёт, находит оплаты пайщиков и засчитывает их автоматически.

Текст страницы в каталоге приложений — `CATALOG.md`: его читают председатель и совет, технических подробностей в нём нет. Этот файл — для разработчика.

## Запись реестра

Запись — в `components/controller/src/extensions/extensions.registry.ts`. Что значит каждое поле — корневой `components/controller/CLAUDE.md`, раздел «Что расширение объявляет о себе».

### `sberpoll` — Приём платежей на расчётный счёт в Сбере

- Доступность в сети: закрыто для установки во всех сетях.
- Ставится новому кооперативу сразу, выключенным (`defaults` в записи реестра).
- Модуль: `SberpollExtensionModule` — `sberpoll/sberpoll-extension.module.ts`.
- Своего рабочего стола нет: расширение работает на сервере и в чужих экранах.
- Настроек нет: схема пустая.
- Миграции схемы базы: 0; миграции настроек: 0.
- Обязательные порты: `Logger`, `MessageChannel`, `Organization`, `PaymentMethod`, `PaymentPollingState`, `Payment`.

## Где что лежит

- Сервер: `components/controller/src/extensions/sberpoll/`. Подкаталоги: `i18n/`.
- Файлы верхнего уровня: `sberpoll-extension.module.ts`, `sberpoll.ports.ts`.
- Порты и их владельцы — `components/innercoop/PORTS.md`.
