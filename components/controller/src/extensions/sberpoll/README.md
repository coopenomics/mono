Приложение автоматически принимает паевые взносы на расчётный счёт кооператива в Сбербанке.

В окне оплаты пайщик получает реквизиты счёта и назначение платежа с номером своего взноса. Он переводит деньги из любого банка и указывает назначение платежа в точности.

Приложение регулярно читает выписку по счёту кооператива. По номеру в назначении платежа оно находит взнос пайщика, сверяет сумму и зачисляет взнос автоматически, без участия кассира.

Приложение работает без комиссии, условия перевода задаёт банк пайщика.
