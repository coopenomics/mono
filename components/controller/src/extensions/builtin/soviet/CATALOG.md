# Стол Совета

Рабочий стол членов совета кооператива. На нём совет рассматривает вопросы повестки, ведёт реестры кооператива и проводит общие собрания пайщиков.

- Повестка совета содержит вопросы, по которым голосуют члены совета. Решение совета оформляется протоколом.
- Реестр пайщиков показывает пайщиков кооператива и сведения о каждом из них.
- Реестр документов хранит документы кооператива с подписями и доверенности. В разделе «Шаблоны документов» совет утверждает редакции документов, по которым работает кооператив.
- Реестр расходов показывает расходы кооператива по служебным запискам, реестр контрагентов — получателей этих средств.
- Реестр собраний ведёт общие собрания пайщиков.

Председатель настраивает кооператив и его приложения на Столе Председателя.
