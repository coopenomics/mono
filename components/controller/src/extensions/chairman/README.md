Стол председателя — рабочее место председателя совета кооператива.

Председатель рассматривает запросы одобрений и подписывает документы, которые приложения направляют ему после решений совета. Здесь он ведёт состав совета, кооперативные участки, контакты и ключ кооператива, размеры регистрационных взносов и способ приёма платежей.

В каталоге приложений председатель устанавливает и настраивает приложения кооператива и выбирает стартовые страницы рабочих столов.

Вопросы повестки с истёкшим сроком рассмотрения приложение снимает автоматически. Частота проверки повестки задаётся в настройках.
