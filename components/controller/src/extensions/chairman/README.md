# Стол Председателя

Рабочий стол председателя кооператива. На нём председатель готовит кооператив к работе на платформе, настраивает приложения и доступ пайщиков.

- Онбординг ведёт кооператив по первым решениям совета: совет утверждает положения о цифровых сервисах и документы, по которым пайщики вступают в кооператив. Пайщиков, которые вступили до подключения к платформе, председатель загружает списком.
- Запросы одобрений собирают документы, которые приложения кооператива направляют председателю на предварительное одобрение перед советом.
- Пресеты предложений готовят документы для вопросов повестки совета, например утверждение положения о целевой программе.
- Каталог приложений устанавливает, настраивает, включает и выключает приложения кооператива.
- Управление доступом задаёт права пайщиков на рабочих столах.
- Параметры кооператива, члены совета, кооперативные участки, регистрационные взносы, стартовые страницы, ключ кооператива и провайдер платежей настраиваются в отдельных разделах.
- Журнал уведомлений показывает сообщения, которые кооператив направил пайщикам.

Вопросы, по которым совет не принял решение в срок, Стол Председателя снимает с повестки и уведомляет об этом.
