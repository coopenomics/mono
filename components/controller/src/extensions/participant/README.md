Стол пайщика — личный кабинет каждого пайщика кооператива.

Пайщик видит свой кошелёк и платежи, совершает паевые взносы и возвращает их, хранит реквизиты для выплат. В разделе документов собраны заявления и соглашения пайщика с его подписью. Здесь же находятся удостоверение пайщика, карта кооператора, контакты кооператива и обращение в поддержку.

Пайщик участвует в общих собраниях со своего стола. Приложение сообщает ему о собрании письмами на электронную почту. Письма приходят при объявлении собрания, за три дня до начала, в момент начала, за день до завершения и после завершения.

В настройках задаются частота проверки новых собраний, тема писем и адрес сайта кооператива для ссылок в письмах.
