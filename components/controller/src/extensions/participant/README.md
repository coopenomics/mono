Приложение следит за общими собраниями кооператива и рассылает пайщикам уведомления на электронную почту.

Пайщик получает письмо при объявлении собрания, за три дня до начала, в момент начала, за день до завершения и после завершения.

В настройках задаются частота проверки новых собраний, тема писем и адрес сайта кооператива для ссылок в письмах.
