# Поздравления

Приложение поздравляет пайщиков кооператива с днём рождения письмом от имени кооператива.

- Председатель пишет шаблон поздравления на год или на месяц: тему и текст письма с переменными — фамилией, именем, отчеством, возрастом, названием кооператива.
- Предпросмотр показывает письмо на конкретном пайщике до включения шаблона.
- Каждый день в час отправки приложение направляет письма именинникам дня — физическим лицам и индивидуальным предпринимателям.
- Журнал показывает, кому и с каким шаблоном направлено поздравление, а календарь — дни рождения пайщиков по месяцам.

Шаблоны и журнал видят председатель и члены совета; шаблоны пишет и включает председатель.
