# Информационные рассылки

Приложение направляет пайщикам письма от имени кооператива по шаблонам председателя.

- Поздравление с днём рождения: в день рождения пайщика — физического лица или индивидуального предпринимателя — приложение направляет ему письмо по шаблону на год или на месяц.
- Информационная рассылка: в назначенную дату письмо получают все действующие пайщики, в том числе организации. Праздничная рассылка повторяется каждый год. Рекламу приложение не рассылает.
- Шаблон пишется в редакторе с переменными: фамилия, имя, отчество, обращение, название кооператива, председатель; у поздравления — ещё возраст.
- Предпросмотр показывает письмо на конкретном пайщике, пробное письмо приложение направляет председателю на почту.
- Журнал показывает каждое отправленное письмо, календарь — дни рождения пайщиков по месяцам.

Приложение видит и ведёт только председатель кооператива.
