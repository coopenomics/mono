# Рассылки

## 1.1.0

- Информационные рассылки всем действующим пайщикам в дату, с повтором каждый год для праздников.
- Пробное письмо председателю из редактора шаблона.
- Переменная «Кооператив» подставляет сокращение и название: «ПК «Восход»».
- Приложение видит только председатель.

## 1.0.0

- Шаблоны поздравлений председателя с периодом действия, переменными и предпросмотром на пайщике.
- Календарь дней рождения физических лиц и индивидуальных предпринимателей.
- Ежедневная рассылка писем через центр уведомлений и журнал поздравлений.
