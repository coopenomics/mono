# Установка приложения «Поздравления»

1. Установите приложение из каталога. Календарь дней рождения заполнится в течение нескольких минут после установки.
2. Укажите час отправки поздравлений по времени кооператива (по умолчанию 9 часов).
3. На рабочем столе «Поздравления» создайте шаблон на текущий год, проверьте письмо в предпросмотре и включите шаблон.
