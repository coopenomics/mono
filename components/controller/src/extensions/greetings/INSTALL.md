# Установка приложения «Информационные рассылки»

1. Установите приложение из каталога. Календарь дней рождения заполнится в течение нескольких минут после установки.
2. Укажите час отправки писем по времени кооператива (по умолчанию 9 часов).
3. На рабочем столе «Информационные рассылки» создайте шаблон поздравления на текущий год либо рассылку на дату, отправьте себе пробное письмо и включите шаблон.
