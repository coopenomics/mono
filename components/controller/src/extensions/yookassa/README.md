Приложение принимает вступительные и паевые взносы банковской картой через платёжный сервис ЮKassa.

В окне оплаты пайщик выбирает оплату картой, вводит данные карты на странице сервиса и подтверждает платёж. Сервис сообщает кооперативу о результате, и взнос зачисляется пайщику автоматически, без участия кассира.

К сумме взноса добавляется комиссия сервиса 3,5%. Пайщик видит полную сумму к оплате до подтверждения платежа.

Деньги поступают на расчётный счёт кооператива по договору с ЮKassa в сроки, которые установил сервис.
