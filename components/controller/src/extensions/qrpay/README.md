Приложение позволяет пайщику оплатить вступительный и паевой взносы по QR-коду со своего телефона.

В окне оплаты пайщик видит QR-код с реквизитами расчётного счёта кооператива, суммой и назначением платежа. Он сканирует код в приложении своего банка, проверяет данные и подтверждает перевод. Реквизиты, сумма и назначение платежа подставляются в перевод сами.

Деньги поступают напрямую на расчётный счёт кооператива. Приложение работает без комиссии, условия перевода задаёт банк пайщика.

После поступления денег кассир находит платёж в реестре платежей и отмечает его оплаченным. С этого момента взнос зачисляется пайщику.

Код формируется по банковским реквизитам кооператива. Проверьте их перед включением приложения.
