# Оплата по QR — документация разработчика

В окне оплаты вступительного или паевого взноса приложение показывает QR-код для оплаты. Пайщик сканирует код в приложении своего банка, и банк заполняет платёж по данным из кода.

Текст страницы в каталоге приложений — `CATALOG.md`: его читают председатель и совет, технических подробностей в нём нет. Этот файл — для разработчика.

## Запись реестра

Запись — в `components/controller/src/extensions/extensions.registry.ts`. Что значит каждое поле — корневой `components/controller/CLAUDE.md`, раздел «Что расширение объявляет о себе».

### `qrpay` — Оплата по QR

- Доступность в сети: везде.
- Ставится новому кооперативу сразу, включённым (`defaults` в записи реестра).
- Модуль: `QrPayExtensionModule` — `qrpay/qrpay-extension.module.ts`.
- Своего рабочего стола нет: расширение работает на сервере и в чужих экранах.
- Настроек нет: схема пустая.
- Миграции схемы базы: 0; миграции настроек: 0.
- Обязательные порты: `Logger`, `Organization`, `PaymentMethod`, `Payment`, `PaymentProviderRegistry`.

## Где что лежит

- Сервер: `components/controller/src/extensions/qrpay/`. Подкаталоги: `i18n/`.
- Файлы верхнего уровня: `qrpay-extension.module.ts`, `qrpay.ports.ts`.
- Порты и их владельцы — `components/innercoop/PORTS.md`.
