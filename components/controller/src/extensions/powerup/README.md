Приложение следит за вычислительными ресурсами кооператива в блокчейне и пополняет их автоматически.

Каждое действие кооператива в блокчейне расходует память для хранения документов, процессорное время и пропускную способность сети. Ресурсы арендуются за AXON. Когда ресурсов мало, операции кооператива останавливаются до пополнения.

Приложение ежедневно арендует ресурсы на заданную сумму. Дополнительно задаётся минимальный запас по каждому ресурсу. При снижении запаса до минимума приложение арендует ресурсы на сумму пополнения.

На рабочем столе председатель видит запас ресурсов и журнал аренды.
