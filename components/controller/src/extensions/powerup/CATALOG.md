# Стол вычислительных ресурсов

Кооператив работает на общей сети платформы. Каждая операция кооператива — документ, платёж, решение совета — расходует ресурсы сети, которые кооператив арендует.

Приложение каждый день проверяет запас ресурсов кооператива и пополняет его автоматически. Так операции кооператива выполняются без остановок.

В настройках председатель задаёт сумму ежедневного пополнения и минимальный запас ресурсов.
