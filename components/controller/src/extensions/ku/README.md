Приложение даёт пайщикам рабочий стол кооперативного участка.

Любой пайщик объявляет собрание участка со своей повесткой. Участники присоединяются по заявлению и голосуют бюллетенями по каждому вопросу. Председатель собрания утверждает протокол своей подписью.

Собрание учреждает кооперативный участок и избирает его председателя. Решение собрания председатель направляет в совет кооператива, и после утверждения советом участок создаётся.

Пайщик становится доверенным лицом участка по заявлению и договору о полной материальной ответственности. Заявление одобряет председатель участка. На участке работает до трёх доверенных лиц.

История собраний и решений сохраняется.
