# Стол бухгалтера

Рабочий стол бухгалтера кооператива. Приложение ведёт двойную бухгалтерию по операциям кооператива на платформе и готовит налоговую отчётность.

- Реестры операций, проводок и счетов показывают учёт кооператива по каждой операции.
- Календарь отчётности показывает сроки сдачи и состояние каждого отчёта.
- Формы отчётности заполняются по данным учёта: бухгалтерский баланс, 6-НДФЛ, РСВ, ПСВ, декларация по УСН, уведомления в ФНС. Бухгалтер проверяет форму и скачивает файл для отправки в налоговую или для печати. Перед скачиванием стол проверяет файл по требованиям ФНС.
- Архив хранит отчёты после сдачи.
