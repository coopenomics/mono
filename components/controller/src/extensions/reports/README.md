Стол бухгалтера ведёт бухгалтерский учёт кооператива и готовит налоговую отчётность.

Бухгалтер видит операции кооператива, проводки по счетам, остатки на кошельках программ и на счетах учёта. Учёт ведётся двойной записью и складывается из действий пайщиков, совета и кассира.

Календарь отчётности показывает сроки сдачи. Приложение формирует бухгалтерский баланс, 6-НДФЛ, расчёт по страховым взносам, сведения для Социального фонда, декларацию по упрощённой системе и уведомления для налоговой службы. Бухгалтер проверяет форму, сверяет её с учётом и выгружает для сдачи. Сданные формы хранятся в архиве.
