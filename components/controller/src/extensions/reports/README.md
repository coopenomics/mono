# Стол бухгалтера

Рабочий стол бухгалтера кооператива. Приложение ведёт двойную бухгалтерию по операциям кооператива на платформе и готовит налоговую отчётность.

- Реестры операций, проводок, кошельков и счетов показывают учёт кооператива по каждой операции.
- Календарь отчётности показывает сроки сдачи и состояние каждого отчёта.
- Формы отчётности заполняются по данным учёта: бухгалтерский баланс, 6-НДФЛ, РСВ, ПСВ, декларация по УСН, уведомления в ФНС. Бухгалтер проверяет форму и скачивает файл XML для отправки или PDF для просмотра. Перед скачиванием стол сверяет XML со схемой ФНС.
- Архив хранит файлы отчётов после сдачи.
