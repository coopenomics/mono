# Стол поддержки

Приложение для обращений пайщика в совет кооператива: происшествия, запросы на обслуживание и обращения в орган управления.

Фаза 2: класс расширения и три файла-декларации подключены к реестру; заведены сущности («Обращение», «Сообщение», «Вложение») и репозитории. Сервисы, резолверы и экраны — в следующих фазах.
