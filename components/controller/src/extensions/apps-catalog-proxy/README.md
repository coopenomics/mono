# Стол разработчика

Приложение публикует приложения кооператива в общий каталог платформы.

- Разработчик заводит пакет своего приложения и публикует его выпуски.
- Выпуск проходит модерацию перед публикацией в каталоге.
- На столе назначаются издатели приложений. Издатель-пайщик получает ключ каталога на своё приложение.
- Разработчик задаёт тарифы и видит подписчиков своего приложения.
