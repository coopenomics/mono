# Стол разработчика

Стол для разработчиков, которые создают приложения для кооперативов платформы.

- Разработчик размещает своё приложение в общем каталоге и выпускает его новые версии.
- Каждая версия проходит проверку перед публикацией.
- На столе назначаются издатели приложений.
- Разработчик задаёт цену подписки и видит кооперативы, которые подключили его приложение.
