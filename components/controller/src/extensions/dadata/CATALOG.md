# Анкета по ИНН

Приложение ускоряет вступление организации в кооператив. Представитель организации вводит ИНН, и анкета заполняется сведениями из государственного реестра юридических лиц: наименование, ОГРН, КПП, юридический адрес и руководитель.

Телефон, фактический адрес и банковские реквизиты организация указывает сама.

Для работы приложения укажите в настройках ключ сервиса DaData.
