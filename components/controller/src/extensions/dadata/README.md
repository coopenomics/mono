# Анкета по ИНН — документация разработчика

Приложение ускоряет вступление организации в кооператив. Представитель организации вводит ИНН, и анкета заполняется сведениями из государственного реестра юридических лиц: наименование, ОГРН, КПП, юридический адрес и руководитель.

Текст страницы в каталоге приложений — `CATALOG.md`: его читают председатель и совет, технических подробностей в нём нет. Этот файл — для разработчика.

## Запись реестра

Запись — в `components/controller/src/extensions/extensions.registry.ts`. Что значит каждое поле — корневой `components/controller/CLAUDE.md`, раздел «Что расширение объявляет о себе».

### `dadata` — Анкета по ИНН

- Доступность в сети: везде.
- Ставит председатель из каталога приложений (`defaults` в записи реестра нет).
- Модуль: `DadataExtensionModule` — `dadata/dadata-extension.module.ts`.
- Своего рабочего стола нет: расширение работает на сервере и в чужих экранах.
- Поля настроек (`Schema` модуля): `api_key`, `secret_key`, `api_url`.
- Миграции схемы базы: 0; миграции настроек: 0.
- Обязательные порты: `Logger`, `OrganizationLookupRegistry`.

## Где что лежит

- Сервер: `components/controller/src/extensions/dadata/`. Подкаталоги: `domain/`, `i18n/`.
- Файлы верхнего уровня: `dadata-extension.module.ts`, `dadata.ports.ts`.
- Порты и их владельцы — `components/innercoop/PORTS.md`.

## Как устроено

Расширение заполняет анкету организации при вступлении в кооператив по ИНН. Пайщик вводит ИНН первым полем, сервер получает сведения из ЕГРЮЛ через DaData и заполняет ими анкету: полное и краткое наименование, тип организации, ОГРН, КПП, юридический адрес, город, руководителя и его должность. Эти поля закрыты для правки. Телефон, основание полномочий, фактический адрес и банковские реквизиты пайщик заполняет сам.

Без расширения или без ключа анкета заполняется вручную.
