Расширение заполняет анкету организации при вступлении в кооператив по ИНН. Пайщик вводит ИНН первым полем, сервер получает сведения из ЕГРЮЛ через DaData и заполняет ими анкету: полное и краткое наименование, тип организации, ОГРН, КПП, юридический адрес, город, руководителя и его должность. Эти поля закрыты для правки. Телефон, основание полномочий, фактический адрес и банковские реквизиты пайщик заполняет сам.

Без расширения или без ключа анкета заполняется вручную.
