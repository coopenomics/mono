Установите приложение из каталога. Рабочий стол «Робот совета» откроется членам совета.

Каждый член совета на странице «Автоматизация решений» выбирает типы решений и доверяет роботу свой голос по ним. Председатель отдельно выбирает типы решений, протоколы которых робот подписывает за него.

Робот начинает работать по типу решения, когда доверенных ему голосов хватает для кворума и председатель доверил подпись протокола этого типа. До этого вопросы остаются в повестке для обычного голосования.
