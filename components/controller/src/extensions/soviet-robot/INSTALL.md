# Установка

1. Установите расширение из каталога. Стол «Робот совета» появится у членов совета.
2. Каждый член совета на странице «Автоматизация решений» выпускает разрешение робота и отмечает типы решений, по которым доверяет роботу свой голос. Председатель отдельно отмечает типы решений, протоколы которых робот подписывает за него.
3. Робот начнёт работать по типу решения, когда делегировавшие голоса набирают кворум и председатель делегировал подпись протокола этого типа. До этого решения остаются в повестке для ручного голосования.

Ключ кооператива должен быть в хранилище платформы: транзакции робота подаются от имени кооператива.
