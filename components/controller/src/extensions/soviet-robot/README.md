# Робот совета

Принимает типовые решения совета автоматически, за секунды, по вопросам, которые члены совета заранее разрешили решать без личного участия. Робот не подменяет совет: каждый голос и подпись протокола остаются подписью конкретного члена совета, поставленной ключом отдельного разрешения его аккаунта, которое он выдал роботу под ограниченный список типов решений.

- **Реестр действий автоматизации** — по каждому типу решения видно, кто из членов совета делегировал роботу голос, делегировал ли председатель подпись протокола и достигает ли робот кворума сам.
- **Делегирование** — член совета выпускает на своём аккаунте разрешение робота, передаёт роботу его ключ и включает автоматизацию по выбранным типам; председатель отдельно — по типам протоколов. Отзыв — в любой момент, после него робот не подпишет ничего.
- **Журнал** — каждое решение робота: этап, голоса, транзакции, ошибки и повторы.

Ключи хранятся зашифрованными ключом кооператива и не попадают в цепь. Контракт `soviet` проверяет, что ключ подписи принадлежит заявленному разрешению аккаунта члена совета и что тип решения делегирован.
