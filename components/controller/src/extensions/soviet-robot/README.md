Робот принимает типовые решения совета за секунды по вопросам, которые члены совета заранее доверили ему.

Каждый член совета сам выбирает типы решений и доверяет роботу свой голос по ним. Председатель отдельно доверяет роботу подпись протоколов выбранных типов. Каждый голос и каждая подпись остаются голосом и подписью конкретного члена совета. Доверие отзывается в любой момент.

Робот решает вопрос сам, когда доверенных ему голосов хватает для кворума и председатель доверил подпись протокола. Остальные вопросы остаются в повестке для обычного голосования.

Совет видит по каждому типу решения, кто доверил роботу голос и набирает ли робот кворум. Журнал хранит каждое решение робота с голосами и результатом.
