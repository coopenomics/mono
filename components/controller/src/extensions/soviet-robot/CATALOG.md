# Робот совета

Робот совета принимает типовые решения совета за секунды — по тем видам вопросов, которые члены совета заранее разрешили ему решать.

- Каждый голос робота — голос конкретного члена совета. Член совета сам выдаёт роботу разрешение и выбирает виды вопросов.
- Протокол решения робот подписывает, если председатель разрешил ему это для видов протоколов, которые сам выбрал.
- Разрешение член совета или председатель отзывает в любой момент.
- Реестр показывает по каждому виду решения, кто из членов совета передал роботу голос и хватает ли голосов для кворума.
- Журнал показывает каждое решение робота: этапы, голоса и ошибки.
