Приложение связывает кооператив с сетью «Карта кооператора».

Пайщик выпускает карту одним действием на своём рабочем столе. Кооператив подтверждает членство пайщика, и любой участник сети проверяет подлинность этого подтверждения.

Анкета пайщика остаётся в кооперативе. В сеть уходят фамилия, имя и отчество пайщика, для организации уходит наименование. Остальные поля анкеты сеть получает в виде контрольных отпечатков и по ним замечает расхождение данных между кооперативами. После прекращения членства кооператив отзывает подтверждение, и карта показывает прекращение членства.

Пайщик с картой вступает в другой кооператив без повторного заполнения анкеты. С его разрешения анкета передаётся напрямую из кооператива, который уже проверил данные. Новый кооператив рассматривает заявление в обычном порядке.

На экране входа карта находит учётную запись пайщика и ведёт его к обычному входу с паролем.
