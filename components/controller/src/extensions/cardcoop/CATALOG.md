# Карта кооператора

Приложение подключает кооператив к сети «Карта кооператора». Карта подтверждает, что человек состоит в кооперативе.

- Пайщик выпускает карту на своём столе одним действием, кооператив подтверждает его членство.
- Анкета пайщика остаётся в кооперативе. Сеть получает только имя пайщика (для организации — наименование).
- При выходе пайщика из кооператива подтверждение отзывается, и карта показывает, что членство прекращено.
- При вступлении в другой кооператив пайщик с помощью карты передаёт ему свою анкету и заполняет её заново только по желанию. Анкета передаётся напрямую между кооперативами и только с согласия пайщика.
- Вход на стол кооператива по-прежнему по паролю пайщика.
