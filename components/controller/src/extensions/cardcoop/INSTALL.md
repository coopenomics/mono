Расширение устанавливается после того, как кооператив включён в реестр сети «Карта пайщика».

При включении оператор сети выдаёт кооперативу секрет для проверки уведомлений — его нужно вписать в параметр «Секрет вебхука». Пока параметр пуст, кооператив может отправлять подтверждения, но не принимает уведомления о новых связках: пайщик, выпустивший карту, останется без подтверждения членства.

Адрес узла сети менять не требуется — значение по умолчанию рабочее. Поле оставлено настраиваемым для тестового контура.

Ключ подписи расширение берёт из хранилища ключей кооператива; отдельно ничего вводить не нужно.
