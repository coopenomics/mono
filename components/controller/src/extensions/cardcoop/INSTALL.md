Расширение устанавливается после того, как кооператив включён в реестр сети «Карта кооператора».

Вводить ключи не требуется — ни свои, ни сетевые. Ключ подписи расширение берёт из хранилища ключей кооператива, а ключ проверки уведомлений сети читает из цепи: сеть публикует его отдельным разрешением на своём аккаунте, и там же он меняется при ротации.

Адрес узла сети менять не требуется — значение по умолчанию рабочее. Поле оставлено настраиваемым для тестового контура.

Подключение к реестру сети происходит само (story 7.6). Кооператив при старте доносит
параметры своей установки подписанным документом: issuer и реквизиты клиента card.coop
берутся из развёртывания (`CARDCOOP_CLIENT_ID`, `CARDCOOP_CLIENT_SECRET`,
`CARDCOOP_OIDC_ISSUER` — те же значения, что получает authentik для блюпринта
`coopid-cardcoop-client`), адреса приёмников расширение называет само. Пустой секрет —
подключение пропускается с записью в журнал. Ротация секрета — смена значения в
развёртывании и перезапуск: изменившийся состав уезжает сам.

Настройка «Я — оператор сети (ВОСХОД)» включается только на установке оператора: по записи
цепи об активации кооператива она объявляет card.coop его допуск. Сеть принимает объявления
только от кооператива, названного её конфигурацией оператором, поэтому включённый по ошибке
флаг даёт отказ в журнале, а не чужие допуски.
