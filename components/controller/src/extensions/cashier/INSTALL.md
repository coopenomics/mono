# Установка стола кассира

Стол кассира входит в базовую комплектацию кооператива. Узел ставит его при
запуске сам, и настраивать его не нужно.

Чтобы пайщик работал кассиром, председатель назначает ему роль «Кассир» на
странице «Управление доступом» стола председателя. После назначения стол
появляется у пайщика в переключателе столов.
