# Беспроцентные займы

Приложение беспроцентных займов пайщикам: единый реестр займов контракта `debt`
и заём под обеспечение паевым взносом в целевой программе.

Пайщик выбирает кошелёк обеспечения из реестра обеспечения контракта, сумму и
срок, подписывает заявление и договор. С подписи сумма обеспечения переходит на
кошелёк обеспечения и в программе не участвует. Совет принимает решение,
председатель подписывает договор через запросы одобрений, кассир выплачивает
деньги с назначением «заём по договору № …». Возврат — с главного кошелька,
целиком или частями; после срока — просрочка, через пять дней — обращение
обеспечения в пользу кооператива.

Займы, выданные другими приложениями (Генерация в «Благоросте»), регистрируются
в том же реестре и видны в этом столе.

Требования — компонент 73 проекта «Благорост» в blago, стандарт процесса —
`contracts/cpp/debt/p.dbt.loan.standard.yaml`.
