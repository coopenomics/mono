# Контракты — заметки агента

## Кооперативные стандарты (`cpp/**/*.standard.yaml`)

**Стандарты пишутся и правятся только по скиллу `/coop-standards`.** Вызывай
его до первой правки YAML: там схема, правила графа, правила связей между
процессами и проверка перед сдачей. Скилл лежит в
`~/.claude/skills/coop-standards/SKILL.md`; меняется схема или правило —
правится и скилл.

Главное, что ломается без скилла:

- **Прав контракт.** Статусы, действия, документы и операции берутся из кода
  (`cpp/<contract>/`, `lib/core/ledger2/`, реестр документов в
  `C9S/docs-factory:packages/docs-templates/src/registry/`). Расхождение стандарта с кодом
  правится в стандарте.
- **Граф без обрывов.** Каждый `from`/`to` — объявленный статус или `"∅"`;
  удаление записи контрактом — переход `to: "∅"`; `virtual` — только
  итог-отказ.
- **Связи — только по межконтрактным вызовам.** `triggered_by` — точное
  `contract::action`, не проза; `related[]` пишется, когда действие одного
  контракта вызывает действие другого, в обе стороны (`consumes` /
  `provides`). Процессы одного контракта связями не соединяются. Вызываемый
  процесс обязан иметь свой стандарт.
- **Текст — для председателя и бухгалтера**, не для разработчика: правила —
  раздел «Стандарты процессов» корневого `CLAUDE.md`.

Сайт стандартов — `standards-site/` (Vue + vite). Проверка правки: поднять
`./node_modules/.bin/vite --port <порт>` в `standards-site/` и открыть
стандарт — «Описание», «Схема» и «Граф состояний» должны доходить до финиша
без строк «без шага» там, где шаг есть. Собирать сайт только `vite build`
(штатный `build` вызывает vue-tsc).
