# Контракт `edubridge`

ЦПП «Образование» — он-чейн часть приложения «Образовательный мост».

## Процессы

- **p.edu.access** — доступ к курсу. Членский взнос за курс вносится
  конвертацией паевого взноса пайщика в членский кошелёк программы
  (`convert`, операция `o.edu.conv`, Дт 80 / Кт 86) по Заявлению о
  конвертации. Подписка (`opensub` / `extendsub` / `expiresub`) — рабочее
  состояние в таблице `edusubs`; истёкшая подписка стирается, история — у
  парсера.
- **p.edu.rid** — паевой взнос преподавателя результатом интеллектуальной
  деятельности: заявление (`submitrid`, таблица `edurids`) → решение совета →
  акт (`acceptrid`, операция `o.edu.rid`, Дт 04 / Кт 80, средства в главный
  паевой кошелёк преподавателя) либо отказ (`declinerid`).

- **p.edu.teach** — участие преподавателя в хозяйственной деятельности:
  договор УХД (`signcontract`, таблица `educontracts`: pending → active) и
  приложения к нему на курс (`signannex`, таблица `eduannexes` — только до
  второй подписи). Оба документа двухподписные, как в «Благоросте»: первая
  подпись преподавателя, вторая — председателя совета через одобрение
  (`Soviet::create_approval` → `soviet::confirmapprv` → `apprvcontr` /
  `apprvannex`, где двухподписный документ публикуется в реестре); отказ
  (`dclinecontr` / `dclineannex`) стирает ожидающую запись. Движений средств
  нет; `submitrid` требует действующий договор.

Действия преподавателя и пайщика авторизуются ключом кооператива: документ
подписывает пайщик, отправляет бэкенд. Коллбэки одобрений авторизуются
контрактом совета.

Источник правды по логике и операциям — `p.edu.access.standard.yaml`,
`p.edu.rid.standard.yaml` и `p.edu.teach.standard.yaml`.
