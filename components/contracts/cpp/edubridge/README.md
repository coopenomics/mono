# Контракт `edubridge`

ЦПП «Образование» — он-чейн часть приложения «Образовательный мост».

## Процессы

- **p.edu.access** — доступ к курсу. Членский взнос за курс вносится
  конвертацией паевого взноса пайщика в членский кошелёк программы
  (`convert`, операция `o.edu.conv`, Дт 80 / Кт 86) по Заявлению о
  конвертации. Подписка (`opensub` / `chargefee` / `expiresub`) — рабочее
  состояние в таблице `edusubs`; истёкшая подписка стирается, история — у
  парсера. Все суммы процесса считает контракт по условиям курса (`setcourse`,
  таблица `eduterms`): взнос участника и оплаченный срок (`chargefee`),
  удержание по гарантии и его освобождение (`unlockfee`, `chargelesson`),
  возврат при отмене (`cancelsub`, `warrgrant`). Приложение сумм не передаёт;
  расчёт — в `lib/core/edubridge/economy.hpp`.
- **p.edu.rid** — паевой взнос преподавателя результатом интеллектуальной
  деятельности: отчёт о занятии (`openlesson`, таблица `edulessons`), расчёт
  с участниками по одной подписке за действие (`chargelesson`: оплата занятия
  уходит из резерва подписки во взнос преподавателя — за каждого участника
  либо фиксированно, по условиям курса), материалы на ответственное хранение
  на сумму расчёта (`holdrid`, таблица `edurids`, Дт 08 / Кт 76) → заявление (`submitrid`) → решение совета → акт
  (`acceptrid`: `o.edu.rid`, Дт 04 / Кт 08, и `o.edu.ridshr`, Дт 76 / Кт 80,
  сумма на паевой кошелёк программы `w.edu.share`) либо отказ (`declinerid`,
  `recallrid`). В ЦПП «Цифровой Кошелёк» паевой взнос переходит заявлением
  преподавателя о трансляции (`wthshare`, `o.edu.wthshr`, `w.edu.share` →
  `w.wal.share`, без проводки); возврат паевого взноса — уже оттуда.
  Результат оплачивается из резерва выплат преподавателям своего курса:
  таблица `educourses` ведёт по каждому курсу собранное, остаток резерва и
  выплаченное; при нехватке резерва курса `acceptrid` отклоняется.

- **p.edu.teach** — участие преподавателя в хозяйственной деятельности:
  договор УХД (`signcontract`, таблица `educontracts`: pending → active).
  Документ двухподписный, как в «Благоросте»: первая подпись преподавателя,
  вторая — председателя совета через одобрение (`Soviet::create_approval` →
  `soviet::confirmapprv` → `apprvcontr`, где двухподписный документ
  публикуется в реестре); отказ (`dclinecontr`) стирает ожидающую запись.
  Допуск преподавателя к курсу и его ставка на курсе — `setassign` /
  `delassign`, таблица `eduassigns`; отдельного документа у допуска нет.
  Движений средств нет;
  `submitrid` требует действующий договор.

Действия преподавателя и пайщика авторизуются ключом кооператива: документ
подписывает пайщик, отправляет бэкенд. Коллбэки одобрений авторизуются
контрактом совета.

Источник правды по логике и операциям — `p.edu.access.standard.yaml`,
`p.edu.rid.standard.yaml` и `p.edu.teach.standard.yaml`.
