# Контракт "marketplace"

## Описание

Контракт "marketplace" представляет собой платформу обмена в кооперативной среде. Обмен производится в соответствии с требованиями законодательства ФЗ-3085-1 "О Потребительской Кооперации".

## Структура Контракта

Контракт состоит из следующих компонентов:

### Структуры

- `balance`: Описывает баланс пользователя.
- `requests`: Описывает информацию об обмене.
- `requests_params`: Параметры обмена, включая имя пользователя, контракт, количество единиц, цену за штуку и дополнительные данные и метаданные.

## Использование

### Установка

Для развертывания контракта следуйте стандартной процедуре развертывания контрактов EOSIO.

### Интеграция

Взаимодействие с контрактом осуществляется через стандартный интерфейс EOSIO, с использованием соответствующих действий.

## Списание обеспечительной части по итогу периода (процесс p.mkt.due, задача 99D-33)

Суммы для итога участка и списания контракт держит в своих счётчиках и не
принимает их от узла:

- `kudues` — строка пайщика за период списания (пайщик, участок, период):
  стоимость выданных заказов, обеспечительная часть к списанию по ставкам,
  удержания при отказе (целиком участку), число заказов;
- `kucounters` — строка участка за период: стоимость заказов (T) и собранная
  обеспечительная часть (C), по которым `closeperiod` считает ставки.

Период нумерует контракт — `Branch::aid_period` (календарный месяц UTC либо
отрезок `brnconfig.aid_period_seconds` на стенде). Счётчики пишут те же
транзакции, что двигают кошелёк `w.mkt.due`: `issueact2` пополняет в период
конца гарантийного срока, `cancelorder` (удержание при отказе) — в текущий
период, `onmktrtauth` уменьшает на возвращённое, `exitdue` (вызывает
registrator) стирает строки пайщика. Единственное место записи —
`lib/core/marketplace/dues.hpp`.

Узел по окончании периода зовёт `closeperiod(coopname, braname, period, planned,
memos, aid_paid)` — только факты о расходах — и `chargeperiod(coopname, username,
braname, period)` по каждой строке пайщика; списание идёт одной транзакцией в
нитке `p.mkt.due` с хэшем строки (`Marketplace::Dues::charge_hash`) и стирает её.
Память счётчиков оплачивает контракт (`RAM_PAYER_CLASS(…, contract)`).
Переходное действие `migratedue` переносит строки, выданные до появления
счётчиков, под потолком остатка кошелька пайщика; снимается следующим выпуском.
