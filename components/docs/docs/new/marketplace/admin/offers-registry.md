# Реестр предложений

Реестр предложений содержит все предложения поставщиков кооператива в любом состоянии. Это опубликованные, снятые, отклонённые и ждущие модерации. Страница «Модерация» показывает только очередь на решение. Реестр показывает всю историю ассортимента кооператива.

![Реестр предложений](/assets/new/marketplace/admin/offers-registry/01-offers-registry.png)

Таблица показывает состояние, номер предложения, товар, поставщика и цену. Кнопка «Фильтр» в шапке отбирает предложения по состоянию и поставщику. Нажатие на строку открывает карточку предложения для просмотра. Администратор видит, что предлагает поставщик и на каких условиях, до того как предложение попадёт в каталог. Решение по новому предложению принимается на странице «Модерация».
