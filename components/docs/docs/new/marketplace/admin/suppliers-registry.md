# Реестр поставщиков

Реестр поставщиков отвечает на вопрос «кто вообще имеет право предлагать имущество кооперативу». Поставщик в Столе заказов — это не внешняя организация, а пайщик кооператива, допущенный к публикации Предложений. Прежде чем первое Предложение появится на модерации, его автор должен оказаться в этом реестре — так администратор управляет самим кругом поставщиков, а не только их товарами.

![Реестр поставщиков на столе администратора](/assets/new/marketplace/admin/suppliers-registry/01-suppliers-registry.png)

В реестре перечислены все пайщики, допущенные к публикации Предложений. Здесь же администратор работает с допуском:

## Одобрение заявок и прямое добавление

Попасть в поставщики можно двумя путями, и оба проходят через эту страницу:

- **По заявке** — пайщик подаёт заявку на статус поставщика, администратор рассматривает и одобряет её в реестре.
- **Напрямую** — администратор может добавить поставщика сам, без заявки со стороны пайщика.

После включения в реестр пайщик получает стол поставщика и может публиковать Предложения — каждое из них перед выходом в каталог пройдёт модерацию.
