# Стол администратора

Стол администратора — рабочее место председателя кооператива в Столе заказов. Здесь настраивается всё, что определяет работу витрины и сети выдачи, и видна полная картина заказов.

Реестры:

- **[Реестр заказов](orders-registry.md)** — все заказы кооператива со статусами и деталями.
- **[Реестр поставщиков](suppliers-registry.md)** — допуск пайщиков к публикации Предложений.
- **[Реестр предложений](offers-registry.md)** — все Предложения во всех статусах.

Витрина:

- **[Модерация](moderation.md)** — одобрение и отклонение Предложений перед публикацией в каталоге.
- **[Доступные категории](categories.md)** — какие категории открыты для публикации.

Экономика и сеть:

- **[Экономика](economy.md)** — кооперативная наценка: единый процент на обеспечение хозяйственной деятельности.
- **[Пункты выдачи заказов](issuance-points.md)** — сеть кооперативных участков: карта, режим работы, статусы.
- **[Списания скоропорта](writeoffs.md)** — вывод испорченного имущества с балансов участков через решение совета.

Раздел «Подключение ЦПП» используется один раз — при [подключении Стола заказов кооперативом](../connection/coop-accept-cpp.md); после принятия программы он больше не нужен.
