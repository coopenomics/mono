# Реестр заказов

Реестр заказов — сводная картина всей заказной деятельности кооператива на столе администратора. Если пайщик в «Моих заказах» видит только свои заказы, а председатель кооперативного участка — только заказы своего ПВЗ, то здесь собраны все заказы всех пайщиков по всем участкам. Это главный наблюдательный пункт администратора: по нему видно, как движется каждый заказ и где поток задерживается.

![Реестр всех заказов кооператива с текущими статусами](/assets/new/marketplace/admin/orders-registry/01-orders-registry.png)

На странице — все заказы кооператива с текущими статусами. Каждая строка — отдельный заказ пайщика с его текущим положением в процессе.

## Фильтры по стадиям

Фильтры вверху реестра не случайны: они повторяют жизненный цикл заказа. Заказ последовательно проходит стадии:

- **ожидает сборки партии** — заказ оформлен и копится в партию поставщика;
- **ждёт акцепта поставщика** — партия собрана, слово за поставщиком;
- **в работе** — поставщик принял заказ: идёт подготовка отгрузки, доставка на участок и приёмка;
- **получен** — имущество выдано заказчику, заказ завершён.

Переключаясь по стадиям, администратор видит срез потока в каждой точке цикла — например, сколько заказов застряло в ожидании решения поставщика.

## Карточка заказа

Открыв любой заказ, администратор видит его полностью: документы, операции и проводки процесса. Это самый подробный разрез заказа на платформе — по нему можно восстановить весь путь от оформления до выдачи и разобрать любую спорную ситуацию.
