# Экономика

Страница «Экономика» — место, где администратор управляет кооперативной наценкой. Наценка — это процент, который добавляется к цене поставщика и идёт на обеспечение хозяйственной деятельности кооператива: заказчик в каталоге видит цену уже с наценкой, а поставщик получает выплату по своей себестоимости.

![Экономика на столе администратора: кооперативная наценка](/assets/new/marketplace/admin/economy/01-economy.png)

## Единый процент для всего кооператива

Наценка задаётся одним числом на весь кооператив — единый процент для всех участков и всех категорий. Это принципиальное решение: раз процент везде одинаков, невозможны спекуляции на разнице условий и переток заказов между участками — пайщику незачем «выбирать участок повыгоднее», условия всюду равны.

## Куда идёт наценка

После исполнения заказа наценка распределяется кооперативному участку, который выдал заказ. Так участок выдачи получает средства на свою работу пропорционально реально обслуженному потоку заказов — дальнейшая судьба этих средств видна председателю КУ на его столе, в экономике участка.

## Когда действует изменение

Изменение наценки действует только на новые заказы — те, что созданы после установки нового процента. Уже оформленные заказы исполняются на тех условиях, на которых заказчики их подтверждали: задним числом цена ничьего заказа не меняется.
