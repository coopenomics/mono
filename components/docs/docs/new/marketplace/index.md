# Стол заказов

**Стол заказов** — это цифровое расширение кооператива, через которое пайщики складываются на закупку имущества (продуктов, товаров, услуг) на участок, получают это имущество на пункте выдачи (ПВЗ) и при необходимости оформляют возврат.

Стол собран из шести ролевых рабочих мест, каждое со своей частью процесса:

| Роль | Что делает |
|---|---|
| **Заказчик** | Просматривает каталог Предложений, оформляет Заказ, получает имущество на ПВЗ, оформляет возврат при браке. |
| **Поставщик** | Публикует Предложения, принимает группы Заказов в работу, готовит партию к отгрузке, подписывает акт приёмки. |
| **Оператор кооперативного участка** | Создаёт акты приёмки партии, маркирует имущество штрих-кодами, ведёт реестр склада, видит ленту выдач. |
| **Председатель кооперативного участка** | Ставит закрывающую подпись акта приёмки, открывает выдачу заказа пайщику, обрабатывает заявления о возврате. |
| **Председатель кооператива** | Модерирует Предложения, ведёт справочник кооперативных категорий, заводит Сеть ПВЗ, инициирует списания. |
| **Совет** | Голосует по предложениям о списании, контролирует склад и выплаты поставщикам (read-only). |

## Магистральные процессы

Стол заказов работает в четырёх взаимосвязанных циклах:

1. **Витрина** — Председатель кооператива заводит Сеть ПВЗ и включает кооперативные категории, поставщик публикует Предложение, председатель его модерирует. Каталог наполняется.
2. **Закупочный цикл** — Заказчик собирает Заказ. Когда набирается партия, поставщик готовит её к отгрузке. На ПВЗ оператор открывает акт приёма-передачи, поставщик ставит первую подпись, председатель участка — закрывающую. Имущество переходит на баланс кооператива. Оператор маркирует партию штрих-кодами. Председатель участка открывает выдачу, заказчик ставит финальную подпись акта выдачи и забирает имущество.
3. **Возвраты** — Заказчик подаёт заявление о возврате. Председатель участка обрабатывает: либо принимает возврат на месте (с очным осмотром и компенсацией пайщику), либо предлагает очный визит, либо отказывает удалённо.
4. **Списания** — Председатель кооператива выносит на совет предложение списать испорченное / неиспользованное имущество. Совет голосует. После решения операция списания исполняется атомарно.

## Онбординг

Подключение Стола заказов идёт по [трёхуровневой схеме][onboarding-index]:

- **L1** — Решение совета о подключении ЦПП Marketplace и принятие положения кооперативом.
- **L2** — Выбор ЦПП Marketplace пайщиком при вступлении в кооператив.
- **L3** — Подпись оферты ЦПП при первом входе на стол (если L2 пропущена).

После L1+L2 пайщик может свободно работать в столе: оформлять Заказы, публиковать Предложения, выполнять роль оператора участка.
