# Подключение кооперативом

Стол заказов включается в кооперативе решением совета: совет утверждает два документа — **Положение о ЦПП «Стол заказов»** и **шаблон публичной оферты**, по которой пайщики будут присоединяться к программе. Пока оба документа не утверждены, столы недоступны, а страница подключения показывает статус «Не подключено».

![Страница подключения ЦПП](/assets/new/marketplace/connection/coop-accept-cpp/01-status.png)

Документы утверждаются по очереди. Дальнейшие шаги — добавление кооперативных участков и назначение пунктов выдачи — разблокируются после принятия обоих.

![Объявление собрания совета](/assets/new/marketplace/connection/coop-accept-cpp/02-announce-dialog.png)

Кнопка «Объявить собрание совета» открывает проект решения — «Утвердить Положение о ЦПП «Стол заказов»». Кнопка «Объявить» подписывает проект электронной подписью председателя и выносит вопрос на повестку совета.

![Ожидание решения совета](/assets/new/marketplace/connection/coop-accept-cpp/03-waiting-council.png)

Вопрос на повестке: члены совета голосуют на своём столе, председатель подписывает протокол — документ утверждён. Тем же порядком утверждается второй документ, шаблон оферты.

![ЦПП подключена](/assets/new/marketplace/connection/coop-accept-cpp/04-connected.png)

Оба документа утверждены: ЦПП «Стол заказов» подключена, оферта зарегистрирована, пайщики могут присоединяться к программе. Ниже разблокированы оставшиеся шаги — [кооперативные участки](../admin/issuance-points.md) и пункты выдачи.
