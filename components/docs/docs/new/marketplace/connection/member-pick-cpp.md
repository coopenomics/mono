# Выбор ЦПП пайщиком

Чтобы начать заказывать через Стол заказов, каждый пайщик один раз присоединяется к целевой потребительской программе (ЦПП) «Стол заказов» — подписывает оферту и знакомится с Положением программы. Эта страница онбординга показывает, подписана ли ЦПП, и ведёт к подписанию, если ещё нет.

![Страница онбординга пайщика: пакет документов ЦПП или подтверждение](/assets/new/marketplace/connection/member-pick-cpp/01-gate-or-done.png)

Страница ведёт себя по-разному в зависимости от того, подписана ли ЦПП. Если ещё нет — пайщику предлагается пакет документов для подписания: оферта на присоединение к ЦПП «Стол заказов» и Положение программы.

Если ЦПП уже подписана, вместо документов показывается зелёный баннер с датой принятия и кнопкой перехода к каталогу — повторно ничего подписывать не нужно.
