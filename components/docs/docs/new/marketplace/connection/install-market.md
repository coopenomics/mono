# Установка приложения

Стол заказов — приложение цифрового кооператива: председатель устанавливает его из магазина приложений кнопкой «включить».

![Форма установки приложения](/assets/new/marketplace/connection/install-market/01-install-form.png)

На форме установки — настройки приложения. Здесь же живут включаемые опции склада: боксы, координатные ячейки и обязательность указания места при приёмке. По умолчанию всё выключено — склад работает простым списком; включить опции можно в любой момент позже.

![После установки](/assets/new/marketplace/connection/install-market/02-after-install.png)

После установки у председателя появляются столы приложения, и интерфейс сам открывает первую доступную страницу — [подключение ЦПП](coop-accept-cpp.md): установка лишь добавляет приложение, работать стол начинает после принятия программы советом.
