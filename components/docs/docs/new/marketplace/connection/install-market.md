# Установка приложения

«Стол заказов» — это приложение платформы цифрового кооператива. Прежде чем пайщики смогут заказывать товары, председатель кооператива устанавливает его из каталога приложений. Эта страница показывает, как выглядит установка.

![Форма установки приложения «Стол заказов»](/assets/new/marketplace/connection/install-market/01-install-form.png)

Страница установки: форма настроек приложения и кнопка «Включить». После её нажатия расширение активируется в кооперативе.

![Столы Стола заказов появились после установки](/assets/new/marketplace/connection/install-market/02-after-install.png)

Сразу после установки у председателя появляются разделы (столы) Стола заказов, и интерфейс сам открывает первую доступную страницу — подключение целевой потребительской программы (ЦПП). Это следующий шаг: см. «Подключение кооперативом».
