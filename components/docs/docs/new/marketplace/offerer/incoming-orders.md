# Стол поставщика — входящие заказы

Входящие заказы — лента заказов пайщиков по предложениям поставщика. Здесь поставщик видит новые заказы, фильтрует их по стадии обработки и принимает (или отклоняет) индивидуальные заказы. Принятые заказы переходят к подготовке отгрузки и дальнейшей приёмке в кооперативном участке.

## Шаг 1. Лента входящих заказов

![Стол «Входящие заказы» поставщика: карточки заказов с номером, датой, количеством, суммой и ПВЗ; вкладки-фильтры по стадиям; кнопки «Принять» и «Отказать» на карточках.](/assets/new/marketplace/offerer/incoming-orders/01-overview.png)

Откройте стол **«Входящие заказы»**. Подзаголовок поясняет: «Заказы пайщиков, по которым вы выступаете поставщиком». Каждая карточка показывает номер заказа, дату, количество, сумму и пункт выдачи (ПВЗ). Вкладки сверху фильтруют заказы по стадии: **Все**, **Ждут моего акцепта**, **Индивидуальные ожидающие**, **Приняты**, **Поставка готова**, **Приняты кооперативом**, **Получены**, **Отменены**. Лента обновляется автоматически.

## Шаг 2. Фильтр «Ждут моего акцепта»

![Вкладка «Ждут моего акцепта»: заказы, требующие решения поставщика.](/assets/new/marketplace/offerer/incoming-orders/02-pending-filter.png)

Вкладка **«Ждут моего акцепта»** показывает заказы, по которым поставщику нужно принять решение — принять заказ или отказать в нём.

## Шаг 3. Индивидуальные заказы, ожидающие решения

![Вкладка «Индивидуальные ожидающие»: карточка заказа с кнопками «Принять» и «Отказать».](/assets/new/marketplace/offerer/incoming-orders/03-individual-pending.png)

Для предложений с индивидуальной отсечкой каждый заказ принимается отдельно. На вкладке **«Индивидуальные ожидающие»** по каждой карточке поставщик нажимает **«Принять»** или **«Отказать»** (при отказе указывается причина).

## Шаг 4. Заказ принят

![Вкладка «Индивидуальные ожидающие» после акцепта пуста: «Нет заказов в этом фильтре».](/assets/new/marketplace/offerer/incoming-orders/04-after-accept.png)

После нажатия «Принять» заказ покидает вкладку «Индивидуальные ожидающие» и переходит во вкладку «Приняты». Зарезервированные средства заказчика остаются заблокированными до выдачи имущества. Когда в фильтре не осталось заказов, отображается пустое состояние «Нет заказов в этом фильтре».

!!! note "Что дальше"
    Принятые заказы дальше готовятся к отгрузке на столе «Подготовка поставки», после чего имущество принимается в кооперативном участке актом приёма-передачи.
