# Входящие заказы

Заказы пайщиков не падают поставщику поодиночке — они наполняют сводный заказ по каждому кооперативному участку. Поставщик видит, как копится объём, и сам решает, когда принять его в работу: можно дождаться цели по объёму, а можно принять раньше, не дожидаясь полного наполнения.

![Входящие заказы поставщика](/assets/new/marketplace/offerer/incoming-orders/01-overview.png)

Заказы пайщиков сгруппированы в партии по кооперативному участку: партия копится до минимального объёма поставки, но принять её можно в любой момент и меньшего объёма. Итог показан по себестоимости — то есть по цене поставщика; членский взнос кооператива в него не входит, эти деньги поставщику не предназначены.

![После приёма заказа](/assets/new/marketplace/offerer/incoming-orders/02-after-accept.png)

После приёма заказ уходит из очереди ожидания и переходит в работу: следующий шаг поставщика — «Подготовка отгрузки». Средства заказчика при этом остаются заблокированными до выдачи имущества на пункте выдачи — деньги придут поставщику не в момент акцепта, а после того, как имущество пройдёт приёмку на участке и будет выдано заказчикам.
