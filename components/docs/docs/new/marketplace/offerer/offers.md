# Стол поставщика — мои предложения

Раздел «Мои предложения» — рабочее место поставщика. Здесь он видит все свои предложения в кооперативе во всех состояниях: на модерации, опубликованные, отклонённые и снятые.

## Обзор

![Мои предложения: счётчики по состояниям, поиск, фильтр и карточки предложений](/assets/new/marketplace/offerer/offers/01-overview.png)

В шапке — четыре счётчика: **Всего**, **Активных**, **На модерации**, **Отклонены**. Ниже — поле поиска по названию и переключатель фильтра по состоянию (Все / На модерации / Опубликованы / Отклонены / Сняты).

Каждое предложение — карточка с цветным значком состояния, названием, ценой за единицу, остатком и описанием. Чтобы опубликовать новое предложение, поставщик переходит на страницу «Создать предложение».

## Фильтр по состоянию

![Фильтр «На модерации» — предложения, ожидающие решения председателя](/assets/new/marketplace/offerer/offers/02-pending-filter.png)

Переключатель сужает список до выбранного состояния. На примере выбрано **«На модерации»** — это предложения, отправленные на проверку и ожидающие решения председателя. После одобрения они становятся опубликованными и попадают в общий каталог; при отклонении поставщик видит причину прямо на карточке.
