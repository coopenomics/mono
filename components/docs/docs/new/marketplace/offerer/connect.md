# Подключение поставщика

Поставщиком в Столе заказов становится пайщик кооператива, допущенный администратором в реестр поставщиков. Попасть в реестр можно двумя путями: подать заявку на подключение — её рассмотрит и одобрит администратор — либо администратор добавляет пайщика в реестр напрямую, без заявки.

Пока допуск не получен, стол поставщика показывает страницу подключения: разделы стола видны в меню, но работать с ними нельзя. Как только администратор допустил пайщика в реестр поставщиков, открываются все разделы стола: «Мои предложения», создание предложений, входящие заказы, подготовка отгрузки и история выплат.
