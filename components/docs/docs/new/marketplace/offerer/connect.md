# Подключение поставщика

Стол поставщика открывается не каждому пайщику: сначала нужен допуск в реестр поставщиков кооператива. Пока допуска нет, вместо разделов стола показывается страница подключения.

![Страница «Стать поставщиком»](/assets/new/marketplace/offerer/connect/01-supplier-onboarding.png)

Подключение начинается с выбора модели работы с кооперативом:

- **Членская модель** — кооператив закупает имущество по договору поставщика; это основная модель MVP.
- **Паевая модель** — поставщик вносит паевой взнос имуществом по договору кооператива; помечена «Скоро» и пока недоступна.

Дальше указываются параметры заключённого с кооперативом договора — номер и дата. По вопросу заключения договора страница показывает контакты кооператива.

Кнопка «Отправить заявку» передаёт заявку председателю кооператива: он рассматривает её в [реестре поставщиков](../admin/suppliers-registry.md) на столе администратора. После одобрения стол поставщика открывается полностью. Администратор может добавить поставщика и напрямую, без заявки.
