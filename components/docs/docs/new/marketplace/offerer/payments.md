# Стол поставщика — история выплат

Раздел «История выплат» показывает поставщику движение денег по его поставкам. По каждому закрытому акту приёмки кооператив формирует платёжный запрос — поставщик отслеживает их здесь.

## Список выплат

![Таблица выплат: дата, сумма, валюта, статус, банковский референс и назначение](/assets/new/marketplace/offerer/payments/01-payments.png)

Таблица содержит колонки: **Дата**, **Сумма**, **Валюта**, **Статус**, **Референс банка** и **Назначение**. В назначении указан заказ, по которому идёт выплата («Выплата поставщику … по заказу …»). Статус **«Ожидает оплаты»** означает, что запрос сформирован, но кооператив ещё не провёл платёж. Список постраничный — внизу переключатель числа строк и навигация по страницам.
