# Выплаты

Выплата поставщику — это покупка кооперативом имущества по акту приёма-передачи. По каждому закрытому акту приёмки кооператив формирует платёжный запрос поставщику; раздел «История выплат» показывает все такие запросы и их состояние.

![История выплат поставщика](/assets/new/marketplace/offerer/payments/01-payments.png)

По каждой выплате видны дата, сумма, валюта, статус, банковский референс и назначение платежа. Свежие запросы стоят в статусе «Ожидает» с суммой по заказу.

Сумма выплаты — это сумма закрытого акта приёма-передачи, то есть фактически принятое на участке имущество по цене из акта (с учётом корректировок приёмки, если они были). Наценка кооператива в выплату не входит — она добавляется к цене для заказчика и остаётся у кооператива.

Выплата уходит поставщику после выдачи имущества заказчикам: пока заказчики не получили заказы на пункте выдачи, их средства остаются заблокированными, и платёж находится в ожидании.
