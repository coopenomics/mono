# Стол поставщика — создание предложения

Публикация предложения (offer) поставщиком — точка входа в поток «Стол заказов»: поставщик-пайщик заводит товар, задаёт цену, доступное количество и правило приёма заказов, после чего отправляет предложение на модерацию председателю. До одобрения товар не виден в публичном каталоге кооператива.

## Шаг 1. Пустая форма «Новое предложение»

![Форма «Новое предложение» сразу после открытия: все поля пустые.](/assets/new/marketplace/offerer/offer-create/01-empty-form.png)

Откройте форму создания предложения. Все поля пустые; обязательные отмечены звёздочкой. Поставщик заполняет карточку товара, который хочет предложить кооперативу.

## Шаг 2. Заполненная форма

![Заполненная форма: название, описание, категория, цена за единицу, единица измерения, доступное количество, гарантия и тип отсечки заказов.](/assets/new/marketplace/offerer/offer-create/02-filled-form.png)

Заполните карточку предложения:

- **Название товара** и **Описание** — то, что увидит пайщик в каталоге.
- **Категория** — одна из кооперативных категорий (здесь «Овощи и фрукты»).
- **Цена за единицу** и **Единица** измерения («шт.»). Цена допускает до 4 знаков после запятой.
- **Доступное количество** — складской остаток; переключатель **«Без ограничения по количеству»** снимает лимит.
- **Гарантия (дней)** — срок гарантии на товар.

**Тип отсечки заказов** определяет, как поставщик принимает заказы по этому предложению:

- **По расписанию (time_based)** — заказы копятся до отсечки по времени;
- **По объёму (volume_based)** — отсечка по накопленному объёму;
- **Открытая подписка (open_subscription)** — постоянный приём;
- **Индивидуально (individual)** — каждый заказ принимается отдельно, без ожидания цикла.

Что даёт каждый тип, какие поля он открывает и как им управлять — подробно в разделе [Типы снабжения (отсечка заказов)](../supply-types.md).

Нажмите **«Опубликовать на модерацию»**.

## Шаг 3. Отправлено на модерацию

![После клика «Опубликовать на модерацию» — успешная отправка и редирект в каталог.](/assets/new/marketplace/offerer/offer-create/03-after-submit.png)

После отправки интерфейс возвращает поставщика в каталог. Предложение ушло председателю на модерацию; до одобрения оно не показывается другим пайщикам.

## Шаг 4. Предложение в каталоге

![Каталог Стола заказов после публикации предложения.](/assets/new/marketplace/offerer/offer-create/04-catalog-after.png)

После одобрения председателем предложение появляется в публичном каталоге кооператива с чипом «Опубликовано», ценой, остатком и кнопкой **«Заказать»** — теперь по нему можно оформлять заказы.

!!! note "Сначала — модерация"
    Свежесозданное предложение получает статус «На модерации» и не попадает в каталог, пока председатель не нажмёт «Одобрить». Это следующий шаг потока.
