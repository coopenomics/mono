# Создание предложения в Столе заказов

Эта страница описывает форму **«Новое предложение»** — основной инструмент поставщика для добавления товара или услуги в каталог Стола заказов. Форма открывается по адресу `/<coopname>/market/create-offer`. В скриншотах ниже `<coopname> = voskhod`.

!!!info "Кому доступна"
    Открыть форму может любой пайщик. Но **успешно создать предложение могут только поставщики**, у которых заполнены поля поставщика (название, ОГРН, банковские реквизиты) и есть хотя бы одна доступная для них категория ЦПП (см. раздел «Категории ЦПП» в Столе председателя).

## 1. Пустая форма

![Полностью пустая форма «Новое предложение» сразу после открытия](/assets/new/marketplace/offerer/offer-create/01-empty-form.png)

Заголовок страницы — **«Новое предложение»**. Форма состоит из следующих полей:

| Поле | Обязательное | Описание |
| --- | --- | --- |
| **Название товара** | ✅ | Короткое наименование, которое увидит заказчик в каталоге. |
| **Описание** | — | Произвольный текст, абзац-два о товаре, упаковке, особенностях. |
| **Категория** | ✅ | Выбор из справочника категорий ЦПП. Список ведёт председатель в разделе «Категории ЦПП» Стола председателя. |
| **Цена за единицу** | ✅ | Числовое значение с подсказкой «До 4 знаков после запятой, например 100.5000». |
| **Единица** | ✅ | Единица измерения (по умолчанию «шт.»). |
| **Доступное количество** | ✅ | Число доступных единиц (по умолчанию 1) или переключатель **«Без ограничения по количеству»**. |
| **Гарантия (дней)** | — | Срок, в течение которого заказчик может оформить возврат (по умолчанию 0). |

### Тип отсечки заказов

Под основными полями — обязательный блок **«Тип отсечки заказов»** с четырьмя радио-кнопками:

- **По расписанию** (`time_based`) — заказы собираются весь цикл, поставка происходит по истечении срока. Если набралось меньше минимального порога — заказы автоматически отменяются. Под радио-кнопкой подсказка: «Поставка по истечении цикла; если набралось меньше — заказы отменятся.»
- **По объёму** (`volume_based`) — поставка стартует, как только заказчики набрали указанный объём, без ожидания конца цикла.
- **Открытая подписка** (`open_subscription`) — заказы принимаются непрерывно, без отсечек.
- **Индивидуально** (`individual`) — поставщик согласует условия с каждым заказчиком отдельно (используется для услуг и нестандартных партий).

### Длительность цикла и порог

Ниже — числовое поле **«Длительность цикла (дней)»** (по умолчанию 7) и опциональное **«Минимальный порог объёма»** (используется только для `volume_based` и `time_based`).

## 2. Заполненная форма

![Та же форма с заполненными полями: «Берёзовый сок ПК Восход», цена 120, количество 50, гарантия 7](/assets/new/marketplace/offerer/offer-create/02-filled-form.png)

Пример заполнения формы для демо-предложения:

- **Название товара:** «Берёзовый сок ПК «Восход» (демо)»
- **Описание:** «Свежий берёзовый сок, разлив 1 л. Поставка через ПВЗ Красногорск.»
- **Цена за единицу:** `120`
- **Доступное количество:** `50`
- **Гарантия (дней):** `7`
- **Тип отсечки:** «По расписанию (`time_based`)»
- **Длительность цикла (дней):** `7`

Поле **«Категория»** остаётся пустым — это сделано умышленно, чтобы показать поведение системы при пропуске обязательного поля.

## 3. Попытка отправки без категории

![Каталог Стола заказов остался пустым: «В каталоге пока нет активных предложений»](/assets/new/marketplace/offerer/offer-create/04-catalog-after.png)

После клика **«Создать»** без выбранной категории форма выводит валидационную ошибку, и предложение в каталог **не попадает**. Каталог при возврате на `/market/catalog` остаётся в исходном состоянии (см. скриншот выше): «Все 0», «В каталоге пока нет активных предложений».

!!!warning "Категории должны быть в кооперативе"
    Список категорий ведёт председатель в разделе «Категории ЦПП» Стола председателя. На пустом стенде без хотя бы одной активной категории создать предложение нельзя — даже председатель столкнётся с пустым выпадающим списком в поле «Категория».
