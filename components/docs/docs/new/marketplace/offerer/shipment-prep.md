# Подготовка отгрузки

Когда все Заказы во входящих обработаны, поставщик переходит к подготовке партии к отгрузке. На этом экране формируется логистика партии — кто, как и когда привезёт имущество на ПВЗ.

## Вариант А и Вариант Б

В Стол заказов встроены два варианта отгрузки, отличающиеся ролью самого поставщика:

- **Вариант А — личная сдача**: поставщик сам привозит партию на ПВЗ и при операторе подписывает акт приёмки.
- **Вариант Б — отгрузка через перевозчика**: поставщик передаёт партию транспортной компании, оператор на ПВЗ принимает имущество **без поставщика**, а подпись поставщика на акте приёмки приходит асинхронно через push-уведомление.

Поставщик выбирает вариант в начале подготовки. От этого зависят следующие шаги.

## Вариант А

Если поставщик сам везёт партию:

1. **Дата и время выезда** — когда поставщик планирует быть на ПВЗ. Информация уходит оператору, чтобы тот был готов принять партию.
2. **Контакт** — телефон поставщика для оператора.
3. Опционально: **ТТН** — товарно-транспортная накладная для внутреннего учёта (не обязательна).

После «Подтвердить готовность» Заказы партии переходят в статус **SHIPMENT_DISPATCHED**.

## Вариант Б

Если партия едет через перевозчика:

1. **Перевозчик** — название транспортной компании из справочника или ручной ввод.
2. **Номер ТТН** — обязательное поле для Варианта Б.
3. **Дата отгрузки** и **ожидаемая дата прибытия на ПВЗ**.
4. **Контакт перевозчика** — телефон, по которому оператор может уточнить статус доставки.

Все Заказы партии переходят в статус **SHIPMENT_DISPATCHED**. Оператор на ПВЗ получает push-уведомление «Ожидается партия от {поставщик}, ТТН {номер}».

## Печать ТТН

Если поставщик хочет получить **печатную форму ТТН** из системы, на странице есть кнопка «Сформировать ТТН». Она генерирует PDF с подставленными реквизитами кооператива, поставщика, перевозчика, перечнем Заказов и подписной зоной. Этот PDF — внутренний, не имеет юридической силы — основа для удобства; юридический документ выпускается перевозчиком отдельно.

## Что после

Имущество едет на ПВЗ. Когда оператор открывает [акт приёмки партии][reception], поставщик получает уведомление и должен поставить [первую подпись акта приёмки][sign].
