# Стол поставщика

Стол поставщика — рабочее место пайщика, который снабжает кооператив имуществом. Разделы стола повторяют путь поставки:

- **[Мои предложения](offers.md)** — опубликованные Предложения и их статусы модерации; отсюда же [создаётся новое](offer-create.md).
- **[Входящие заказы](incoming-orders.md)** — заказы пайщиков по вашим Предложениям, сгруппированные в сводные заказы; здесь партия принимается в работу.
- **[Подготовка отгрузки](shipment.md)** — состав партии к отвозу на кооперативный участок и [QR партии](shipment.md) для стойки приёмки.
- **[Подпись акта](reception-sign.md)** — акт приёма-передачи, который оператор участка предлагает подписать после контроля партии. Здесь видны корректировки веса и цены, если приёмка выявила расхождения.
- **[Выплаты](payments.md)** — история выплат за исполненные заказы.

Поставщиком становятся через [подключение к столу](connect.md) и допуск в реестр поставщиков администратором. Выплата приходит после выдачи имущества заказчикам — это покупка кооперативом имущества по акту приёма-передачи.
