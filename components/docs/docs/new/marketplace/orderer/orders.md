# Стол заказчика — «Мои заказы»

Раздел «Мои заказы» — личный список заказов пайщика на столе заказчика. Сюда заказчик возвращается, чтобы отследить, на каком этапе находится каждый оформленный заказ: ждёт цикла, принят кооперативом, готовится к выдаче или уже получен.

## Список заказов

![Список заказов пайщицы карточками: номер, дата, количество, сумма, ПВЗ и статус](/assets/new/marketplace/orderer/orders/01-my-orders.png)

Каждый заказ показан отдельной карточкой. В шапке — короткий номер заказа и цветной значок текущего статуса («В доставке», «Выдан» и т. д.). Внутри карточки: дата оформления, идентификатор предложения, количество единиц, сумма к оплате, пункт выдачи (ПВЗ) и подпись-этап внизу («Принят кооперативом», «Поставка готовится», «Получен»).

Сверху — строка фильтр-табов: **Все**, **Активные**, **Ждут поставщика**, **Приняты**, **Готовы к выдаче**, **Получены**, **Отменены заказчиком**, **Отменены поставщиком**. По умолчанию открыт таб «Все».

## Фильтр по статусу

![Список, отфильтрованный по табу «Получены» — только завершённые заказы](/assets/new/marketplace/orderer/orders/02-filter-received.png)

Нажатие на таб сужает список до заказов в выбранном статусе. На примере выбран таб **«Получены»** — остаются только завершённые заказы со значком «Выдан» и подписью «Получен». Так заказчик быстро находит, например, все заказы, которые ещё ждут поставщика, или все уже полученные.
