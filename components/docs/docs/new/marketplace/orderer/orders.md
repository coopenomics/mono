# «Мои заказы» — лента заказов пайщика

Раздел `/<coopname>/market/my-orders` — личная лента **всех заказов пайщицы**
по Столу заказов. Доступ открыт любому пайщику (`roles: []` в access-matrix
расширения), но реально каждый видит **только свои заказы**: backend
фильтрует `MarketplaceOrder.orderer_account` равным аккаунту текущего
пользователя.

![Раздел «Мои заказы» пайщицы Екатерины: восемь табов-фильтров по статусу и плейсхолдер «У вас пока нет заказов. Перейдите в каталог, чтобы оформить заказ.»](/assets/new/marketplace/orderer/orders/01-my-orders-empty.png)

## Восемь табов фильтров по статусу

Лента сегментирована по жизненному циклу заказа:

| Таб                       | Что показывает                                                                             |
|---------------------------|--------------------------------------------------------------------------------------------|
| **Все**                   | Все заказы пайщика без фильтра. Активен по умолчанию.                                       |
| **Активные**              | Заказы в любом «живом» статусе — от создания до выдачи.                                     |
| **Ждут поставщика**       | Заказы, по которым поставщик ещё не принял к работе (статус ожидания подтверждения).        |
| **Приняты**               | Поставщик подтвердил заказ; идёт подготовка и доставка на ПВЗ.                              |
| **Готовы к выдаче**       | Партия принята на ПВЗ, заказ ожидает заказчика. Дублирует ленту «Готово к получению».       |
| **Получены**              | Финальный статус: пайщик расписался при выдаче, имущество перешло в собственность.          |
| **Отменены заказчиком**   | Заказ отозван самим пайщиком (до подтверждения поставщиком).                                |
| **Отменены поставщиком**  | Поставщик отказался выполнять заказ или истёк SLA подтверждения.                            |

!!!info "Где взять данные"
    Лента читает GraphQL-запрос `Queries.Marketplace.ListMyOrders`
    (`components/desktop/src/pages/Marketplace/MyOrders/api/index.ts`),
    polling раз в 10 секунд. До подключения SDK-подписки `marketplaceOrderUpdated`
    (Story 9.x) это единственный способ узнать о смене статуса без перезахода
    на страницу.

## Пустое состояние

Если пайщик ещё ни разу не оформлял заказ — в центральной области страницы
крупным шрифтом отображается **«У вас пока нет заказов. Перейдите в каталог,
чтобы оформить заказ.»** На скриншоте — раздел свежезарегистрированной
Екатерины Александровны Смирновой: у неё нулевой остаток на кошельке
(0,00 RUB в карточке профиля слева), и заказов ещё нет — это нормальная
стартовая точка любого нового пайщика.

!!!note "Канон-виджет OrderCard"
    Когда у пайщика появятся заказы, лента не рендерит таблицу — она
    собирается из карточек `widgets/Marketplace/OrderCard` (UX-DR9 / Story
    10.2.3). Корневой класс контейнера — `mp-role-orderer`; токены палитры,
    spacing и touch-target подтягиваются из `marketplace-tokens.scss`.
    Cancel-кнопка карточки (`@action(key='cancel')`) у активного заказа
    открывает confirm-dialog и шлёт мутацию `marketplaceCancelOrder`
    (Story 4.4).

## Где это в навигации

В текущей сборке Стола заказов раздел доступен **только через прямой URL**
`/<coopname>/market/my-orders` — в левом сайдбаре «Стол пайщика» отдельной
ссылки на «Мои заказы» пока нет (он показывает Кошелёк / Удостоверение /
Реквизиты / Документы / Платежи / Собрания / Контакты / Поддержка —
традиционные пункты Стола пайщика). Подключение пункта **«Маркет» в меню
roles**-зависимой навигации произойдёт в финальном эпике интеграции
расширения (см. `extensions/market/install.ts` — workspace `market` и
defaultRoute `marketplace-catalog`).

## Что НЕ снято и почему

Сценарий пытался открыть селект статусов для отдельного кадра «доступные
значения фильтра». Селект отсутствует — фильтрация реализована **табами
поверх ленты**, а не выпадающим меню. Все 8 значений уже видны на главном
кадре, дополнительный снимок не требуется.
