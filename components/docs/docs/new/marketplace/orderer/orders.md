# Мои заказы

Лента **Мои заказы** — единое место, где пайщик видит весь свой портфель заказов: и активные, и завершённые, и отменённые.

## Жизненный цикл Заказа

Каждый Заказ проходит через серию статусов:

| Статус | Что значит |
|---|---|
| **NEW** | Заказ создан, ждёт обработки поставщиком. Можно отменить. |
| **ACCEPTED** | Поставщик принял Заказ в работу. Отмена — только через возврат. |
| **CONSOLIDATED** | Заказ объединён со Сводным заказом. Партия копится. |
| **SHIPMENT_PREPARING** | Поставщик готовит партию к отгрузке. |
| **SHIPMENT_DISPATCHED** | Партия передана перевозчику / выехала на ПВЗ. |
| **ACCEPTED_TO_COOP** | Акт приёмки подписан полностью, имущество на балансе кооператива. Председатель участка открыл выдачу. |
| **READY_TO_RECEIVE** | Имущество маркировано, председатель участка готов отдать заказчику. |
| **RECEIVED** | Заказчик подписал акт выдачи, имущество у него. Цикл закрыт. |
| **DECLINED** | Поставщик отклонил Заказ. Средства возвращены пайщику. |
| **CYCLE_EXPIRED** | Цикл закрыт без сбора партии. Заказ автоматически отменён, средства возвращены. |
| **CANCELLED** | Заказчик отменил Заказ в статусе NEW. Средства возвращены. |
| **RETURN_REQUESTED** | По Заказу подано заявление о возврате. |
| **RETURNED** | Возврат принят председателем участка. |

## Фильтры

В шапке ленты — фильтр по статусу и сортировка по дате создания. Пайщик может одним нажатием отделить активные Заказы от завершённых.

## Карточка Заказа

По клику на Заказ открывается детальный экран:

- Идентификатор и дата создания.
- Предложение, по которому оформлен Заказ (с переходом в карточку).
- Поставщик.
- ПВЗ получения.
- Количество и сумма.
- Лента событий (timeline): когда создан, когда принят поставщиком, когда отгружен, когда принят на ПВЗ, когда выдан заказчику.
- Связанные документы: акт о паевом взносе, акт приёма-передачи (если выписан), акт выдачи (если выписан), заявление о возврате (если есть).

## Действия

В зависимости от статуса в карточке доступны действия:

- **NEW** → «Отменить заказ».
- **READY_TO_RECEIVE** → «Прийти на ПВЗ» (открывает QR-код для оператора + инструкция, как доехать до участка).
- **RECEIVED** → «Подать заявление о возврате».

Полный пошаговый сценарий получения см. в [Получении заказа][receive], сценарий возврата — в [Возврате][return-claim].
