# Гарантийный возврат

Если полученный товар оказался с недостатком, вы можете вернуть его по гарантии. Заявление подаётся прямо из карточки полученного заказа — в течение гарантийного срока, который установлен для этого предложения. Решение принимает кооперативный участок: сначала удалённо по вашему описанию и фотографиям, при необходимости — на очном осмотре.

## Где найти возврат

![Карточка полученного заказа](/assets/new/marketplace/orderer/returns/01-order-detail.png)

Карточка полученного заказа: сумма, количество и цена за единицу, пункт выдачи, сверка «Заказ / Факт» и хронология — от оформления до получения. Здесь же расположен блок гарантийного возврата.

![Блок гарантийного возврата с датой окончания срока](/assets/new/marketplace/orderer/returns/02-return-available.png)

Блок гарантийного возврата показывает, можно ли ещё подать заявление. Срок возврата задаётся председателем при одобрении предложения; пока он не истёк, подача доступна, а рядом с состоянием указана дата окончания гарантии.

## Подача заявления

![Шаг «Описание»: причина возврата и количество](/assets/new/marketplace/orderer/returns/03-claim-reason.png)

Шаг «Описание»: своими словами объясните, что не так с товаром, — этот текст увидит председатель участка при удалённом рассмотрении. Здесь же указывается количество: в примере возвращаются 3 единицы из выданных. Количество можно не указывать вовсе — тогда к возврату пойдёт всё полученное.

![Шаг «Фото»: приложенные фотографии товара](/assets/new/marketplace/orderer/returns/04-claim-photo.png)

Шаг «Фото»: приложите фотографии товара. Файлы сохраняются в хранилище кооператива, а их отпечатки (хеши) записываются в блокчейн — это доказательная база, которую нельзя подменить задним числом.

![Шаг «Подпись»: заявление целиком перед подписанием](/assets/new/marketplace/orderer/returns/05-claim-preview.png)

Шаг «Подпись»: заявление на гарантийный возврат целиком — состав, количество и сумма к возврату. Вы подписываете его своим ключом; подпись уходит в блокчейн вместе с хешами фотографий.

## После подачи

![Заявление подано и ждёт решения](/assets/new/marketplace/orderer/returns/06-claim-submitted.png)

Заявление подано и ждёт решения председателя кооперативного участка. Действие подачи из карточки заказа исчезает: по одному заказу одновременно рассматривается только одно заявление. Дальше участок либо примет решение удалённо по фотографиям, либо пригласит вас на очный осмотр с товаром.
