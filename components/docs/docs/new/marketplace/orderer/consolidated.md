# Стол заказчика — сводный заказ

Раздел «Сводный заказ» показывает заказы пайщика, сгруппированные по циклу поставки. Несколько заказов, попавших в одну партию, обслуживаются совместно — на одном цикле, с одной поставкой. Это удобно, когда пайщик оформил несколько заказов, которые кооператив везёт вместе.

## Партии заказов

![Список партий: для каждой — тип цикла, этап, сумма и ПВЗ, внутри — карточки заказов](/assets/new/marketplace/orderer/consolidated/01-overview.png)

Вверху — счётчики: сколько партий в работе и сколько групп всего. Ниже — карточки партий. В шапке партии её номер и число заказов в ней. Для партии показаны: **этап партии** (минимальный активный статус среди входящих заказов — пока хотя бы один заказ ждёт цикл, вся партия считается в работе), **всего единиц**, **сумма партии** и **ПВЗ доставки**.

## Состав партии

![Партия раскрыта: внутри карточки отдельных заказов со статусами](/assets/new/marketplace/orderer/consolidated/02-group-detail.png)

Внутри партии — карточки отдельных заказов (номер, дата, идентификатор предложения, количество, сумма, ПВЗ, статус). Кнопка **«Открыть»** на карточке ведёт к подробностям конкретного заказа.
