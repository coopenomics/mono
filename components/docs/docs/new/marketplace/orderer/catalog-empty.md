# Пустой каталог

Каталог показывает предложения, опубликованные для выбранного пункта выдачи. Пока предложений нет, каталог пуст.

![Каталог без предложений](/assets/new/marketplace/orderer/catalog-empty/01-empty-catalog.png)

Сверху пункт выдачи заказчика и кнопка «Сменить». Счётчик у вкладки «Все» показывает число предложений. Предложения появятся после публикации поставщиком и одобрения на модерации. Кошелёк Стола заказов виден в шапке.
