# Заказ до получения

Пока заказ не получен, гарантийный возврат недоступен. Карточка заказа показывает его путь и действия, которые открыты сейчас.

![Заказ ждёт сборки партии](/assets/new/marketplace/orderer/order-no-return-yet/01-order-not-received.png)

Заказ в состоянии «Ожидает сборки партии». Полоса коллективного заказа показывает, какая часть партии уже собрана. Ниже сумма заказа, количество и цена за единицу. Кнопка «Отменить заказ» открыта, пока поставщик не принял заказ. Блок «Где забрать» называет пункт выдачи с адресом. Хронология пока содержит один шаг, оформление заказа. Блок гарантийного возврата появится после получения.
