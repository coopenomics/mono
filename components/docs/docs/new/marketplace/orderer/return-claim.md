# Возврат имущества

Если после получения Заказа пайщик обнаружил, что имущество имеет дефект, не соответствует Предложению или не подходит по другой объективной причине — он может оформить **заявление о возврате**.

## Когда можно вернуть

Условия возврата задаются в положении ЦПП «Стол заказов» и могут варьироваться от кооператива к кооперативу. Типовые правила:

- **Гарантийный срок** — обычно 7–14 дней с момента подписи акта выдачи. После — возврат только по решению совета.
- **Категории дефектов** — брак при производстве, повреждение при доставке, несоответствие Предложению (не тот сорт, объём, маркировка).
- **Условия товара** — товар должен быть в той же фасовке, без следов использования (для продуктов — нераспечатанная упаковка), с сохранёнными штрих-кодами кооператива.

## Подача заявления

Пайщик заходит в [Мои заказы][orders], находит нужный Заказ в статусе `RECEIVED` и нажимает «Подать заявление о возврате». Открывается форма:

1. **Категория дефекта** — выбор из справочника (брак / повреждение / несоответствие).
2. **Описание** — свободный текст до 2000 символов с подробностями.
3. **Фотографии** — до 10 файлов JPEG/PNG/WEBP, до 10 МБ каждое. Хранятся в IPFS, ссылки сохраняются в заявлении.
4. **Сумма возврата** — автоматически рассчитывается из фактической стоимости (если возвращаются не все единицы, можно скорректировать).

После заполнения формируется **заявление о возврате**: документ из реестра с подписью пайщика, фотографиями (как content-hash) и ссылкой на исходный Заказ.

## Что после

Заявление поступает председателю кооперативного участка, который выдавал Заказ. У председателя несколько вариантов реакции — см. [Обработка возвратных заявлений][approve]:

- **Принять удалённо** — председатель доверяет описанию, без очного осмотра восстанавливает паевой взнос пайщика, имущество возвращается на склад участка.
- **Очный осмотр** — пайщику предлагается принести имущество на ПВЗ; председатель сверяет факт, ставит подпись акта возврата.
- **Отказать** — председатель не согласен с заявлением. Заявление отклоняется, имущество остаётся у пайщика, средства не возвращаются. Пайщик может обжаловать через совет (отдельный процесс).

В карточке Заказа пайщик видит timeline движения заявления: подано → на рассмотрении → принято/отклонено/предложен очный визит.
