# Стол заказчика целиком

Стол заказчика состоит из четырёх разделов. Это каталог, корзина, мои заказы и код для получения. Страница показывает их на одном примере.

![Каталог](/assets/new/marketplace/orderer/marketplace-tour/01-catalog.png)

Каталог показывает предложения поставщиков для выбранного пункта выдачи карточками. Карточка содержит категорию, название, поставщика, цену за единицу, доступное количество и описание. Предложение со склада кооператива отмечено отдельно. Вкладки сверху отбирают по категории, кнопка справа задаёт порядок. Кнопка «В корзину» кладёт предложение в корзину.

![Мои заказы](/assets/new/marketplace/orderer/marketplace-tour/02-my-orders.png)

Раздел «Мои заказы» ведёт заказы от оформления до получения. Карточка заказа показывает товар, номер, дату, пункт выдачи, сумму, количество и состояние. Вкладки делят заказы по состоянию.

![Корзина](/assets/new/marketplace/orderer/marketplace-tour/03-cart.png)

Корзина собирает предложения из каталога для оформления одним заказом. Пустая корзина предлагает перейти в каталог.

![Код для получения](/assets/new/marketplace/orderer/marketplace-tour/04-receive-code.png)

Раздел «Показать QR» показывает код заказчика. Оператор пункта выдачи сканирует код и выдаёт всё, что готово к получению. Код показывают с экрана телефона или с распечатки.
