# «Готово к получению» — заказы, ожидающие на ПВЗ

Раздел `/<coopname>/market/ready-to-receive` (Story 6.7) — отдельная
лента **только тех заказов пайщика, которые сейчас в статусе
`READY_TO_RECEIVE`** на пункте выдачи: партия принята оператором,
маркирована, ждёт самовывоза. Это визуальное продолжение push-уведомления
`marketplace-order-ready` (FR22) — клик по уведомлению ведёт сюда.

## Что показано

В заголовке страницы — **«Готово к получению»**. Справа сверху — кнопка
**«↻ Обновить»** для ручного перечитывания ленты (если push-уведомление
ещё не пришло, или пайщик хочет проверить раньше следующего polling-тика).

Таблица с пятью колонками:

| Колонка             | Что в ней                                                                                  |
|---------------------|--------------------------------------------------------------------------------------------|
| **Заказ**           | Идентификатор заказа (короткая ссылка на детальный экран).                                  |
| **Пункт выдачи**    | Кооперативный участок, на котором заказ ожидает выдачи.                                     |
| **Количество**      | Сумма по позициям заказа.                                                                   |
| **Сумма заказа**    | Полная стоимость в валюте кошелька кооператива.                                             |
| **Открыто к выдаче**| Дата/время, когда оператор завершил приёмку и партия стала доступна для самовывоза.         |

Под таблицей — иконка предупреждения и текст
**«Нет заказов, готовых к получению.»** Это нормальное состояние свежей
пайщицы Екатерины: у неё нет оформленных заказов вообще, поэтому и
готовых к получению быть не может.

## Чем эта лента отличается от «Мои заказы»

«Мои заказы» (`/market/my-orders`) — это **полная** лента заказов пайщика
по всем 8 статусам жизненного цикла, с табами фильтрации. «Готово к
получению» — **узкая выборка** ровно одного статуса `READY_TO_RECEIVE`,
сделанная отдельной страницей, чтобы пайщик мог сразу из push-уведомления
попасть на список того, что нужно забрать, без переключения на правильный
таб.

Источник данных тот же — `MarketplaceOrder` в backend — но фильтр на
сервере другой: `status = 'READY_TO_RECEIVE' AND orderer_account = me`.

!!!info "Когда заказ исчезает из этой ленты"
    После того как пайщик расписывается при выдаче (вторая подпись
    `signiss2`, Story 6.6), статус заказа меняется на `RECEIVED` —
    карточка пропадает из этой ленты и появляется в табе «Получены»
    раздела «Мои заказы».

## Канон оформления

Лента строится из карточек `widgets/Marketplace/OrderCard` с корневым
классом `mp-role-orderer` и mp-status-chip = `READY_TO_RECEIVE`.
В пустом состоянии (на этом скриншоте) виджет OrderCard не отрисовывается —
показывается только обёртка таблицы с шапкой колонок и плейсхолдером.
