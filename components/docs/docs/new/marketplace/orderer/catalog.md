# Каталог витрины

Каталог — главная страница Стола заказчика. Здесь пайщик видит **активные Предложения поставщиков**, отфильтрованные по кооперативным категориям, и собирает из них корзину Заказа.

![Каталог витрины пайщицы Екатерины на свежем стенде: фильтр «✓ Все 0», селектор сортировки «Свежие сначала», плейсхолдер «Ничего не найдено — в каталоге пока нет активных предложений»](/assets/new/marketplace/orderer/catalog/01-catalog-empty.png)

На скриншоте — состояние каталога на свежем стенде до первой публикации Предложения: фильтр-чип «Все 0» (счётчик 0 — нет ни одного активного), сортировка по умолчанию «Свежие сначала», по центру placeholder «Ничего не найдено — в каталоге пока нет активных предложений». Левый сайдбар — «Стол пайщика» (Кошелёк, Удостоверение, Реквизиты, Документы, Платежи, Собрания, Контакты, Поддержка), снизу карточка с балансом «0,00 RUB Доступно».

## Что показывается

Каталог построен как лента карточек Предложений. Каждая карточка содержит:

- Краткое название имущества (например, «Картофель Адретта, мешок 25 кг»).
- Кооперативная категория (овощи и фрукты / молочные / мясо / рыба / хлеб / бакалея / напитки / готовая еда / услуги / прочие — фиксированный набор из 10 категорий).
- Цена за единицу и валюта (рубль).
- Тип цикла Предложения:
    - **Объёмный (volume-based)** — Заказы аккумулируются, пока не наберётся минимальный объём партии для отгрузки.
    - **Периодический (time-based)** — Заказы принимаются до фиксированной даты закрытия цикла.
- Кооперативный участок, куда поставщик будет привозить партию.
- Имя поставщика и его рейтинг (по результатам прошлых поставок).

## Фильтры и сортировка

В шапке каталога — фильтр по категории (фишки-чипы с количеством активных Предложений в каждой) и сортировка:

- по дате публикации (сначала новые),
- по цене (по возрастанию / убыванию).

Фильтр и сортировка применяются на стороне backend — список Предложений приходит уже отсортированным, с пагинацией.

## Что доступно из карточки

По клику на карточку открывается экран **Оформление заказа** — это уже [следующий шаг][order-create]. Из карточки также можно:

- Открыть профиль поставщика (история его Предложений, рейтинг).
- Посмотреть карточку кооперативного участка, куда будет привозиться партия (адрес ПВЗ, режим работы, председатель).

## Что не показывается

В каталоге **не отображаются**:

- Предложения, ожидающие модерации председателем кооператива.
- Предложения, отозванные поставщиком или отклонённые модерацией.
- Предложения, у которых закрыт цикл (для volume-based — набралась партия, для time-based — прошла дата закрытия).
- Предложения от поставщиков, которым кооператив временно ограничил публикации (через стол председателя).
