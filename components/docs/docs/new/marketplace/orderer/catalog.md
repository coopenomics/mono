# Каталог

Каталог — витрина вашего кооператива: здесь собраны предложения, которые публикуют поставщики-пайщики. Цены в каталоге показаны уже с наценкой кооператива — то, что вы видите, то и заплатите, ничего сверху не добавится. Сверху страницы — фильтры-чипы по категориям, чтобы быстро сузить список, а в шапке выбран ваш пункт выдачи.

![Каталог витрины с карточкой предложения](/assets/new/marketplace/orderer/catalog/01-catalog-with-offer.png)

Так выглядит каталог. Сверху — выбранный пункт выдачи; его можно сменить прямо здесь, и каталог покажет предложения, доступные на новом участке. Карточка предложения показывает категорию, цену для заказчика, доступный остаток и поставщика. Кнопка «В корзину» начинает оформление заказа.

![Карточка предложения](/assets/new/marketplace/orderer/catalog/02-offer-detail.png)

По клику на карточку открывается подробная страница предложения: фотографии, полное описание, цена за единицу с учётом наценки кооператива, поставщик и условия поставки на выбранный пункт выдачи.

![Диалог выбора количества](/assets/new/marketplace/orderer/catalog/03-quantity-dialog.png)

Кнопка «В корзину» открывает выбор количества. Количество указывается в единицах товара — килограммах, литрах или штуках, — а итоговая сумма пересчитывается сразу, пока вы меняете число. Кнопка «Добавить» кладёт позицию в корзину.
