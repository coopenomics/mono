# Нет заказов

Страница «Мои заказы» ведёт заказы заказчика от оформления до получения на пункте выдачи. У нового заказчика она пуста.

![Заказов пока нет](/assets/new/marketplace/orderer/orders-empty/01-no-orders.png)

Вкладки сверху делят заказы по состоянию. Это активные, ждут поставщика, в работе, получены и отменены. Первый заказ оформляется из каталога. Отменить заказ можно, пока его не принял поставщик. Получение оформляет оператор на месте, заказчик подписывает документ там же.
