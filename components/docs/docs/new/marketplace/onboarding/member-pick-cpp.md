# Подключение пайщика к Столу заказов

Перед первым входом на стол заказчика пайщик подписывает пакет документов целевой потребительской программы (ЦПП) «Стол заказов». Это разовое действие: после подписания программа становится доступна, и страница больше не появляется.

## Пакет документов программы

![Страница подключения: пакет ЦПП «Стол заказов» с двумя документами и кнопкой «Подписать оферту»](/assets/new/marketplace/onboarding/member-pick-cpp/01-gate-or-done.png)

Пайщику предлагается ознакомиться с двумя обязательными документами:

- **Оферта на присоединение к ЦПП «Стол заказов»** — заявление о присоединении к программе с условиями участия;
- **Положение ЦПП «Стол заказов»** — правила взаимодействия заказчиков, поставщиков и ПВЗ.

Значок «глаз» открывает документ для чтения, чекбокс отмечает ознакомление. Кнопка **«Подписать оферту»** подписывает документы электронным ключом пайщика и отправляет подпись в блокчейн; **«Отказаться»** закрывает доступ к программе.

!!!note "Если программа уже подключена"
    Пайщику, уже подписавшему ЦПП, вместо пакета документов показывается зелёный баннер «Вы уже подключены к Столу заказов» с датой подписания и кнопкой перехода в каталог.
