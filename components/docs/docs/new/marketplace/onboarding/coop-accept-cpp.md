# L1 — Подключение ЦПП Marketplace кооперативом

Первый уровень онбординга — это **одноразовое решение совета о подключении** Целевой Потребительской Программы (ЦПП) «Стол заказов» к кооперативу. Без этого решения ни один пайщик не может оформить Заказ или опубликовать Предложение.

## Кто принимает решение

Решение о подключении ЦПП — компетенция совета кооператива. Председатель готовит проект Положения о ЦПП «Стол заказов» (на основе типового шаблона из реестра документов кооперативной платформы) и выносит его в повестку очередного собрания совета.

## Что фиксируется

После того как совет проголосовал «за»:

1. **Положение о ЦПП «Стол заказов»** — статический документ из платформенного реестра с подстановкой параметров кооператива (название, реквизиты, дата принятия). Идёт через стандартный механизм фабрики документов и попадает в архив принятых положений.
2. **Регистрационная оферта ЦПП** — публичная оферта, по которой пайщики смогут на L2 присоединиться к программе. Регистрируется в общем реестре регистрационных оферт `coop_registration_offers_registry`.

Эти два документа — единое целое: положение задаёт правила, оферта — присоединение пайщика к ним.

## Что после

Когда совет утвердил ЦПП:

- В Стартовых страницах появляется кнопка «Включить Стол заказов» (раздел Магазин приложений в столе председателя).
- В мастере регистрации нового пайщика появляется опция «Подключить ЦПП "Стол заказов"» (это вход на [L2][l2]).
- Действующим пайщикам можно отправить рассылку с приглашением подписать оферту через первый вход на стол ([L3][l3]).

## Особенности

- ЦПП можно подключить ровно один раз. Повторное решение совета о подключении не имеет смысла — программа уже работает.
- Расторжение ЦПП (отказ от программы) — отдельный процесс совета, в MVP не реализован.
- Параметры ЦПП (комиссия кооператива, набор кооперативных категорий, режим работы Сети ПВЗ) задаются после подключения отдельными процессами — см. [Категории ЦПП][categories] и [Сеть ПВЗ][branches].
