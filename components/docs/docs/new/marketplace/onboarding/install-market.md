# Подключение приложения «Стол заказов»

Приложение «Стол заказов» поставляется как опциональный модуль платформы. Прежде чем кооператив сможет вести каталог, предложения и заказы, председатель подключает приложение из административного раздела «Магазин приложений» под своей учётной записью.

!!!info "Когда выполнять"
    Подключение приложения — однократная операция при первом запуске Стола заказов в кооперативе. После подключения страница принятия программы и витрина появляются у пайщиков, но пользоваться ими ещё нельзя — нужно принять Положение программы решением Совета (см. следующую инструкцию).

## Шаг 1. Открыть карточку расширения «Стол заказов» в магазине приложений

В боковом меню председателя выберите «Магазин приложений» — пункт подсвечивается зелёной полосой. Слева, под иконкой приложения, доступна кнопка «ВКЛЮЧИТЬ». Справа разворачивается панель «Настройки» с предзаполненными техническими полями. Параметры по умолчанию подходят для большинства кооперативов — менять их вручную не требуется.

![Страница подключения приложения «Стол заказов»: форма настроек и кнопка «включить» для активации.](/assets/new/marketplace/onboarding/install-market/01-install-form.png)

!!!warning "Не менять шаблон документа вручную"
    Среди настроек есть ссылка на шаблон Положения программы в реестре документов кооператива. Меняйте её только если ваш кооператив согласовал альтернативный шаблон Положения с юристом — иначе подготовка оферт для пайщиков перестанет работать.

## Шаг 2. Активировать расширение и убедиться в успехе

Нажмите «ВКЛЮЧИТЬ». Платформа подключает разделы Стола заказов: страницу принятия программы, витрину и роли участников (оператор ПВЗ, заказчик, поставщик, член совета). После короткой перенастройки карточка приложения покажет описание «Стол заказов» и вкладки «Настройки / Помощь». Это значит — приложение подключено и готово к работе.

![Состояние после подключения: уведомление об успехе и обновлённый интерфейс с разделами Стола заказов.](/assets/new/marketplace/onboarding/install-market/02-after-install.png)

!!!note "Следующий шаг"
    После подключения в боковом меню председателя появляется пункт «Онбординг → Подключение программы «Стол заказов»». Перейдите туда, чтобы зафиксировать решение Совета о принятии Положения и наполнить каталог базовыми категориями — см. инструкцию [«Принятие программы „Стол заказов“ кооперативом»](coop-accept-cpp.md).
