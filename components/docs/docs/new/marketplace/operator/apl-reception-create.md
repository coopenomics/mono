# Создание акта приёмки партии

Когда партия физически прибыла на ПВЗ, оператор открывает экран **Создания акта приёма-передачи** (АПП). Этот акт — главный юридический документ передачи имущества от поставщика к кооперативу.

## Что заполняется

Из ленты [Ожидаемых поставок][incoming] оператор открывает партию и нажимает «Создать акт». Появляется форма приёмки:

1. **Реквизиты партии** — приходят из Предложения и Сводного заказа: поставщик, имущество, количество по плану.
2. **Фактическое количество** — оператор сверяет, что реально привезли, и вводит:
    - либо одинаковое значение по всем Заказам (если партия пришла целиком и в нужном объёме),
    - либо разные значения по разным Заказам (если, например, часть товара испорчена и должна быть распределена пропорционально).
3. **Категория состояния** — отдельно для каждого Заказа: «принят полностью» / «принят с дефектом» / «не принят» (для возврата перевозчику).
4. **Комментарий оператора** — заметка о приёмке: с какими условиями пришла партия, какие нюансы.

В Варианте А (поставщик при сдаче) — фактическое количество видит и подтверждает сам поставщик прямо на стойке.
В Варианте Б — оператор сверяет с накладной перевозчика, и подпись поставщика ожидается асинхронно.

## Подпись акта первой подписью

После «Сохранить акт» формируется документ «Акт приёма-передачи имущества» с реквизитами. Дальше — каскад подписей:

1. **Первая подпись — поставщик** ([Подпись акта поставщиком][offerer-sign]). В Варианте А — тут же на стойке. В Варианте Б — пуш на поставщика, он подписывает удалённо.
2. **Закрывающая подпись — председатель участка** ([Закрывающая подпись][close]). Только после этого имущество окончательно переходит на баланс кооператива.

Оператор сам **не подписывает акт** — он только составляет его. Подписи — у поставщика и председателя.

## Что после

После закрывающей подписи председателя:

- Имущество переходит на баланс кооператива в реестре `inventory` участка.
- Появляется задача оператора: [Маркировка партии][label] — наклеить штрих-коды.
- Запускается push-цепочка ко всем заказчикам партии: «Ваш заказ принят на ПВЗ, скоро будет готов к получению».
