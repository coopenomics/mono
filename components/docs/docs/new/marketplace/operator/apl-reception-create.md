# Стол ПВЗ — открытие приёмки партии

Открытие акта приёма-передачи (АПП) на партию — шаг, с которого начинается приёмка имущества в кооперативном участке. Когда поставщик отгрузил партию, оператор/председатель КУ открывает по ней акт приёмки; затем акт подписывают поставщик (первая подпись) и председатель КУ (закрывающая подпись).

## Шаг 1. Стол «Приёмка партии»

![Стол «Приёмка партии» кооперативного участка: поля «ID кооперативного участка» с кнопкой «Загрузить АПП» и «ID партии (shipment_id)» с кнопкой «Создать АПП»; ниже — таблица актов (АПП / Вариант / Статус / Сумма), пока пустая.](/assets/new/marketplace/operator/apl-reception-create/01-reception-empty.png)

Откройте стол **«Приёмка партии»**. Вверху — два действия:

- **«Загрузить АПП»** — по идентификатору кооперативного участка подгружает уже существующие акты приёмки в таблицу ниже.
- **«Создать АПП»** — по идентификатору партии (`shipment_id`) открывает новый акт приёма-передачи на отгруженную поставщиком партию.

Таблица внизу показывает акты участка с вариантом приёмки, статусом и суммой. До создания первого акта она пуста («Нет данных»).

!!! note "Что дальше"
    После создания акт переходит в статус ожидания подписи поставщика. Поставщик ставит первую подпись, затем председатель КУ — закрывающую; только после этого партия считается принятой в кооператив.
