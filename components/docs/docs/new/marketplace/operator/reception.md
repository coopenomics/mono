# Ожидаемые поставки

Раздел «Ожидаемые поставки» — входная точка стола ПВЗ: здесь оператор и председатель кооперативного участка (КУ) видят партии, которые поставщики собрали и везут именно на их участок. Операционные права у оператора и председателя КУ на этом столе одинаковые: принять партию может любой из них.

![Лента ожидаемых поставок участка](/assets/new/marketplace/operator/reception/01-incoming-shipments.png)

Код кооперативного участка подставляется автоматически — оператору не нужно выбирать, чей склад он смотрит. В ленте по каждой партии видны поставщик, вариант доставки, сумма поставки и текущее состояние. Пока партия не принята, она числится за поставщиком: на складе участка её ещё нет.

## Чужие партии не видны

Стол ПВЗ строго привязан к своему участку. Партия, собранная поставщиком на один участок, на столах других участков не появляется вовсе.

![Стол приёмки другого участка: чужой партии в ленте нет](/assets/new/marketplace/operator/incoming-shipments-foreign/01-no-foreign-shipments.png)

Так выглядит стол приёмки председателя КУ Одинцово в тот момент, когда поставщик собрал партию на Красногорск: в Одинцове её просто не видно. Принять чужую поставку или подписать акт по ней невозможно — каждый участок работает только со своими партиями.
