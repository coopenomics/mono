# Ожидаемые поставки

Оператор кооперативного участка живёт в трёх лентах: ожидаемые поставки → приёмка → выдача. Эта страница — первая.

## Что в ленте

В ленте «Ожидаемые поставки» видны все партии, которые **должны прибыть на ваш ПВЗ** в ближайшее время. Каждая строка — партия:

- **Поставщик**: ФИО, username, контакт.
- **Предложение**: имущество (название, категория), количество единиц.
- **Дата отгрузки** (когда поставщик отгрузил) и **ожидаемая дата прибытия**.
- **Вариант доставки**: А (поставщик везёт сам) или Б (через перевозчика).
- **Для варианта Б**: перевозчик, номер ТТН, телефон контакта.
- Число Заказов в партии и общее количество единиц по всем Заказам.

## Сортировка и фильтры

В шапке — фильтр по статусу (ожидаются, в пути, прибывшие) и сортировка по ожидаемой дате прибытия.

Оператор обычно смотрит ленту утром и видит: «сегодня к 14:00 — Сидоров с картофелем, 200 кг», «завтра — Петров с молочкой через ПЭК».

## Как зафиксировать прибытие

Когда партия физически на ПВЗ:

- Для **Варианта А** (поставщик сам приехал): оператор открывает строку партии → жмёт «Создать акт приёмки» → переходит к [Приёмке партии][reception], при этом поставщик стоит рядом и подпишет в течение нескольких минут.
- Для **Варианта Б** (перевозчик привёз): оператор разгружает, считает фактическое количество, потом открывает «Создать акт приёмки» → проставляет фактическое количество → подписи поставщика ждёт асинхронно через push.

## Push-уведомления

Оператор получает push-уведомления о ключевых событиях:

- За 24 часа до ожидаемой даты прибытия: «Завтра придёт партия от {поставщик}».
- В момент отгрузки поставщиком: «Партия от {поставщик} отгружена, ожидается {дата}».
- При расхождениях в логистике (перевозчик сообщил о задержке): «Партия задержана».
