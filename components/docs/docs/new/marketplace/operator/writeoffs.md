# Списание на участке

Скоропортящееся имущество не должно лежать на балансе кооператива дольше своего срока годности: всё, что просрочено, подлежит списанию. Списание — не кнопка на складе, а оформленный процесс с решением совета; участок в нём — последнее звено, которое подтверждает фактическое выбытие.

## Как устроен процесс

1. Председатель кооператива — или автоматика по таймеру вместо него — отбирает на складах позиции с истёкшим сроком годности и формирует служебную записку: какие позиции просрочены и предлагаются к списанию.
2. Записка уходит в совет; совет принимает решение о списании.
3. Решение получают председатели кооперативных участков, на складах которых лежит это имущество.
4. Участок осуществляет выбытие: раздача, употребление, физическое уничтожение — способ на усмотрение участка. Суть одна: имущество выбывает со склада.
5. Председатель участка подтверждает выбытие подписью — с этого момента имущество снято с баланса.

Первые три шага живут на [столе администратора](../admin/writeoffs.md); здесь, на столе ПВЗ, — последний шаг.

![Списание ждёт подтверждения склада](/assets/new/marketplace/operator/writeoffs/01-pending-confirmation.png)

Вкладка «Списание» склада показывает утверждённые советом списания, ожидающие проведения: состав имущества, причина и ссылка на решение. Подтвердить выбытие может только председатель кооперативного участка.

![Служебная записка о списании](/assets/new/marketplace/operator/writeoffs/02-service-memo.png)

Подтверждение — подпись служебной записки: ею председатель участка фиксирует, что имущество фактически выбыло со склада.

![Имущество списано](/assets/new/marketplace/operator/writeoffs/03-executed.png)

Списание проведено: позиции сняты со склада и с баланса кооператива, подтверждать на участке больше нечего.
