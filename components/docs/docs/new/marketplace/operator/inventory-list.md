# Склад участка

**Склад участка** — реестр всех маркированных единиц имущества, физически находящихся на кооперативном участке. Это рабочая «картотека» оператора.

## Что показывает

Каждая строка — единица имущества с уникальным внутренним штрих-кодом. Колонки:

- **Штрих-код** — Code128 или EAN-13, как промаркировано.
- **Предложение** — что это за имущество (название, категория).
- **Заказ** — к какому Заказу пайщика привязана единица (с переходом в карточку Заказа).
- **Заказчик** — ФИО пайщика.
- **Статус**:
    - `MARKED` — промаркировано, ждёт открытия выдачи.
    - `READY_TO_RECEIVE` — председатель участка открыл выдачу, ожидается приход пайщика.
    - `ISSUED` — выдано пайщику, физически покинуло склад.
    - `RETURNED` — возвращено пайщиком, снова на складе (ждёт списания / повторного использования).
    - `WRITTEN_OFF` — списано (физически испорчено / устарело, ушло из реестра).
- **Дата приёма на склад**.

## Фильтры

В шапке — фильтры:

- По статусу (видеть только то, что готово к выдаче, или только возвращённое).
- По Заказу или Предложению.
- По дате приёма.

## Что можно сделать из строки

- **Сканировать штрих-код** — открывает карточку конкретной единицы с историей событий (когда принята, когда выдана, кем возвращена).
- **Перейти в Заказ** — открывает карточку Заказа в столе заказчика (read-only для оператора).
- **Подать на списание** — если единица испорчена / просрочена. Списание идёт через совет — см. [Запуск списания][writeoff]. Оператор только инициирует заявку, фактическая операция — после решения совета.
