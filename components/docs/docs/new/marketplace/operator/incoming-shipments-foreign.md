# Ожидаемые поставки на чужом пункте

Оператор видит поставки только своего пункта выдачи. Поставки на другой пункт на его столе не показываются.

![Пункт без поставок](/assets/new/marketplace/operator/incoming-shipments-foreign/01-no-foreign-shipments.png)

Сверху карточка пункта выдачи оператора с адресом и состоянием. Поставки появятся на странице, когда поставщик направит партию на этот пункт. Приёмка начинается со сканирования кода поставщика кнопкой «Сканировать QR». Код подтверждает личность поставщика и состав партии.
