# Гарантийные возвраты

Гарантийный возврат проходит в два шага: сначала удалённое решение по заявлению пайщика с фотографиями, затем очный осмотр имущества на пункте выдачи и приём возврата. С возвратами работают оператор и председатель КУ.

![Лента гарантийных возвратов участка](/assets/new/marketplace/operator/returns/01-return-claims.png)

Порядок работы виден прямо на столе: удалённое решение по заявлению, очный осмотр, приём возврата. Придя на участок, пайщик показывает QR из своей заявки — оператор читает его сканером в шапке.

## Полная цепочка решения

![Заявление пайщика ждёт рассмотрения](/assets/new/marketplace/operator/return-accept/01-claims-list.png)

Табы разделяют работу по стадиям: ждут рассмотрения, ожидают визита, архив.

![Карточка заявления: обращение, фотографии, суммы](/assets/new/marketplace/operator/return-accept/02-claim-detail.png)

В карточке — обращение пайщика, фотографии товара, суммы к возврату и хронология. Отсюда принимается решение.

![Удалённое решение по фотографиям](/assets/new/marketplace/operator/return-accept/03-remote-decision.png)

По фотографиям можно пригласить заказчика на очный осмотр либо отказать сразу. Отказ обязан быть мотивирован, приглашение — нет.

![Заявление одобрено к очному осмотру](/assets/new/marketplace/operator/return-accept/04-approved-for-visit.png)

Пайщик приглашён на участок с имуществом. Пока осмотр не проведён, деньги не двигаются.

![Очный осмотр и принятие возврата](/assets/new/marketplace/operator/return-accept/05-onsite-inspection.png)

На очном осмотре председатель фиксирует, что обнаружено, и принимает возврат. Подтверждение — вторая подпись на том же заявлении пайщика: контракт требует обе подписи.

![Возврат принят](/assets/new/marketplace/operator/return-accept/06-return-accepted.png)

Средства восстановлены пайщику, имущество зачислено на склад участка обезличенным остатком кооператива. Дальше председатель либо предлагает его снова, либо списывает.
