# Поток выдач

Лента **Поток выдач** показывает оператору все Заказы, которые **готовы к выдаче** на этом ПВЗ — то есть председатель участка открыл выдачу первой подписью акта.

## Когда Заказ попадает в ленту

Заказ появляется здесь сразу после того, как:

1. Партия принята (закрыт акт приёмки председателем).
2. Имущество промаркировано.
3. Председатель участка нажал «Открыть выдачу» — поставил первую подпись акта выдачи.

В этот момент пайщику-заказчику отправляется push «Ваш заказ готов к получению на ПВЗ».

## Что в карточке Заказа

Каждая строка — Заказ с подробностями:

- **Заказчик** (ФИО, контакт, желательно с фотографией для быстрой идентификации).
- **Имущество** (название, количество).
- **Штрих-код** — наклейка на единице, которую нужно отсканировать при выдаче.
- **Дата открытия выдачи** — когда председатель подписал «Открыть выдачу».
- **Срок хранения** — сколько ещё дней Заказ ждёт пайщика, прежде чем оператор должен будет связаться с пайщиком напрямую.

## Действия оператора

Оператор работает в режиме «пайщик пришёл за Заказом»:

1. **Найти Заказ в ленте** — фильтр по ФИО / username, либо QR-код от пайщика.
2. **Сверить штрих-код** — сканер на упаковке.
3. **Передать пайщику на финальную подпись** — открыть его экран с актом выдачи, или, если пайщик пришёл без своего устройства, дать планшет ПВЗ.

Финальную подпись акта выдачи ставит **сам пайщик** через свой ЭП — см. [Получение заказа][receive].

## Что после

После финальной подписи Заказа пайщиком:

- Заказ исчезает из ленты «Поток выдач».
- Единица имущества в [Складе участка][warehouse] переходит в `ISSUED`.
- Если фактическое количество отличалось от заказа в меньшую сторону, разница возвращается пайщику на программный кошелёк автоматически.

## Если пайщик долго не приходит

Если по Заказу прошло больше N дней (типовая настройка — 7–14 дней) без появления пайщика, оператор получает напоминание «Свяжитесь с пайщиком {ФИО}». В крайних случаях имущество возвращается на склад и подаётся на списание через совет (см. [Запуск списания][writeoff]).
