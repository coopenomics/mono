# Экономика участка

У кооперативного участка есть собственный кошелёк: с каждого исполненного заказа сюда приходит членский взнос. Раздел «Экономика участка» показывает накопленные средства и позволяет распределять их между участниками работы участка. Смотреть экономику могут все, кто работает на столе ПВЗ; настройка ставок и весов распределения — право только председателя КУ, операторы видят их в режиме просмотра.

![Кошелёк участка и движения по нему](/assets/new/marketplace/operator/economy/01-branch-wallet.png)

В кошелёк участка приходит членский взнос с каждого исполненного заказа. Ниже — движения по кошельку со ссылкой на заказ-источник.

## Сетка распределения

![Сетка распределения по весам участников](/assets/new/marketplace/operator/economy/02-distribution-grid.png)

У каждого участника свой вес; доля считается как вес к сумме весов. Рядом видно, сколько уже лежит на персональном кошельке участника. Менять веса может только председатель КУ.

## Распределение накопленного

![Диалог распределения](/assets/new/marketplace/operator/economy/03-distribute-dialog.png)

Сумма разойдётся по весам участников. Резерв плановых расходов остаётся в общем кошельке — распределить его нельзя.

![После распределения: доли на персональных кошельках](/assets/new/marketplace/operator/economy/04-distributed.png)

Сумма ушла с общего кошелька на персональные кошельки участников по их долям. Дальше каждый распоряжается своей долей сам — переводом в Стол заказов или материальной помощью.

![Общий кошелёк после распределения](/assets/new/marketplace/operator/economy/05-wallet-after.png)

Остаток общего кошелька уменьшился ровно на распределённую сумму, а само распределение видно отдельной строкой в движениях.
