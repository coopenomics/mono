# История заказов

История заказов — сквозной архив пункта выдачи: все заказы, привязанные к этому кооперативному участку, с их статусами. Раздел доступен оператору и председателю КУ.

![История заказов участка](/assets/new/marketplace/operator/orders-history/01-orders-history.png)

Карточка заказа открывается по клику — оператор видит состав, суммы и весь путь заказа.
