# История заказов

История заказов содержит все заказы на этот пункт выдачи с их состояниями. Раздел открыт оператору и председателю кооперативного участка.

![История заказов участка](/assets/new/marketplace/operator/orders-history/01-orders-history.png)

Таблица показывает состояние, номер заказа, сумму, товар, количество и заказчика. Кнопка «Фильтр» в шапке отбирает заказы по состоянию. Нажатие на строку открывает заказ с его состоянием, документами и операциями. Сюда же ведут ссылки из движений на странице «Экономика участка».
