# Стол ПВЗ — маркировка имущества EAN-13

После приёмки партии в кооператив оператор кооперативного участка маркирует имущество внутренним штрих-кодом — восьмой шаг магистрального потока «Стол заказов». Формат маркировки — **EAN-13** (стандарт маркетплейсов), а не QR-код. Сгенерированные этикетки печатаются и наклеиваются на единицы товара для складского учёта и последующей выдачи пайщикам.

## Шаг 1. Панель маркировки

![Стол «Маркировка имущества» оператора/председателя КУ. Два режима: «Маркировка партии целиком» (выбор партии поставки + стратегия + формат штрих-кода) и «Поштучно по заказу». Формат — EAN-13 (стандарт маркетплейсов, не QR; UX-DR11/DR12).](/assets/new/marketplace/operator/inventory-label/01-labeling-panel.png)

Стол маркировки предлагает два режима: **«Маркировка партии целиком»** (сервер пройдёт по всем заказам выбранной партии и сгенерирует этикетки, уже промаркированные заказы пропускаются) и **«Поштучно по заказу»**. Для партии задаются стратегия маркировки (одна этикетка на заказ / на единицу / на упаковку) и формат штрих-кода. Чтобы посмотреть уже наклеенные этикетки, укажите идентификатор участка и нажмите **«Загрузить инвентарь»**.

## Шаг 2. Сетка этикеток EAN-13

![Инвентарь КУ `krg`: сетка наклеенных этикеток EAN-13 (BarcodeDisplay). На каждую единицу — машиночитаемый штрих-код, название товара и пайщик-получатель. Кнопка «Печать партии» отправляет лист этикеток на принтер.](/assets/new/marketplace/operator/inventory-label/02-inventory-grid.png)

Для каждой единицы инвентаря выводится карточка с машиночитаемым штрих-кодом EAN-13, названием товара и пайщиком-получателем. Кнопка **«Печать партии»** отправляет лист этикеток на принтер. После маркировки имущество готово к выдаче (шаги 9–10).

!!! info "Только штрих-код, не QR"
    В рамках MVP маркировка ведётся штрих-кодами формата EAN-13 / Code128 (стандарт маркетплейсов). QR-коды не используются.
