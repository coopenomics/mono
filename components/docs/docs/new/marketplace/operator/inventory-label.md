# Маркировка имущества

После того как акт приёмки закрыт председателем участка и имущество легло на баланс кооператива, оператор маркирует единицы имущества **внутренними штрих-кодами кооператива**. Это нужно, чтобы при выдаче пайщику можно было сверить «что выдаём» сканером.

## Зачем кооперативные штрих-коды

Заводские штрих-коды (с упаковки от производителя) не всегда подходят:

- На развесном товаре их вовсе нет.
- В партии могут быть единицы с одинаковыми заводскими штрих-кодами (например, 50 одинаковых мешков картофеля).
- Кооперативный штрих-код привязан к **конкретному Заказу** конкретного пайщика — это исключает путаницу при выдаче.

## Форматы

Поддерживается два формата:

- **Code128** — текстовый штрих-код произвольной длины. Универсальный, читается любым сканером, в нём кодируется ID заказа + ID партии.
- **EAN-13** — компактный 13-значный формат. Используется когда нужно уместить штрих-код в небольшую этикетку (например, на молочный пакет).

Формат выбирается оператором при маркировке партии. По умолчанию — Code128.

## Два режима маркировки

Оператор может маркировать:

- **Одну единицу за раз** — сканировать наклейку, привязать к Заказу. Полезно, когда оператор маркирует постепенно по мере поступления.
- **Всю партию за раз** — массовая маркировка по `shipment_id`. Backend сразу генерирует штрих-коды на все Заказы партии, оператор печатает их одной пачкой и наклеивает.

В массовом режиме можно задать опциональные **per-order overrides**: например, для Заказа #5 в партии — выбрать другой формат (EAN-13 вместо Code128) или другой `pack_size` (если в одном заказе несколько физических упаковок).

## Печать этикеток

Из экрана маркировки доступна кнопка **«Печать этикеток»** — формирует PDF с этикетками всех Заказов партии. Этикетка содержит:

- Штрих-код.
- Имя пайщика-заказчика (для быстрой идентификации при выдаче).
- Краткое описание имущества.
- Номер Заказа.

Оператор печатает на термопринтере или обычном принтере, режет, клеит на упаковку.

## Что после

Когда вся партия промаркирована:

- Заказы переходят в состояние «готовы к выдаче».
- Председатель участка может открывать выдачу пайщикам ([Открытие выдачи][issuance-open]).
- В реестре [Склада участка][warehouse] видны все промаркированные единицы.
