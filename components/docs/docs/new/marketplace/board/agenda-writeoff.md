# Повестка совета — проекты списания

Раздел показывает совету проекты списания скоропортящегося имущества, отправленные администратором. Голосование совета проходит на общей повестке кооператива; здесь — обзор статусов и принятых решений.

## Лента проектов

![Повестка совета: вкладки по статусам и лента проектов списания](/assets/new/marketplace/board/agenda-writeoff/01-overview.png)

Вверху — вкладки-фильтры по статусу: **Все**, **На повестке**, **Одобрены**, **Исполняются**, **Исполнены**, **Отклонены**. Черновики проектов сюда не попадают — это рабочая зона администратора на странице «Проекты списания». Внизу — общий счётчик проектов на повестке.

## Фильтр «На повестке»

![Вкладка «На повестке» — проекты, ожидающие решения совета](/assets/new/marketplace/board/agenda-writeoff/02-on-agenda.png)

Вкладка **«На повестке»** показывает проекты, отправленные в совет и ожидающие голосования. По каждому проекту видны дата создания, триггер, число позиций, сумма списания и статус. Когда проектов нет, показывается сообщение «Совет ещё не получал проектов списания».
