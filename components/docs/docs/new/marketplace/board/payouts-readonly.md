# Выплаты поставщикам

Страница «Выплаты поставщикам» показывает ленту выплат по всему кооперативу. По каждому закрытому акту приёмки кооператив формирует выплату поставщику. Подтверждает и отклоняет выплаты кассир кооператива в реестре платежей. Для совета страница открыта только для чтения.

![Выплаты поставщикам](/assets/new/marketplace/board/payouts-readonly/01-board-payouts.png)

Таблица показывает дату, поставщика, сумму, состояние и назначение выплаты. Строка открывает выплату целиком. В ней видно, за какой заказ платили и чем оплата подтверждена. Поиск сверху находит выплаты по имени поставщика или названию организации, кнопка «Фильтр» отбирает по состоянию. Внизу число выплат и их сумма.
