# Выплаты поставщикам — обзор совета

Раздел предназначен для обзора советом выплат поставщикам по столу заказов.

## Раздел в подготовке

![Информационный экран: раздел обзора выплат для совета в подготовке](/assets/new/marketplace/board/payouts-readonly/01-placeholder.png)

На текущем этапе раздел показывает информационный экран. До его подключения совет видит движение средств по выплатам через кассовый стол кооператива. Сами выплаты по конкретным актам приёмки доступны поставщику в его разделе «История выплат».
