# Склад кооператива

Страница «Склад» показывает имущество кооператива по всем пунктам выдачи. Для совета она открыта только для чтения. Операции с имуществом выполняют операторы на столах пунктов выдачи.

![Склад кооператива](/assets/new/marketplace/board/warehouse-readonly/01-warehouse-summary-empty.png)

Плитки сверху считают позиции на складе, единицы на остатке, пункты выдачи, позиции с истёкшим сроком и единицы без штрих-кода. Таблица идёт по позициям и пунктам выдачи. В ней принятое, выданное и списанное количество. Поиск находит позицию по товару, категории, пункту выдачи или адресу, отбор по состоянию сужает список. Нажатие на наименование открывает предложение, по которому имущество пришло.
