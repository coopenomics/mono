# Склад кооператива

Совет имеет **read-only доступ** к складам всех кооперативных участков. Это инструмент контроля: член совета может в любой момент посмотреть, что физически принадлежит кооперативу, без необходимости запрашивать у председателя.

## Что видно

Из меню Стола совета открывается страница «Склад кооператива». Это **агрегированный реестр** всех единиц имущества по всей сети ПВЗ:

- **Единицы со статусами**: `MARKED` (промаркировано, ждёт выдачи), `READY_TO_RECEIVE` (открыта выдача), `ISSUED` (выдано), `RETURNED` (возвращено), `WRITTEN_OFF` (списано).
- **Распределение по ПВЗ**: сколько единиц на каждом участке.
- **Распределение по категориям**: что у нас больше всего по объёму / стоимости.
- **Динамика**: график движения склада за последние 30 / 90 / 365 дней.

## Фильтры

В шапке доступны фильтры:

- По статусу.
- По кооперативному участку.
- По категории.
- По поставщику (кто привозил эту партию).
- По дате (когда единица принята на склад).

Все фильтры — на стороне backend, выборка приходит с пагинацией.

## Действия совета

Совет не может выдавать имущество, маркировать, списывать или менять статусы — это компетенция оператора и председателей. У совета только **смотрите**. Однако:

- Можно **поставить пометку** к карточке единицы — заметку для следующего обсуждения совета (например, «обсудить избыток молочной продукции на КУ Красногорск»). Заметки видны другим членам совета.
- Можно **открыть карточку Заказа / Предложения / Партии**, к которой относится единица — переход на детальную страницу.

## Зачем это нужно

Член совета обычно работает с этой страницей в трёх контекстах:

1. **Подготовка к собранию совета** — посмотреть, что предлагается к списанию (раздел «Списания»), сверить с фактическим состоянием склада.
2. **Аудит** — раз в квартал / год член совета может выгрузить полный реестр и сверить с инвентарной ведомостью.
3. **Контроль председателя** — увидеть, не накапливаются ли остатки, нет ли заброшенных Заказов.
