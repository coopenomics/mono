# Стол председателя — сводный склад кооператива

«Сводный склад кооператива» — агрегированный обзор движения товарных позиций по всем участкам: сколько единиц на складах, сколько выдано, возвращено и списано.

## Обзор

![Сводный склад: счётчики и таблица позиций по участкам с приходом и расходом](/assets/new/marketplace/board/warehouse-readonly/01-warehouse-summary-empty.png)

В шапке — счётчики: **Активных позиций**, **КУ с движением**, **Товарных позиций в обороте**, **Списано (накопительно)**. Ниже — две вкладки: **Сводный склад** (таблица: SKU, позиция, ПВЗ, приход, расход, остаток) и **Поток заказов и поставок**. Поиск по SKU/названию помогает быстро найти позицию.

!!!note "Доступ к данным"
    Сводная таблица наполняется по мере накопления движений на участках. Детальный список наклеек по конкретному участку доступен председателю участка на его столе «Склад моего КУ».
