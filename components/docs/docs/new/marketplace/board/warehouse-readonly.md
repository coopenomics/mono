# Сводный склад кооператива (Эпик 9, Story 9.2)

Раздел `/<coopname>/market/warehouse-summary` — обзор полного склада
имущества по всем кооперативным участкам (КУ) для **председателя и членов
совета**. Read-only зрение для контроля движений: ни одна позиция здесь
не списывается и не редактируется (списания идут через [«Списания
скоропорта»][writeoffs], выдачи — через operator-стол ПВЗ).

## Две вкладки

В шапке страницы — табы:

- **«Сводный склад»** — текущие остатки по `ku × sku` (на скриншоте активна).
- **«Поток заказов и поставок»** — динамика приходов/расходов
  во времени (графики FR37/FR38). На MVP — табличные итоги, графики
  динамики подключаются через `AR37 SDK-подписки платформы` отдельным
  этапом интеграции.

## Четыре KPI-карточки

Над таблицей — четыре сводных счётчика по всему кооперативу:

| Карточка                       | Что показывает                                                         |
|--------------------------------|------------------------------------------------------------------------|
| **Активных позиций**           | Сколько SKU сейчас на складах хотя бы одного КУ с ненулевым остатком.   |
| **КУ с движением**             | Сколько кооперативных участков имеют хотя бы одно ненулевое движение.   |
| **Товарных позиций в обороте** | Сумма единиц по всем активным SKU (мера оборота, а не количества SKU).  |
| **Списано (накопительно)**     | Сколько позиций уже списано через `o.mkt.wroff` — суммарно с начала.    |

На свежем стенде все четыре счётчика — `0`.

## Таблица сводного склада

Под KPI — таблица с поиском **«Поиск по SKU / названию»** в правом верху
секции и колонками:

| Колонка      | Что в ней                                                              |
|--------------|------------------------------------------------------------------------|
| **SKU**      | Идентификатор товарной позиции (артикул в реестре кооператива).         |
| **Позиция**  | Человекочитаемое название позиции.                                      |
| **ПВЗ**      | Кооперативный участок, на чьём складе находится позиция.                |
| **Приход**   | Совокупный приход за выбранный период (по умолчанию — за всё время).    |
| **Расход**   | Совокупный расход — выдачи пайщикам, списания, возвраты на склад.       |
| **Остаток**  | Текущий остаток.                                                        |
| **Ед.**      | Единица измерения (шт., кг., литр и т. п.).                              |

Иконка предупреждения и **«Нет данных»** — нормальное состояние свежего
кооператива до первых поставок.

## Доступ и ограничения

- **Чтение разрешено** только `chairman` и `member` (access-matrix
  marketplace: `Warehouse: ['read:all']`). Обычный пайщик пункт меню
  не видит, прямой URL вернёт 403.
- **Редактирование запрещено** на этой странице **всем ролям**. Список
  имущества меняется только триггерами marketplace-контракта:
  `o.mkt.label` (маркировка приёма), `o.mkt.iss1/iss2` (выдача),
  `o.mkt.wroff/wroff2` (списание), `o.mkt.return/return2` (возврат).
