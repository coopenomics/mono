# Стол председателя — модерация предложений

Модерация предложений — шаг, на котором председатель кооператива решает, какие товары поставщиков попадут в публичный каталог. Поставщик уже опубликовал предложение (оно в статусе «На модерации»); председатель одобряет его, после чего товар становится доступен пайщикам для заказа.

## Шаг 1. Очередь на модерации

![Стол «Модерация предложений» председателя: лента предложений в статусе «На модерации» с действием «Одобрить» на карточке и счётчиком «На модерации: 1».](/assets/new/marketplace/chairman/offer-moderation/01-moderation-list.png)

Откройте стол **«Модерация предложений»**. Подзаголовок поясняет: «Предложения поставщиков ожидают вашего одобрения. После „Одобрить“ товар появится в публичном каталоге кооператива». В правом верхнем углу — счётчик ожидающих модерации. Каждая карточка показывает название, цену, остаток и описание; на карточке доступна кнопка **«Одобрить»**.

## Шаг 2. Подтверждение одобрения

![Диалог «Одобрить предложение?»: подтверждение, что товар появится в публичном каталоге. Кнопки «Отмена» и «Одобрить».](/assets/new/marketplace/chairman/offer-moderation/02-moderation-confirm-dialog.png)

По нажатию «Одобрить» открывается диалог подтверждения «Одобрить предложение?» с названием товара и пояснением, что предложение появится в публичном каталоге кооператива. Нажмите **«Одобрить»** для публикации либо **«Отмена»**, чтобы оставить предложение на модерации.

## Шаг 3. Очередь после одобрения

![Лента модерации после одобрения: одобренное предложение пропало из очереди и сразу доступно в публичном каталоге.](/assets/new/marketplace/chairman/offer-moderation/03-moderation-after-approve.png)

После одобрения предложение исчезает из очереди модерации и сразу становится доступным в публичном каталоге кооператива — пайщики могут оформлять по нему заказы.

!!! info "Отклонение предложения"
    Председатель может не одобрять предложение — тогда оно остаётся в статусе «На модерации» и в каталог не попадает.
