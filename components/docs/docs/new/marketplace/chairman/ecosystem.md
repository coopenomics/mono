# Реестр экосистемы — другие кооперативы со «Столом заказов»

Раздел `/<coopname>/market/ecosystem` (Story 9.4) — наглядный реестр
других кооперативов, у которых тоже установлено расширение «Стол
заказов». Это **read-only заглушка** до подключения платформенного
`ecosystem_registry` (NFR-Sc2 / AR18). Полная активация —
**вторая фаза** проекта, межкооперативная торговля.

![Экосистема кооперативов: карточка «Текущий кооператив — Кооператив voskhod установил расширение Стол заказов», карточка «Другие кооперативы с расширением Стол заказов» с пояснением «Межкооперативная торговля включится позже»](/assets/new/marketplace/chairman/ecosystem/01-ecosystem.png)

## Что показано сейчас

Страница состоит из двух карточек.

### «Текущий кооператив»

Информация о собственном кооперативе:

> Кооператив **voskhod** установил расширение «Стол заказов».

Это значит: на controller'е кооператива выполнена миграция
`marketplaceBootstrapV4Migration` (9 базовых категорий + базовые
ACL-роли), расширение `extension_name: market` зарегистрировано в
workspace-конфиге, frontend подключил роуты `/market/*` и
`/market-pvz/*`. То есть **L1-онбординг** ([«Подключение ЦПП
кооперативом»][l1]) уже пройден.

### «Другие кооперативы с расширением «Стол заказов»»

Здесь будет список controller'ов **других** кооперативов, которые тоже
установили это расширение. Реестр строится из платформенного сервиса
`ecosystem_registry` — общего справочника подключений к coopenomics.

В MVP справочник ещё не активен; вместо списка — информационная иконка
и текст:

> Межкооперативная торговля включится позже.

!!!info "Зачем это нужно"
    Когда `ecosystem_registry` подключится, председатель сможет:

    - Видеть актуальный список «братских» кооперативов с витриной
      Стола заказов.
    - Заключать межкооперативные договоры — например, чтобы пайщики
      одного кооператива могли закупаться в другом.
    - Маршрутизировать предложения, которые есть в одном кооперативе,
      но требуют доставки в ПВЗ другого.

    Это активирует **межкооперативную торговлю** (вторая фаза проекта),
    выходящую за рамки текущего MVP.

## Кому открыт раздел

`roles: ['chairman', 'member']` — председателю кооператива и членам
совета. Пайщикам не виден.

## Источник истины

После активации `ecosystem_registry` страница не будет хранить состояние
у себя — каждый рендер она запросит платформенный API
(`AR18: ecosystem read API`) и покажет актуальный snapshot. На текущем
этапе MVP backend marketplace ничего не отправляет в эту страницу;
карточка «Текущий кооператив» собирается из локального
controller-конфига.
