# Экосистема

Страница «Экосистема» показывает кооперативы сети, которые подключили Стол заказов. Межкооперативная торговля между ними включится позже.

![Экосистема](/assets/new/marketplace/chairman/ecosystem/01-ecosystem.png)

Блок «Текущий кооператив» подтверждает, что кооператив установил приложение. Блок «Другие кооперативы» перечислит соседние кооперативы с приложением, когда они подключатся. Пока он пуст.
