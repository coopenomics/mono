# Стол председателя ПВЗ — список пунктов выдачи

Раздел «ПВЗ Стола заказов» показывает все пункты выдачи (кооперативные участки) кооператива — их адреса, статус и положение на карте.

## Список ПВЗ

![Список ПВЗ: карточки участков с кодом, адресом и статусом; справа — панель карты](/assets/new/marketplace/chairman/branches/01-pvz-list.png)

Каждый ПВЗ — карточка с кодом участка (например, `krg`), адресом и значком статуса **«Активен»**. Действия на карточке: **«Изменить»**, **«Геокодинг»** (пересчитать координаты по адресу) и **«Деактивировать»**. Справа — карта Яндекса с расположением пунктов.

!!!note "Геокодинг и точки на карте"
    Карта подключается ключом картографического сервиса (`YANDEX_MAPS_API_KEY`). Сама карта отображается всегда, а пункт появляется на ней точкой-плейсмарком только после успешного геокодинга его адреса. Пока координаты участка не определены, под адресом видна пометка «Координаты не определены — повторите позже»; кнопка **«Геокодинг»** запускает пересчёт адреса в координаты.
