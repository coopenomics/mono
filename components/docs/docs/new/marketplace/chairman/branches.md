# Сеть ПВЗ

**Сеть пунктов выдачи** (Сеть ПВЗ) — это набор кооперативных участков, на которые поставщики могут привозить партии, а заказчики — приходить за имуществом. Председатель кооператива ведёт эту сеть в отдельной странице **Кооперативные участки** (раздел «Настройки» в Столе председателя).

## Что в реестре

Каждая запись — кооперативный участок (КУ, он же ПВЗ):

- **Краткое название** (например, «КУ Красногорск») и полное юридическое наименование.
- **Председатель участка** — пайщик, у которого роль `trustee` для этого КУ. Это контактное лицо, главный подписант (закрывающая подпись акта приёмки, открытие выдачи, обработка возвратов).
- **Доверенные лица** (`trusted[]`) — пайщики, которым председатель участка делегирует часть полномочий. На MVP — read-only по складу + потоку заказов.
- **Адрес и контакты** — физический адрес ПВЗ, телефон, email.
- **Геокоординаты** (lat, lng) — для отображения на карте кооператива.
- **Реквизиты** — банковский счёт для расчётов с поставщиками и пайщиками, юридические реквизиты.

## Создание нового КУ

В типовом сценарии на MVP **создание участка проходит вне цифровой системы**:

1. На совете кооператива принимается решение о новом участке.
2. Юридически регистрируется (либо как филиал, либо как отдельное юр.лицо в составе кооператива).
3. Открывается банковский счёт.
4. Только после этого председатель **добавляет КУ в цифровую систему** через эту страницу.

Это сделано для того, чтобы цифровой реестр всегда соответствовал реальности — кооператив не «играет в участки» в системе, не имея их фактически.

## Кнопка «Добавить участок»

В шапке таблицы — кнопка «Добавить участок». Открывает форму:

1. **Имя аккаунта участка** (`braname`) — короткий уникальный идентификатор, в EOSIO-нотации (3–12 символов латиницы): например, `krg`, `odn`, `myt`.
2. **Председатель участка** — выбор через автокомплит по пайщикам (UserSearchSelector). Нужно ввести username или ФИО, выбрать из списка.
3. **Наименование участка** — короткое, для каталога ПВЗ.
4. **Контакты** — телефон, email участка.
5. **Адрес** — физический адрес.
6. **Документ-основание** — обязательное поле, текст со ссылкой на решение совета («решение собрания совета №СС-1 от 20 мая 2026 г.»).

После нажатия «Создать» председатель кооператива своим ключом запускает on-chain действие `branch::createbranch`. Это атомарно создаёт on-chain аккаунт ПВЗ, регистрирует трасти и связывает участок с кооперативом.

## Управление существующим КУ

Кликнув по строке участка, председатель видит:

- **Карточка КУ** — все реквизиты.
- **Карточка счёта** — банковские реквизиты участка.
- **Карточка председателя** — read-only данные текущего trustee.
- **Доверенные лица** — добавить / удалить пайщика как `trusted`.
- **Удалить участок** — только если у участка нет активных Заказов и складских остатков (защита от случайного удаления).

## Карта ПВЗ

На главной странице раздела доступна **карта сети** — все КУ на интерактивной карте через геокоординаты. Полезно для:

- Пайщика, который выбирает ПВЗ при оформлении Заказа — он видит, какой ближе.
- Поставщика, который планирует логистику — на какие ПВЗ ему ехать.
- Совета — общая картина территориального покрытия кооператива.
