# Стол председателя ПВЗ — список пунктов выдачи

Раздел «ПВЗ Стола заказов» показывает все пункты выдачи (кооперативные участки) кооператива — их адреса, статус и положение на карте.

## Список ПВЗ

![Список ПВЗ: карточки участков с кодом, адресом и статусом; справа — панель карты](/assets/new/marketplace/chairman/branches/01-pvz-list.png)

Каждый ПВЗ — карточка с кодом участка (например, `krg`), адресом и значком статуса **«Активен»**. Действия на карточке: **«Изменить»**, **«Геокодинг»** (пересчитать координаты по адресу) и **«Деактивировать»**. Справа — панель карты с расположением пунктов.

!!!note "Карта и геокодинг в этой среде"
    На локальном стенде геокодинг и карта отключены (нет ключа картографического сервиса), поэтому вместо карты показывается заглушка, а у участков — пометка об отключённом геокодинге. В рабочей среде с заданным ключом адреса автоматически разворачиваются в точки на карте.
