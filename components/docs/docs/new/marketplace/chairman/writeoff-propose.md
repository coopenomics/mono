# Списания скоропорта — admin-стол председателя

Раздел `/<coopname>/market/writeoffs` (Story 8.7) — рабочее место
председателя по проектам списания **скоропорта**: имущества с истекающим
сроком годности, которое необходимо снять с баланса кооператива до
истечения. Доступ в access-matrix — `roles: ['chairman', 'member']`;
обычный пайщик пункт не видит.

## Как устроен процесс списания

Под заголовком — серая пояснительная строка, дублирующая регламент:

> Сначала собирается черновик списания (вручную или автоматически
> крон-сервисом). Затем председатель подписывает **Заявление 1106**
> и отправляет проект в совет. Совет голосует через свою повестку и
> подписывает **Протокол 1105** — backend сам атомарно списывает
> позиции через пары **`o.mkt.wroff`** + **`o.mkt.wroff2`**.

Это полный жизненный цикл проекта списания:

1. **Сбор черновика.** Председатель открывает новый черновик через
   кнопку **«+ Новый черновик»** (правый верх) или ждёт, пока внутренний
   крон-сервис (`@coopenomics/boot` -> mkt cron) сам не подберёт
   позиции с истекающим сроком и не создаст proposal автоматически.
2. **Подпись 1106.** Председатель подписывает **Заявление о списании
   (registry_id=1106)** своей ЭП. После подписи backend дёргает
   action `propwroff` контракта marketplace.
3. **Повестка совета.** `propwroff` создаёт повестку через
   `soviet::createagenda(type=mktwroff)`. Совет видит проект в своём
   столе, голосует обычным `sov.decision` flow.
4. **Подпись 1105.** Положительное решение совета подписывается
   **Протоколом 1105**, в backend срабатывает action `execwroff`.
5. **Per-item списание.** Backend атомарным циклом проходит по
   позициям проекта и для каждой выполняет **пару действий**:
   `o.mkt.wroff` (списание со склада участка) + `o.mkt.wroff2`
   (списание в кооперативной книге). Атомарность гарантирована —
   откат любой позиции откатывает весь проект.

!!!warning "Зачем 1106 и 1105 — два документа"
    Списание имущества — это финансовая операция, затрагивающая баланс
    кооператива. Закон требует **подпись председателя** (заявление 1106
    как инициатива) и **решение совета** (протокол 1105 как
    коллегиальное одобрение). Один документ или одна подпись
    юридически недостаточны.

## Блоки страницы

### Карточка «В работе совета»

Сводная карточка с двумя счётчиками:

- **0 проект(ов)** — сколько проектов сейчас в повестке совета;
- **на сумму 0.00 ₽** — общая стоимость списываемого имущества по
  всем активным проектам в валюте кооператива.

В пустом состоянии — нули, как на скриншоте.

### Список активных проектов

Под карточкой — лента активных проектов списания (статусы «черновик»,
«подписан председателем», «в повестке совета», «в голосовании»). На
свежем стенде — плейсхолдер:

> Нет проектов на повестке. Откройте новый черновик или дождитесь,
> пока крон-сервис подберёт скоропорт.

### Архив

Блок **«Архив»** — закрытые проекты: исполненные (списание завершено
через `execwroff`), отклонённые советом, отозванные председателем.
Сейчас — **«Архив пуст.»**
