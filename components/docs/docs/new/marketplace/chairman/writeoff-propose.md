# Списания имущества

Если на складе участка скопилось имущество, которое нельзя выдать пайщикам (просрочено, испорчено, не востребовано), оно должно быть **списано**. Это финансовая операция, которая требует решения совета. Председатель кооператива инициирует её через страницу **Списания**.

## Когда нужно списание

Типовые сценарии для списания:

- **Просроченный товар** — продукты с истёкшим сроком годности.
- **Возвращённое имущество** — товар, который пайщик вернул как дефектный; кооператив не может его перепродать.
- **Невостребованные Заказы** — пайщик не пришёл за Заказом, прошёл срок хранения, имущество не имеет смысла держать.
- **Утрата при инвентаризации** — фактически отсутствует на складе по разным причинам.

В каждом случае имущество физически вычеркивается из реестра кооператива, и сумма списания идёт на счёт «Прочие расходы».

## Подготовка предложения

Списание начинается с **предложения совету**. Председатель открывает страницу «Списания», нажимает «Создать предложение». В форме:

1. **Перечень имущества** — единицы со склада с их штрих-кодами, заказчиками-владельцами (для возвращённых) и фактической стоимостью.
2. **Причина списания** — текстовое описание (до 2000 знаков): что случилось, почему имущество не может быть выдано / перепродано.
3. **Фотографии** — состояние имущества на момент списания (если применимо).
4. **Итоговая сумма** — рассчитывается автоматически из стоимостей единиц.

После сохранения формируется **проект решения совета о списании** — стандартный документ из реестра с подставленными данными.

## Подача на совет

Председатель нажимает «Отправить на совет». Это запускает стандартный механизм повестки:

- Документ-предложение появляется в текущей или ближайшей повестке совета как пункт «Списание имущества».
- Члены совета (видят в [Голосовании по списанию][vote]) знакомятся с предложением и голосуют.

## Что после решения совета

- **Совет принял**: предложение исполняется атомарной транзакцией:
    - Единицы имущества помечаются как `WRITTEN_OFF` в реестре участка.
    - Сумма списания списывается с накопителя на счёт «Прочие расходы» — это операция ledger2 на стороне Коопеномика.
    - Председатель и оператор участка получают push «Списание исполнено».
- **Совет отклонил**: предложение возвращается председателю с комментарием. Имущество остаётся в реестре (но в статусе «proposed for write-off»). Председатель может скорректировать и подать новое предложение, либо вернуть имущество в обычный оборот.

## Как пайщик это видит

Если пайщик-владелец возвращённого имущества жив в кооперативе, в его карточке возврата отображается финальный шаг: «Имущество списано по решению совета №X от {дата}». Это закрывает историю возврата.
