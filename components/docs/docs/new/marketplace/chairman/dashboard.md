# Стол председателя ПК — обзор разделов

Председатель ПК входит на платформу со своим e-mail и приватным ключом. Сразу после входа открывается **Стол председателя** — рабочее место, через которое председатель управляет кооперативом: подписывает решения, добавляет ПВЗ и членов совета, настраивает программу платежей и интеграции.

!!!info "Кому подойдёт эта инструкция"
    Председателю потребительского кооператива, который входит в платформу впервые или хочет освежить в памяти, где какой раздел.

## Шаг 1. Главный экран — онбординг

![Стол председателя сразу после входа: меню слева, чек-лист онбординга справа](/assets/new/marketplace/chairman/dashboard/00-after-login.png)

Сразу после клика «Войти» председатель попадает на экран **«Адаптируйте кооператив к работе на платформе»**. Это пошаговый чек-лист первичной настройки:

1. Утверждение соглашения о ЦПП «Цифровой Кошелёк»
2. Утверждение положения о простой электронной подписи
3. Утверждение политики конфиденциальности
4. Утверждение пользовательского соглашения
5. Утверждение форм заявлений на вступление
6. О вступлении в ПК «Восход»
7. Импорт пайщиков (загрузка CSV-файла)
8. Объявить общее собрание

Каждый шаг можно открыть, заполнить и подписать. Сверху виден таймер до конца льготного периода адаптации.

Слева — постоянная навигация по разделам Стола председателя: Онбординг, Запросы одобрений, Магазин приложений, Стартовые страницы, Члены совета, Кооперативные Участки, Регистрационные взносы, Ключ кооператива, Провайдер платежей, Контакты кооператива. Внизу — карточка председателя с балансом «0,00 RUB» и кнопкой «Выйти».

## Шаг 2. Онбординг (повторно)

![Тот же экран онбординга — отдельный раздел меню](/assets/new/marketplace/chairman/dashboard/01-onboarding.png)

Раздел «Онбординг» — стартовая страница Стола председателя. Сюда фронт перенаправляет сразу после входа, пока чек-лист не пройден до конца. Когда все 8 шагов отмечены — раздел переходит в режим «выполнено», и можно убрать пункт из меню через раздел «Стартовые страницы» (см. шаг 5).

## Шаг 3. Запросы одобрений

![Лента входящих действий, ожидающих подписи председателя](/assets/new/marketplace/chairman/dashboard/02-approvals.png)

В разделе **«Запросы одобрений»** собираются действия пайщиков, для которых регламент требует предварительной подписи председателя:
- передача доли,
- открытие проекта на капитализацию,
- выпуск регистрационного билета,
- и другие действия из контракта `soviet`.

Колонки таблицы: «Пользователь», «Действие», «Статус», «Дата создания», «Действия». Сверху — фильтр «Статус: Ожидает». Если очередь пуста — фронт показывает плашку «У председателя нет запросов предварительных одобрений».

## Шаг 4. Магазин приложений

![Карточки доступных расширений: Стол Совета, Благорост, Стол Председателя, Стол Уполномоченного, Стол Пайщика и т. д.](/assets/new/marketplace/chairman/dashboard/03-extensions.png)

**«Магазин приложений»** — витрина расширений, которые можно установить в кооператив:
- **Стол Совета** — управление решениями и собраниями совета.
- **Благорост** — программа капитализации РИД.
- **Стол Председателя** — функции, доступные только председателю кооператива.
- **Стол Уполномоченного** — рабочее место уполномоченного председателя ПВЗ.
- **Стол Пайщика** — личный кабинет пайщика.
- **Стол вычислительных ресурсов** — биллинг ресурсов кооператива.
- **YOOKASSA**, **SBERKASSA** — провайдеры платежей.

Клик по карточке открывает страницу расширения с инструкцией по установке и настройкой прав. После установки расширения у соответствующих ролей появляются новые пункты меню.

!!!note "Стол заказов входит в стандартный пакет"
    Расширение «Стол заказов» (marketplace) — отдельный модуль; см. инструкцию [«Разделы Стола заказов»](./market-tour.md).

## Шаг 5. Стартовые страницы

![Настройка маршрутов после входа для каждой роли](/assets/new/marketplace/chairman/dashboard/04-system-settings.png)

Раздел **«Стартовые страницы»** позволяет назначить каждой роли — председателю, члену совета, оператору ПВЗ, пайщику — свой первый экран после входа. По умолчанию для председателя — «Онбординг», для пайщика — «Кошелёк», для оператора ПВЗ — «Выдача заказов».

Здесь же можно скрыть «Онбординг» из меню, когда чек-лист пройден.

## Шаг 6. Члены совета

![Реестр членов совета](/assets/new/marketplace/chairman/dashboard/05-members.png)

Раздел **«Члены совета»** содержит список действующих членов совета кооператива и их роли. Председатель может добавить или удалить члена совета, а также инициировать ротацию подписей.

## Шаг 7. Кооперативные участки (ПВЗ)

![Реестр ПВЗ кооператива](/assets/new/marketplace/chairman/dashboard/06-branches.png)

В разделе **«Кооперативные Участки»** председатель видит реестр ПВЗ — юридически оформленных подразделений кооператива, в которых работают свои председатели участков и доверенные лица.

Заголовок страницы:

> Создание кооперативных участков сейчас происходит за пределами цифровой системы. Здесь добавляются уже созданные и юридически оформленные участки с их председателями.
>
> При добавлении трёх участков кооператив автоматически переходит на мажоритарную систему управления. Действующим пайщикам будет предложено выбрать участок и делегировать голос его председателю. Новые пайщики делают выбор при регистрации.

Колонки таблицы: «Название», «Председатель». Кнопка «**+ Добавить участок**» открывает форму создания. Если таблица пуста — отображается значок «Нет данных».

!!!warning "Связь с MVP «Стол заказов»"
    Без хотя бы одного ПВЗ Стол заказов работать не будет: каждый заказ должен быть привязан к пункту выдачи.

## Шаг 8. Регистрационные взносы

![Настройка тарифов вступления и членских взносов](/assets/new/marketplace/chairman/dashboard/07-register-payments.png)

Раздел **«Регистрационные взносы»** — здесь председатель задаёт размеры вступительного и минимального членского взносов, ставит частоту списания минимального и привязывает их к программам (Кошелёк, Marketplace, Благорост). Поля синхронизируются с контрактом `soviet`.

## Шаг 9. Ключ кооператива

![Управление ключом active@coopname](/assets/new/marketplace/chairman/dashboard/08-cooperative-key.png)

В разделе **«Ключ кооператива»** председатель управляет ключом `active@<coopname>` — это ключ, которым подписываются все системные действия кооператива (приём пайщиков, утверждение решений, выплаты). Здесь же показывается публичный ключ и время последней ротации.

!!!danger "Ротируйте ключ при компрометации"
    Ключ кооператива — это master-credential, его утрата делает весь кооператив уязвимым. Меняйте его регулярно и храните в безопасном месте.

## Шаг 10. Провайдер платежей

![Настройка провайдера приёма платежей (YooKassa, СберКасса и др.)](/assets/new/marketplace/chairman/dashboard/09-payment-provider.png)

Раздел **«Провайдер платежей»** позволяет привязать к кооперативу платёжный шлюз — YooKassa, СберКасса или другой провайдер из магазина приложений. Поля: API-ключ, secret, webhook URL, валюта.

## Шаг 11. Контакты кооператива

![Юридические реквизиты и контакты для писем](/assets/new/marketplace/chairman/dashboard/10-contacts.png)

Раздел **«Контакты кооператива»** содержит юридические реквизиты для писем, счетов, регистрации заявлений: полное и краткое наименование, ИНН/ОГРН, почтовый и фактический адрес, телефон, e-mail, банковские реквизиты. Эти поля попадают в шапки PDF-документов, которые подписывает председатель.
