# Стол администратора целиком

Стол администратора Стола заказов открыт председателю кооператива. Члены совета видят его только для чтения. Страница показывает все разделы стола на одном примере.

![Реестр заказов](/assets/new/marketplace/chairman/market-tour/01-orders.png)

Раздел «Реестр заказов» показывает все заказы кооператива с состояниями. Заказ открывается с документами, операциями и проводками.

![Реестр поставщиков](/assets/new/marketplace/chairman/market-tour/02-suppliers.png)

Раздел «Реестр поставщиков» показывает поставщиков с моделью участия, договором и состоянием. Заявку пайщика одобряет председатель, администратор добавляет поставщика напрямую.

![Реестр предложений](/assets/new/marketplace/chairman/market-tour/03-offers.png)

Раздел «Реестр предложений» показывает предложения поставщиков в любом состоянии. Подробно на странице [«Реестр предложений»](../admin/offers-registry.md).

![Модерация](/assets/new/marketplace/chairman/market-tour/04-moderation.png)

Раздел «Модерация» показывает очередь предложений на решение. После одобрения предложение появляется в каталоге.

![Экономика](/assets/new/marketplace/chairman/market-tour/05-economy.png)

Раздел «Экономика» задаёт целевой членский взнос в процентах. Он добавляется к стоимости каждого заказа и после исполнения распределяется участку выдачи. Ниже оборот за период по позициям и пунктам выдачи.

![Доступные категории](/assets/new/marketplace/chairman/market-tour/06-categories.png)

Раздел «Доступные категории» задаёт категории для предложений поставщиков. Базовые категории выключаются, своя категория добавляется.

![Пункты выдачи заказов](/assets/new/marketplace/chairman/market-tour/07-issuance-points.png)

Раздел «Пункты выдачи заказов» делает кооперативные участки пунктами выдачи. Здесь адрес, контакты и режим работы, адрес геокодируется для карты.

![Списания скоропорта](/assets/new/marketplace/chairman/market-tour/08-writeoffs.png)

Раздел «Списания скоропорта» собирает имущество к списанию со складов. Заявление одной кнопкой уходит в повестку совета, после протокола оператор подтверждает выбытие.

![Склад](/assets/new/marketplace/chairman/market-tour/09-warehouse-summary.png)

Раздел «Склад» показывает принятое, выданное и списанное по каждому пункту выдачи. Только для чтения, операции идут на столах пунктов выдачи.

![Выплаты поставщикам](/assets/new/marketplace/chairman/market-tour/10-payouts.png)

Раздел «Выплаты поставщикам» показывает ленту выплат по закрытым актам приёмки. Подтверждает выплаты кассир в реестре платежей.

![Экосистема](/assets/new/marketplace/chairman/market-tour/11-ecosystem.png)

Раздел «Экосистема» перечислит кооперативы сети с приложением, когда включится межкооперативная торговля.
