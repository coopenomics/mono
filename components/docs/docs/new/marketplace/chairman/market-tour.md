# Разделы Стола заказов — экскурсия для председателя

Эта инструкция — обзорная карта **Стола заказов** (marketplace) с точки зрения председателя кооператива. Здесь не описаны бизнес-сценарии (создание заказа, выдача товара, возврат) — для них есть отдельные роль-ориентированные инструкции. Цель раздела — показать, где какая страница находится и за что отвечает.

!!!info "URL-конвенция"
    Все маршруты Стола заказов находятся под `#/<coopname>/market/*` для общих разделов и `#/<coopname>/market-pvz/*` для разделов оператора ПВЗ. В наших скриншотах `<coopname>=voskhod`.

## 1. Каталог Стола заказов

![Главная страница каталога с фильтрами и сортировкой](/assets/new/marketplace/chairman/market-tour/01-catalog.png)

**Каталог** — витрина активных предложений товаров и услуг кооператива. Сверху — переключатель «Все 0» (бэйдж считает число активных предложений), справа — сортировка («Свежие сначала»). На пустом каталоге фронт показывает «Ничего не найдено. В каталоге пока нет активных предложений».

Сюда заказчики приходят, чтобы выбрать и оформить заказ. Каждое предложение — карточка с фото, ценой, доступным количеством и кнопкой «Заказать».

## 2. Создать предложение

![Форма «Новое предложение» с полями товара и параметрами цикла](/assets/new/marketplace/chairman/market-tour/02-create-offer.png)

Раздел **«Создать предложение»** — форма, которой пользуется поставщик (председатель ПВЗ, доверенное лицо или сам кооператив). Поля:

- **Название товара** (обязательно)
- **Описание**
- **Категория** (обязательно) — выбирается из справочника
- **Цена за единицу** (обязательно, до 4 знаков после запятой)
- **Единица** — шт., кг, м и т. п.
- **Доступное количество** или переключатель «Без ограничения по количеству»
- **Гарантия (дней)**
- **Тип отсечки заказов**:
    - **По расписанию** (`time_based`) — поставка по истечении цикла
    - **По объёму** (`volume_based`)
    - **Открытая подписка** (`open_subscription`)
    - **Индивидуально** (`individual`)
- **Длительность цикла (дней)**
- **Минимальный порог объёма** (опциональный, для `volume_based`)

После заполнения предложение уходит в каталог и становится видно всем пайщикам кооператива.

## 3. Мои заказы

![Лента заказов председателя как заказчика](/assets/new/marketplace/chairman/market-tour/03-my-orders.png)

**«Мои заказы»** — лента всех заказов, которые председатель оформил как заказчик. Здесь видно статус каждого заказа: ожидает оплаты, в работе у поставщика, готов к выдаче, выдан, возвращён.

## 4. Готовые к выдаче

![Список заказов, доставленных в ПВЗ и ждущих получения](/assets/new/marketplace/chairman/market-tour/04-ready-to-receive.png)

Раздел **«Готовые к выдаче»** показывает заказы со статусом `READY_TO_RECEIVE` — товар уже на ПВЗ и ждёт, пока заказчик его заберёт. Эта страница — визуальное продолжение push-уведомления `marketplace-order-ready`.

## 5. Возвраты

![Заявки на возврат товара от заказчиков](/assets/new/marketplace/chairman/market-tour/05-returns.png)

Раздел **«Возвраты»** — лента заявок на возврат, которые заказчики оформили после получения товара. Председатель видит причину возврата и может одобрить/отклонить заявку (или передать обработку оператору ПВЗ).

## 6. Списания скоропорта

![Управление черновиками списания: проект → совет → атомарное списание](/assets/new/marketplace/chairman/market-tour/06-writeoffs.png)

**«Списания скоропорта»** — раздел для управления списанием товаров с истёкшим сроком годности или повреждённых при хранении.

Описание процесса (из текста на странице):

> Сначала собирается черновик списания (вручную или автоматически крон-сервисом). Затем председатель подписывает Заявление 1106 и отправляет проект в совет. Совет голосует через свою повестку и подписывает Протокол 1105 — backend сам атомарно списывает позиции через пары `o.mkt.wroff` + `o.mkt.wroff2`.

Структура:
- **«В работе совета»** — карточка с числом проектов и их общей суммой.
- **Лента активных проектов** (плейсхолдер «Нет проектов на повестке. Откройте новый черновик или дождитесь, пока крон-сервис подберёт скоропорт»).
- **Архив** — закрытые проекты (плейсхолдер «Архив пуст»).
- Кнопка **«+ Новый черновик»** в правом верхнем углу запускает форму ручного создания списания.

## 7. Склад: сводка

![Сводный остаток товаров по всем ПВЗ](/assets/new/marketplace/chairman/market-tour/07-warehouse-summary.png)

**«Склад: сводка»** — агрегированный остаток товаров по всем ПВЗ кооператива. Председатель видит, где какой товар лежит и в каком количестве. Этот раздел используется для планирования логистики между ПВЗ.

## 8. Реестр экосистемы

![Текущий кооператив и список других кооперативов с расширением «Стол заказов»](/assets/new/marketplace/chairman/market-tour/08-ecosystem.png)

Раздел **«Реестр экосистемы»** показывает:

- **Текущий кооператив** (карточка `voskhod установил расширение «Стол заказов»`).
- **Другие кооперативы** с тем же расширением — для будущей межкооперативной торговли.

Сейчас работает только локально внутри одного кооператива (плашка «**Межкооперативная торговля включится позже.**»).

## 9. Пункты выдачи

![Список ПВЗ кооператива](/assets/new/marketplace/chairman/market-tour/09-pvz-list.png)

**«Пункты выдачи»** (`/market-pvz/list`) — список всех ПВЗ с их названиями, адресами и операторами. Тот же реестр виден в Столе председателя в разделе «Кооперативные Участки», но здесь — с маркетплейсной точки зрения (с фокусом на работу с заказами, а не на юр-управление).

## 10. Выдача заказов на ПВЗ

![Реестр товаров на пункте выдачи, готовых к передаче заказчику](/assets/new/marketplace/chairman/market-tour/10-pvz-issuance.png)

Раздел **«Выдача заказов»** — рабочее место оператора ПВЗ: список товаров, ждущих передачи заказчику. Каждая строка — заказ с пометкой статуса, ФИО заказчика и кнопкой «Выдать» (с подтверждением подписи).

## 11. Возвраты на ПВЗ

![Обработка возвратов оператором пункта выдачи](/assets/new/marketplace/chairman/market-tour/11-pvz-returns.png)

**«Возвраты на ПВЗ»** — обратная сторона раздела «Возвраты» (шаг 5): здесь оператор ПВЗ принимает товар обратно, ставит причину, фотографирует упаковку и закрывает заявку.

## 12. Склад ПВЗ

![Остаток товаров у конкретного пункта выдачи](/assets/new/marketplace/chairman/market-tour/12-pvz-warehouse.png)

**«Склад ПВЗ»** — остаток товаров у конкретного пункта выдачи. По сравнению с «Складом: сводка» (шаг 7) — здесь только свой ПВЗ. Оператор использует этот экран, чтобы провести инвентаризацию.
