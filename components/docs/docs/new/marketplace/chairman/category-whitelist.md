# Кооперативные категории

!!!info "Реализовано"
    Страница `/market/category-whitelist` реализована (коммит `50538b45d43`). Председатель видит whitelist разрешённых категорий с stat-карточками; пустой whitelist означает, что доступен весь глобальный каталог. Backend готов — `available-category-admin.resolver.ts` (@AuthRoles chairman). В MVP добавление через ручной ввод ID; tree-выбор через `marketplaceGetCategoryTree` подключится на следующем шаге Story 3.x.

![Whitelist категорий: stat-карточки и пустой список](/assets/new/marketplace/chairman/category-whitelist/01-overview.png)

![Диалог добавления категорий по ID](/assets/new/marketplace/chairman/category-whitelist/02-add-dialog.png)

Стол заказов работает с фиксированным набором из **10 кооперативных категорий**. Они едины для всей кооперативной сети, но каждый кооператив сам решает, **какие из них включены** в его Столе.

## Полный набор

| Категория | Примеры |
|---|---|
| Овощи и фрукты | картофель, морковь, яблоки |
| Молочные | молоко, сыр, йогурт |
| Мясо | говядина, свинина, птица |
| Рыба | свежая, мороженая, копчёная |
| Хлеб | свежий хлеб, выпечка, лаваш |
| Бакалея | крупы, мука, сахар, соль |
| Напитки | соки, морсы, минеральная вода |
| Готовая еда | замороженные блюда, заготовки |
| Услуги | мастер на час, доставка, уборка |
| Прочие | непродовольственные товары |

Этот список зафиксирован на уровне платформы и не расширяется индивидуальными кооперативами. Это нужно для:

- Унификации каталогов по сети кооперативов.
- Простоты статистики и налогового учёта.
- Прозрачности для пайщика, который переходит из кооператива в кооператив.

## Whitelist кооператива

Председатель открывает страницу **Категории ЦПП** и видит чекбоксы по всем 10 категориям. Включённые — это те, в которых можно публиковать Предложения и оформлять Заказы; выключенные — недоступны.

Включение / выключение — мгновенно, не требует решения совета (это техническая настройка, не юридическая).

Однако есть **защитные правила**:

- Нельзя выключить категорию, если в ней есть **активные Предложения** или **активные Заказы**. Сначала нужно дождаться, пока Предложения закроют цикл / отзовутся, а Заказы — завершатся.
- При выключении категории, в которой ещё есть готовые-к-выдаче Заказы, председатель получает предупреждение со списком этих Заказов.

## Зачем выключать категории

Типовые сценарии:

- **Сезонность** — кооператив временно убирает «Овощи и фрукты», пока местные поставщики не вышли из отпусков.
- **Юридические ограничения** — кооператив выключает «Мясо» / «Рыба», потому что нет сертификации.
- **Тестовый запуск** — на старте Стол заказов включают только в одной категории («Бакалея»), отрабатывают процессы, потом добавляют остальные.

## Что после изменения

После включения / выключения категории:

- Поставщики видят соответствующее изменение в форме [Создания предложения][offer-create] (категории-чипы).
- В [каталоге][catalog] обновляются фильтры — пайщик не увидит выключенные категории в фильтре.
