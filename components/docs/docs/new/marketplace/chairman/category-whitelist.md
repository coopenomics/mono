# Доступные категории товаров кооператива

Председатель может ограничить, какие категории товаров пайщики вправе публиковать в каталоге. Это «белый список» категорий: пока он пуст — доступен весь глобальный каталог; как только в него добавлена хотя бы одна категория — публиковать можно только из неё.

## Обзор

![Страница «Доступные категории»: счётчики и пустой белый список](/assets/new/marketplace/chairman/category-whitelist/01-overview.png)

В шапке — счётчики: **Всего записей**, **Категорий**, **Типов товаров** и индикатор **«Whitelist активен»**. Пустой список показывает состояние **«Нет (открыт каталог)»** и подсказку: пайщикам доступен весь глобальный каталог. Чтобы ограничить — нажать **«Добавить»**.

## Добавление категории

![Диалог добавления категорий в белый список](/assets/new/marketplace/chairman/category-whitelist/02-add-dialog.png)

Диалог добавления позволяет указать категории, которые войдут в белый список. После сохранения каталог для пайщиков сузится до выбранных категорий и их типов товаров.
