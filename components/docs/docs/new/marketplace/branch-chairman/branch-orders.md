# Заказы участка

!!!warning "Эпик 6 — в разработке"
    Сводная лента «Заказы участка» для председателя КУ ещё не реализована в UI: председатель пока пользуется лентой оператора и фильтрами в `OperatorIssuancePage`. Описание ниже отражает целевое UX «всё про мой ПВЗ на одной странице», которое появится после завершения Эпика 6.

Лента **Заказы участка** даёт председателю общую картину всего, что происходит с Заказами на его ПВЗ. Это сводный обзор, более широкий, чем оператор видит в своих специализированных лентах.

## Что показывает

Каждая строка — Заказ, привязанный к этому участку:

- Заказчик (ФИО, контакт).
- Поставщик и Предложение.
- Текущий статус (от NEW до RECEIVED, RETURNED, WRITTEN_OFF — см. [Жизненный цикл Заказа][orders]).
- Сумма и количество.
- Ключевые даты: создание Заказа, прибытие на ПВЗ, выдача пайщику.

## Зачем председателю это видеть

В типовой день председатель смотрит ленту, чтобы:

1. **Понять загруженность участка** — сколько Заказов в работе, какие узкие места.
2. **Найти задерживающиеся Заказы** — кто принят на ПВЗ давно, но не выдан пайщику. Возможно, нужно лично связаться с пайщиком.
3. **Отследить инциденты** — Заказы с категорией DECLINED, RETURN_REQUESTED, CYCLE_EXPIRED — чтобы понять, не повторяются ли проблемы у одного поставщика, у одного типа имущества, у одного времени года.

## Фильтры и группировки

- **По статусу** — увидеть только активные / только проблемные.
- **По поставщику** — посмотреть, как идут дела у конкретного партнёра.
- **По дате** — лента за день, неделю, месяц.
- **По заказчику** — найти все Заказы конкретного пайщика.

## Действия из ленты

В отличие от ленты оператора, здесь председатель не выдаёт имущество физически. Зато может:

- **Открыть выдачу** для Заказа, если оператор по какой-то причине не справляется (председатель может сам поставить первую подпись акта выдачи).
- **Связаться с пайщиком** — кнопка «Сообщение пайщику» (открывает чат-канал через системы кооператива).
- **Подать на списание** — если имущество просрочено / физически отсутствует.
