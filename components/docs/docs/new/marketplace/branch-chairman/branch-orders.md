# Сводный стол кооперативного участка

«Сводный стол КУ» собирает в одном месте все процессы участка: приёмки партий от поставщиков, выдачи пайщикам и гарантийные возвраты. Это обзорная панель председателя участка.

## Выбор участка

![Сводный стол до ввода кода: поле «ID кооперативного участка» и подсказка](/assets/new/marketplace/branch-chairman/branch-orders/01-empty-input.png)

Чтобы загрузить данные, председатель вводит **код своего участка** (например, `krg`) и нажимает **«Загрузить»**.

## Три ленты процессов

![После загрузки: вкладки «Приёмки», «Выдачи», «Возвраты» со счётчиками](/assets/new/marketplace/branch-chairman/branch-orders/02-loaded-tabs.png)

После загрузки появляются три вкладки со счётчиками: **Приёмки**, **Выдачи** и **Возвраты**. Каждая показывает активные элементы своего процесса; для действий председатель переходит на специализированные столы Стола ПВЗ. Когда активных элементов нет, вкладка показывает пустое сообщение (например, «Нет активных приёмок» — партии появятся здесь после подтверждения поставщиком).
