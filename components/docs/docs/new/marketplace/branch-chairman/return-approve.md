# Стол ПВЗ — гарантийные возвраты

Раздел «Гарантийный возврат» — рабочее место председателя участка для рассмотрения заявлений о возврате имущества. Заявления распределены по очередям в зависимости от стадии рассмотрения.

## Очереди заявлений

![Страница возвратов: ввод кода КУ и три секции — удалённое рассмотрение, очный визит, архив](/assets/new/marketplace/branch-chairman/return-approve/01-operator-returns-empty.png)

Вверху — поле **ID кооперативного участка** и кнопка **«Загрузить заявления»**. Ниже — три секции со счётчиками:

- **Ждут удалённого рассмотрения** — заявления, по которым решение можно принять дистанционно;
- **Ожидают очного визита** — требующие осмотра имущества на участке;
- **Архив** — завершённые заявления.

Пока заявлений на возврат нет, каждая секция показывает соответствующее пустое сообщение.
