# Взнос имуществом в участок

Пайщик вносит в кооперативный участок имущество паевым взносом по договору участия в хозяйственной деятельности. Взнос проходит четыре шага. Пайщик подаёт заявление, председатель участка одобряет его, совет принимает решение о приёме, затем стороны подписывают акт приёма-передачи. Взнос ведётся на странице [«Инициаторы участка»](initiators-money.md) стола ПВЗ, раздел «Имущество».

![Окно паевого взноса имуществом](/assets/new/marketplace/branch-chairman/initiators-property/01-property-dialog.png)

Кнопка «Внести имуществом» открывает окно заявления. Пайщик указывает наименование и категорию имущества, описание, гарантийные условия, количество с единицей измерения, цену приёма и срок гарантийных обязательств в днях. Обязательны наименование, описание, количество, единица измерения и цена приёма. Кнопка «Подать заявление» подписывает заявление и направляет его председателю участка.

![Заявление подано](/assets/new/marketplace/branch-chairman/initiators-property/02-property-created.png)

Заявление появляется в разделе «Имущество» на этапе «Заявление подано». Строка показывает имущество, инициатора и цену приёма. Председатель участка одобряет заявление либо отклоняет его. Причина отказа обязательна, после отказа вопрос в совет не выносится.

![Совет принял решение](/assets/new/marketplace/branch-chairman/initiators-property/03-property-approved.png)

После одобрения вопрос о приёме имущества поступает в совет. По решению совета строка переходит на этап «Совет принял решение», и в ней появляется кнопка «Подписать акт». Акт приёма-передачи первым подписывает пайщик, вторую подпись ставит председатель совета.

После обеих подписей имущество принято в участок. Цена приёма задаёт сумму, которую участок возместит инициатору из своей экономии.
