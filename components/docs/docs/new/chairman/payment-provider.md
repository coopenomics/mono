# Провайдер платежей

Провайдер платежей задаёт, как кооператив принимает входящие платежи пайщиков по умолчанию. Через него заводятся паевые взносы из кошелька пайщика и взносы при регистрации.

![Провайдер платежей](/assets/new/chairman/payment-provider/01-page.png)

На кадре выбран банковский платёж по QR-коду. Пайщик получает реквизиты и код для оплаты из любого банковского приложения, кассир подтверждает поступление денег в реестре платежей вручную. Приложения приёма платежей из каталога добавляют в список свои способы. Кнопка «Сохранить» применяет выбор.
