# Ключ кооператива

Ключ кооператива подписывает транзакции кооператива в блокчейне. Пайщики подписывают документы своими ключами, транзакции в цепь отправляет кооператив своим ключом. Ключ хранится на сервере зашифрованным.

![Ключ кооператива](/assets/new/chairman/cooperative-key/01-page.png)

Поле «Приватный ключ» принимает новый ключ взамен текущего. После сохранения ключ скрыт, страница его больше не показывает. Обновление нужно при смене ключа у аккаунта кооператива или при восстановлении доступа.
