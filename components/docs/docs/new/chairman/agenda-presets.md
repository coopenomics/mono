# Пресеты предложений

Пресеты предложений собирают документы для типовых вопросов повестки совета. Пресет знает, какой вопрос поставить и какой проект решения приложить, председателю остаётся запустить его.

![Пресеты предложений](/assets/new/chairman/agenda-presets/01-presets.png)

Строка пресета называет вопрос и его суть. На кадре один пресет: утверждение Положения о целевой потребительской программе «Благорост». Кнопка «Сгенерировать» собирает документы предложения и ставит вопрос в повестку совета. Дальше вопрос идёт обычным путём: голоса совета, утверждение председателем, протокол в реестре документов.
