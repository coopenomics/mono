# Управление доступом

Управление доступом назначает пайщикам роли приложений. Роль открывает пайщику страницы и действия приложения. Назначение и снятие действуют сразу, пайщик получает уведомление и видит новые страницы после обновления рабочего стола.

![Роли приложений](/assets/new/chairman/access-roles/01-roles.png)

Роли объявляют приложения кооператива, страница показывает их карточками. Карточка называет роль, приложения, в которых она действует, и её назначение. Блок «Читает» перечисляет, что роль видит, блок «Управляет» — что роль делает. Ниже список пайщиков с этой ролью. На кадре роль «Кассир» стола совета управляет реестром платежей и пока никому не назначена, а роль «Ревизор» читает платежи, документы, реестры и отчётность кооператива без права записи.

![Назначение роли](/assets/new/chairman/access-roles/02-assign.png)

Кнопка «Назначить» открывает окно с выбором пайщика. Пайщик ищется по имени среди пайщиков кооператива.

![Роль назначена](/assets/new/chairman/access-roles/03-assigned.png)

После назначения пайщик появляется в списке держателей роли с датой и автором назначения, счётчик роли растёт. Кнопка «Снять» отзывает роль, пайщик теряет доступ, который она давала.
