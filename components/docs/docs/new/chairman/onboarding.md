# Онбординг

Онбординг ведёт председателя по адаптации кооператива к платформе. Кооператив начинает работу в цифровом контуре после нескольких решений совета, по одному на каждый шаг. Платформа собирает проект повестки для каждого шага и фиксирует принятое решение.

![Онбординг](/assets/new/chairman/onboarding/01-page.png)

Сверху страницы срок адаптации, за это время кооперативу нужно пройти все шаги. Первые шаги утверждают положения о цифровых сервисах и формы документов кооператива: соглашение о программе «Цифровой кошелёк», положение о простой электронной подписи, политику конфиденциальности, пользовательское соглашение, формы заявлений на вступление. Пройденный шаг отмечен галочкой. Текущий шаг открыт: кнопка «Объявить собрание совета» ставит вопрос шага в повестку совета, совет голосует, председатель утверждает. На кадре это вступление в ПК «Восход». Дальше идут импорт пайщиков списком из файла и объявление общего собрания.
