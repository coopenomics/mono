# Роли сети

Сеть кооперативной экономики — это цепь блоков и узлы кооперативов. В сети действуют четыре роли: ведущий, оператор, кооператив и провайдер. Пятая сторона, АНО, ведёт цепочку доверия подписей. Каждая роль отвечает за свою часть работы сети, и один кооператив может нести несколько ролей сразу.

| Роль | Что делает | Сколько в сети |
|---|---|---|
| Ведущий | Запускает цепь, ведёт сеть, назначает операторов | Один |
| Оператор | Подключает кооперативы к сети и обслуживает их | Один или несколько |
| Кооператив | Ведёт пайщиков, документы и взносы на своём узле | Сколько угодно |
| Провайдер | Поставляет каталог приложений, облачный хостинг и подписки | Внешний сервис, подключается по желанию |
| АНО | Заверяет операторов в цепочке доверия подписей | Отдельная организация, подключается по желанию |

## Ведущий

Ведущий — кооператив, который запустил цепь. Он ведёт сеть: назначает операторов и снимает их, регистрирует кооперативы в реестре сети. Ведущий в сети один. Кооператив, который развернул платформу сам, становится ведущим своей сети.

## Оператор

Оператор — кооператив, которого ведущий назначил подключать другие кооперативы. Оператор принимает заявку кооператива, подключает его к сети и обслуживает подключение. Узел оператора показывает совету реестр кооперативов и страницы подключения.

Ведущий назначает оператором любой действующий кооператив сети. Сам ведущий тоже оператор: загрузка цепи и миграция реестра вносят его в список операторов. Пока других операторов нет, ведущий подключает кооперативы один.

## Кооператив

Кооператив работает с пайщиками на своём узле. Кооператив выбирает одно из двух положений в сети.

- Кооператив у оператора. Оператор подключил кооператив и обслуживает его. Запись кооператива в реестре сети называет его оператора.
- Кооператив на своей платформе. Кооператив развернул платформу сам, оператора у него нет.

## Провайдер

Провайдер — внешний сервис. Он поставляет узлу каталог приложений, а по договорённости ещё облачный хостинг и подписки. Провайдер проверяет, что версии смарт-контрактов сети совместимы с каталогом.

Узел с провайдером показывает каталог приложений и подписки. Узел без провайдера показывает встроенные приложения. Подключение кооперативов к сети ведёт оператор.

## АНО

АНО «Кооперативная Экономика» ведёт цепочку доверия подписей. АНО заверяет оператора, оператор заверяет свои кооперативы, кооператив выпускает удостоверения пайщикам. По этой цепочке работает [карта кооператора](../participant/cardcoop.md).

Цепочка доверия связывает разные сети и юридические лица. Роли внутри сети действуют независимо от неё: сеть работает и до заверения АНО.

## Режимы работы узла

| Режим | Ведущий | Оператор | Провайдер | Что показывает стол |
|---|---|---|---|---|
| Своя сеть без провайдера | сам кооператив | сам кооператив | нет | Встроенные приложения и реестр кооперативов; подключение ведётся вручную |
| Своя сеть с провайдером | сам кооператив | сам кооператив | есть | Каталог приложений и подписки; подключение автоматизирует хостинг провайдера |
| Кооператив у оператора | другой кооператив | другой кооператив | есть | Каталог приложений, подписки, кошелёк у оператора |

Своя сеть без провайдера — запуск платформы из открытого кода: кооператив сам ведущий и оператор, он ведёт своих пайщиков и при желании подключает другие кооперативы вручную. Провайдер подключается к узлу в любом режиме.

## Как роли записаны

Раздел для разработчиков. Он называет место, где сеть и узел хранят каждую роль.

| Роль | Запись |
|---|---|
| Ведущий | Таблица `network` контракта `registrator`, одна строка с полем `lead`. Строку записывает действие `setlead` с подписью системного аккаунта цепи. Цепь без строки считает ведущим `voskhod` |
| Оператор | Таблица `operators` контракта `registrator`. Оператора назначает действие `appoint`, снимает действие `dismiss`; оба подписывает ведущий |
| Оператор кооператива | Поле `parent_username` записи кооператива в таблице `coops` контракта `registrator`. Поле записывает действие `setoperator` с подписями кооператива и оператора; оно принимает только оператора из таблицы `operators`. Пустое поле означает кооператив на своей платформе |
| Адрес узла оператора | Поле `announce` записи оператора в таблице `coops` |
| Провайдер | Настройка узла `PROVIDER_BASE_URL`. Пустое значение означает узел без провайдера |
| АНО | Аккаунт `ano`, заверения лежат в таблице `endorsements` контракта `ano` |

Узел читает ведущего и список операторов из цепи и сообщает их столу в сведениях о системе.

| Поле сведений о системе | Значение |
|---|---|
| `network_lead` | Ведущий сети |
| `is_operator` | Кооператив узла назначен оператором |
| `has_provider` | Узел подключён к провайдеру |
| `cooperator_account.parent_username` | Оператор кооператива узла |

Своя сеть называет ведущего один раз при запуске цепи: системный аккаунт вызывает `setlead` до действия `init` контракта `registrator`. Затем ведущий вызывает `appoint` со своим именем и становится оператором.
