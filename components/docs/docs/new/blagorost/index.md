# Благорост

Благорост — приложение совместного создания результатов интеллектуальной
деятельности. Участники объединяются в проекты, проекты делятся на
компоненты, у каждого компонента есть мастер, план работ и задачи. Вклад
участника учитывается временем и подтверждается голосованием, а результат
распределяется долями.

Начните с [адаптации](adaptation.md): это первый вход участника в
приложение. Дальше разделы идут по ходу работы: профиль и кошельки,
мастерская и допуск, задачи и учёт времени, голосование и получение доли.
