
# Маркетплейс

## Что такое Маркетплейс

**Маркетплейс** — это фронтенд-расширение (десктоп-приложение), которое предоставляет пользовательский интерфейс для кооперативного обмена имуществом. Маркетплейс работает поверх API [Cooplace](index.md) и не имеет собственного бэкенда.

!!! tip "Маркетплейс — одна из форм «морды лица»"
    Cooplace может иметь множество фронтендов: полноценный маркетплейс с витриной, одностраничный магазин для одного товара, мобильное приложение, или вовсе отсутствие интерфейса (работа только через API).

## Витрина

Витрина отображает опубликованные карточки товаров и услуг. Пайщики могут:

- Просматривать предложения от поставщиков
- Публиковать собственные предложения или заказы (в зависимости от настроек)
- Оформлять заказы на поставку
- Отслеживать статус своих заказов

## Процесс заказа

### 1. Создание карточки
Пайщик (поставщик или заказчик, в зависимости от настроек маркетплейса) создаёт карточку товара. Указывает:

- Название и описание
- Цена за единицу и количество
- Тип доставки (внутренняя / внешняя)
- Тип взноса (паевой / членский)
- Срок годности и гарантийный период
- Опционально: минимальный объём и дедлайн цикла

### 2. Модерация
Карточка проходит модерацию (если включена в настройках). Председатель или уполномоченное лицо одобряет или отклоняет карточку.

### 3. Публикация на витрине
После одобрения карточка появляется на витрине и доступна другим пайщикам.

### 4. Оформление заказа
Заказчик выбирает товар и оформляет заказ. В этот момент:

- Заявка **сразу публикуется в блокчейн**
- Средства заказчика **блокируются смарт-контрактом**
- Начинается процесс поставки

### 5. Поставка
Поставщик подтверждает поставку на кооперативный участок. Председатель КУ подписывает акт приёма-передачи.

### 6. Получение
Заказчик приходит на КУ, подаёт заявление на возврат, получает решение совета, забирает имущество.

### 7. Завершение
После истечения гарантийного периода поставщик получает средства на кошелёк.

## Администрирование

Администрирование маркетплейса осуществляется через расширение **market-admin**:

- **Настройки** — тип ведущих заявок, доступ к публикации, модерация, циклы, доставка
- **Модерация** — одобрение/отклонение карточек
- **Все заказы** — мониторинг активных поставок

## Страницы маркетплейса

| Страница | Описание |
|----------|----------|
| Витрина | Каталог опубликованных товаров |
| Карточка товара | Детальная информация + кнопка заказа |
| Создать предложение | Форма создания карточки |
| Мои предложения | Список карточек пользователя |
| Мои заказы | Отслеживание статуса заказов |
| Склад | Управление имуществом на КУ (председатель) |
| Перевозки | Управление транспортировкой (председатель) |
| Претензии | Гарантийный возврат |
