# Стол преподавателя

За столом преподавателя работает пайщик, назначенный преподавателем
курса. Стол открывается после подключения: преподаватель подписывает
оферту программы и получает назначения.

Разделы стола:

- **Подключение к столу** — оферта программы.
- **Профиль** — данные преподавателя и его условия.
- **Назначения** — курсы и группы преподавателя.
- **Занятия** — проведённые занятия и отчёты о них.
- **Расчёты** — начисления преподавателю и их выплата.
