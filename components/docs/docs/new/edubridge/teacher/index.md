# Стол преподавателя

За столом преподавателя работает пайщик, назначенный преподавателем
курса. Стол открывается после подключения: преподаватель подписывает
оферту программы и получает назначения.

Разделы стола:

- **[Подключение преподавателя](onboarding.md)** — рассказ о себе, оферта и договор участия.
- **[Профиль](profile.md)** — договор, ставка за час и курсы преподавателя.
- **[Назначения](assignments.md)** — курсы, к которым допущен преподаватель.
- **[Календарь](lessons.md)** — занятия по месяцам и отчёт после занятия.
- **[Отчёты](reports.md)** — путь взноса от отчёта до акта: документы на материалы, решение совета, акт.
- **[Расчёты](settlement.md)** — паевой взнос по программе и возврат.
