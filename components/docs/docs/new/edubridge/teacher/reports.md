# Отчёты

Страница «Отчёты» ведёт журнал отчётов преподавателя. В журнале проведённые занятия с отчётом и без, состояние взноса по каждому и действие по строке.

![Отчёты по занятиям](/assets/new/edubridge/teacher/reports/01-reports.png)

В таблице номер занятия, курс, дата проведения, число обучающихся, взнос по занятию и его состояние. Взнос считает контракт по ставке преподавателя и числу обучающихся с оплаченным доступом на дату занятия. Действие по строке зависит от состояния. Это отчитаться, передать материалы на хранение или подписать акт приёма-передачи.

![Занятие целиком](/assets/new/edubridge/teacher/reports/02-details.png)

Нажатие на строку открывает занятие целиком. Сверху состояние взноса, курс, номер занятия, число обучающихся с оплаченным доступом, сумма взноса и дата, до которой материалы на хранении. Ниже тема, дата проведения, длительность и ссылки на материалы. Состояние «На ответственном хранении» означает, что материалы приняты и идёт гарантийный срок курса. Когда срок истекает, заявление о взносе уходит совету само. После решения совета преподаватель подписывает акт приёма-передачи в запросах одобрений.
