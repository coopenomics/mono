# Расчёты

Страница «Расчёт» показывает паевой взнос преподавателя по программе «Образование» и выписку. Взнос зачисляется после решения совета о приёме и двух подписей на акте приёма-передачи. Возврат денег оформляется здесь одной кнопкой.

![Расчёт](/assets/new/edubridge/teacher/settlement/01-settlement.png)

Сверху паевой взнос по программе. Это сумма принятых взносов, которая ещё не возвращена. Кнопка «Получить возврат» открывает заявление на возврат. Ниже выписка с зачислениями по принятым результатам и возвратами. Строка открывает подробности движения.

![Возврат паевого взноса](/assets/new/edubridge/teacher/settlement/02-return-dialog.png)

Возвращается вся доступная сумма. Преподаватель выбирает реквизиты для выплаты. Реквизиты заводятся на странице реквизитов стола пайщика, без них окно показывает кнопку «Добавить реквизиты». Кнопка «Получить возврат» подписывает разом два заявления. Это заявление о трансляции взноса в Цифровой Кошелёк и заявление о возврате деньгами.

![Заявление подано](/assets/new/edubridge/teacher/settlement/03-requested.png)

После подачи возврат появляется в выписке со состоянием «На рассмотрении совета». Паевой взнос по программе обнуляется, сумма переходит на главный паевой кошелёк до выплаты. Совет принимает решение в повестке. После решения платёж попадает кассиру в реестр платежей кооператива.

![Выплата состоялась](/assets/new/edubridge/teacher/settlement/04-paid.png)

Кассир переводит деньги по реквизитам и подтверждает платёж. Возврат в выписке переходит в состояние «Выплачено», главный паевой кошелёк обнуляется. Зачисление по принятому результату остаётся в истории.

![Платежи пайщика](/assets/new/edubridge/teacher/settlement/05-my-payments.png)

Та же выплата видна на столе пайщика в разделе «Платежи». Строка показывает тип платежа «Возврат взноса», сумму и состояние «Завершён».
