# Расчёт

Страница «Расчёт» показывает паевой взнос преподавателя по программе «Образование». Взнос зачисляется после решения совета и подписи акта приёма-передачи.

![Расчёт](/assets/new/edubridge/teacher/settlement/01-settlement.png)

Сверху паевой взнос по программе и доступная сумма. Кнопка «Получить возврат» оформляет заявление на возврат на реквизиты преподавателя. Заявление рассматривает совет, затем кооператив выплачивает деньги. Ниже выписка движений по взносу.
