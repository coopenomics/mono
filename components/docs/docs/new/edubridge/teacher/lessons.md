# Календарь

Календарь преподавателя показывает его занятия по месяцам. Занятия ставит в календарь администратор окнами расписания группы. После конца занятия преподаватель открывает его и отчитывается. Отчёты, документы на подпись и журнал находятся на странице [«Отчёты»](reports.md).

![Календарь преподавателя](/assets/new/edubridge/teacher/lessons/01-calendar.png)

Плитка занятия показывает время и группу. Цвет плитки показывает состояние. Это запланировано, проведено, отчёт просрочен и отменено. Стрелки листают месяцы, кнопка «Сегодня» возвращает к текущему.

![Занятие из календаря](/assets/new/edubridge/teacher/lessons/02-lesson.png)

Плитка открывает занятие. Панель показывает состояние, курс, группу, номер в программе, время, длительность, преподавателя и тему. У проведённого занятия добавляются дата отчёта, число обучающихся в расчёте и материалы. У запланированного занятия панель называет момент, с которого открывается отчёт. После конца занятия внизу панели появляется кнопка «Отчитаться». Отчёт содержит тему и материалы по одной ссылке на строку. Материалы передаются кооперативу на ответственное хранение вместе с отчётом.
