# Назначения

Назначение — допуск преподавателя к курсу. Его выдаёт администратор программы. Страница показывает курсы, к которым допущен преподаватель.

![Назначения](/assets/new/edubridge/teacher/assignments/01-assignments.png)

В таблице курс, расписание, период ведения и состояние назначения.

![Назначение целиком](/assets/new/edubridge/teacher/assignments/02-details.png)

Нажатие на строку открывает назначение целиком. Панель показывает расписание, период, ожидаемый результат, описание курса и учебную программу.
