# Подключение ученика

Пайщик становится учеником после подписи оферты по ЦПП «Образование». Оферта подписывается один раз. После неё пайщик записывает на курсы себя и других обучающихся.

![Оферта ученика](/assets/new/edubridge/member/onboarding/01-offer.png)

Стол ученика до подписи содержит одну страницу «Подключение». Документ читается целиком на странице. Ниже галочка согласия с условиями участия и кнопка «Подписать оферту». Подпись ставится ключом пайщика.

![Стол ученика после подписи](/assets/new/edubridge/member/onboarding/02-after.png)

После подписи стол ученика открыт. В меню появляются [каталог курсов](catalog.md), [обучающиеся](learners.md) и [подписки](subscriptions.md).
