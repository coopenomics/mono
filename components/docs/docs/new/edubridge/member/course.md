# Страница курса

Страница курса показывает условия участия. Сверху название, раздел и уровень, расписание, дата начала занятий и длительность программы. Кнопка «Получить доступ» открывает [оформление подписки](subscribe.md). Если подписка уже есть, вместо неё показаны оплаченный срок и кнопка «Продлить».

![Страница курса](/assets/new/edubridge/member/course/01-course.png)

Плитки показывают взнос в месяц, взнос за весь курс разом, число занятий в месяц с длительностью занятия и число занятий в программе.
