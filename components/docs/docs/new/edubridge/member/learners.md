# Обучающиеся

Обучающийся проходит курс. Это сам ученик или человек, которого ученик записал. Страница показывает обучающихся ученика с числом подписок у каждого. Контакты обучающихся видят ученик и председатель.

![Обучающиеся](/assets/new/edubridge/member/learners/01-learners.png)

Строка показывает имя обучающегося, его код пропуска или адрес и число подписок. Нажатие на строку открывает карточку обучающегося. Кнопка «Добавить обучающегося» в шапке открывает окно нового обучающегося.

![Новый обучающийся](/assets/new/edubridge/member/learners/02-new-learner.png)

В окне ученик указывает фамилию, имя и отчество и способ получения доступа. Для очных занятий это код пропуска. Для курса на площадке это электронная почта или Telegram. На этот адрес уходит доступ к курсу.

![Обучающийся добавлен](/assets/new/edubridge/member/learners/03-added.png)

Новый обучающийся появляется в списке без подписок. Записать его на курс можно из каталога либо из его карточки.
