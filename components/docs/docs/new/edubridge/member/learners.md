# Обучающиеся

Обучающийся проходит курс. Это сам ученик или член его семьи, например ребёнок. По условиям программы ученик записывает на курсы себя и членов семьи. Страница показывает обучающихся ученика с числом подписок у каждого. Контакты обучающихся видят ученик и председатель.

![Обучающиеся](/assets/new/edubridge/member/learners/01-learners.png)

Строка показывает имя обучающегося, его адрес электронной почты и число подписок. Нажатие на строку открывает карточку обучающегося. Кнопка «Добавить обучающегося» в шапке открывает окно нового обучающегося.

![Новый обучающийся](/assets/new/edubridge/member/learners/02-new-learner.png)

В окне ученик указывает фамилию, имя и отчество и адрес электронной почты. На этот адрес площадка курса направляет доступ.

![Обучающийся добавлен](/assets/new/edubridge/member/learners/03-added.png)

Новый обучающийся появляется в списке без подписок. Записать его на курс можно из каталога либо из его карточки.
