# Стол участника

За столом участника работает пайщик, который записывает ученика на курс.
Каталог курсов открыт всем, остальные разделы доступны после подключения к
столу: пайщик подписывает оферту программы и заводит ученика.

Разделы стола:

- **Каталог курсов** и **Карточка курса** — выбор курса и группы.
- **Подключение к столу** — оферта программы и первый ученик.
- **Ученики** — ученики пайщика.
- **Подписки** — записи на курсы, оплаченные месяцы и продление.
