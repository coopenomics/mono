# Стол ученика

За столом ученика работает пайщик, который записывает на курс себя или
другого обучающегося. Каталог курсов открыт всем, остальные разделы
доступны после подключения к столу: пайщик подписывает оферту ученика по
ЦПП «Образование».

Разделы стола:

- **Каталог курсов** и **Карточка курса** — выбор курса и группы.
- **Подключение** — оферта ученика.
- **Обучающиеся** — те, кто проходит курс: сам ученик или те, кого он записал.
- **Мои подписки** — записи на курсы, оплаченные месяцы и продление.
