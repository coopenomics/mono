# Получение доступа к курсу

Доступ к курсу оформляется подпиской. Ученик выбирает обучающегося и способ взноса, кооператив принимает взнос и выдаёт доступ. Окно открывается с карточки курса кнопкой «Получить доступ». У ученика с подпиской та же кнопка называется «Продлить».

![Окно получения доступа](/assets/new/edubridge/member/subscribe/01-dialog.png)

Сверху выбран курс. Ниже ученик выбирает, кто будет обучаться. Это обучающийся из списка, сам ученик или другой человек, которого ученик заводит здесь же. Дальше способ взноса. Помесячный взнос вносится за один месяц занятий. Взнос за весь курс разом закрывает оставшиеся месяцы со скидкой. Окно показывает доступный остаток главного паевого кошелька и дату, до которой будет оплачен доступ. Кнопка «Получить доступ» вносит взнос.

![Подписка оформлена](/assets/new/edubridge/member/subscribe/02-subscribed.png)

После взноса подписка появляется на странице «Мои подписки» с оплаченным сроком и состоянием доступа. Для очного курса занятия идут по расписанию, обучающийся проходит по коду пропуска. Для курса на площадке доступ уходит на адрес обучающегося.
