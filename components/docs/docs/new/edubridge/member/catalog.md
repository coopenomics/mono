# Каталог курсов

Каталог показывает опубликованные курсы кооператива карточками. Карточка содержит раздел и уровень, название, расписание, длительность программы, взнос в месяц и взнос за весь курс со скидкой. Вкладки сверху отбирают курсы по разделу, кнопки под ними по уровню.

![Каталог курсов](/assets/new/edubridge/member/catalog/01-catalog.png)

Взнос в месяц уже содержит целевой членский взнос кооператива. Нажатие на карточку открывает [страницу курса](course.md). До подписи оферты ученика каталог открыт для чтения, запись на курс доступна после [подключения](onboarding.md).
