# Образование

Образование — приложение обучения в кооперативе. Кооператив ведёт каталог
курсов и групп, участник записывает ученика на курс и вносит взносы по
месяцам, преподаватель проводит занятия и отчитывается о них, расчёты с
преподавателем и гарантия участнику идут по правилам программы.

Документация разбита по рабочим столам: кто за столом сидит, что видит и
какие действия ему доступны.
