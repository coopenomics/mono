# Образование

Образование — приложение обучения в кооперативе. Кооператив ведёт каталог
курсов и групп, ученик записывает на курс себя или другого обучающегося и
вносит взносы по месяцам, преподаватель проводит занятия и отчитывается о них,
расчёты с преподавателем и гарантия ученику идут по правилам программы.

Ученик — пайщик, который подписал оферту программы. Обучающийся — тот, кто
проходит курс: сам ученик или человек, которого он записал. У одного ученика
может быть несколько обучающихся.

Документация разбита по рабочим столам: кто за столом сидит, что видит и
какие действия ему доступны.
