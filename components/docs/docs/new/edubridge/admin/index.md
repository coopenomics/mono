# Стол администратора

За столом администратора работает председатель кооператива либо пайщик,
которому назначена роль администратора образования. Стол открывает
подключение приложения, справочники разделов и курсов, площадки проведения
занятий, список преподавателей и учеников, взносы преподавателей и экономику
программы.

Разделы стола:

- **Подключение** — ЦПП «Образование» подключает совет кооператива.
- **Разделы и уровни** и **Курсы** — справочники, из которых собирается каталог.
- **Площадки** — внешние площадки занятий и их подключение.
- **Преподаватели** — договоры, ставки и допуски преподавателей к курсам.
- **Ученики** — ученики программы, их обучающиеся и подписки.
- **Взносы преподавателей** — взносы результатами интеллектуальной деятельности.
- **Экономика** — средства программы и целевой членский взнос.
