# Стол администратора

За столом администратора работает председатель кооператива либо пайщик,
которому назначена роль администратора образования. Стол открывает
настройку приложения, справочники разделов и курсов, площадки проведения
занятий, список преподавателей и участников, взносы и экономику программы.

Разделы стола:

- **Настройка приложения** — условия программы и подключение.
- **Разделы** и **Курсы** — справочники, из которых собирается каталог.
- **Площадки** — внешние площадки занятий и их подключение.
- **Преподаватели** — назначения и условия преподавателей.
- **Участники** — реестр участников программы и их учеников.
- **Взносы** — взносы участников по месяцам.
- **Экономика** — движение средств программы.
