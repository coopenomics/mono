# Площадки

Площадка — место, где проходит курс. Приложение знает три площадки. Это школы Skillspace и GetCourse и очные занятия. На странице у каждой площадки показаны состояние, ключи подключения и дата последней проверки.

![Площадки](/assets/new/edubridge/admin/platforms/01-platforms.png)

Очные занятия работают сразу. Площадки Skillspace и GetCourse требуют ключей. Ключи хранятся зашифрованными, их видит только председатель. Кнопка «Проверить» запрашивает площадку и показывает результат в строке. Кнопка «Выключить» убирает площадку из выбора при создании курса.

![Окно ключей площадки](/assets/new/edubridge/admin/platforms/02-keys-dialog.png)

Кнопка «Задать ключи» открывает окно ввода. Подсказка под полем показывает, где взять ключ в настройках школы. Кнопка «Сохранить и проверить» сохраняет ключ и сразу проверяет подключение.
