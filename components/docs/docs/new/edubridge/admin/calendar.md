# Календарь школы

Календарь школы показывает занятия всех групп кооператива по месяцам. Занятия встают в календарь из окон расписания групп. Администратор переносит и отменяет запланированные занятия здесь же.

![Календарь школы](/assets/new/edubridge/admin/calendar/01-calendar.png)

Сверху отбор по преподавателю и курсу. Под отбором сводка. Это запланированные, проведённые и просроченные по отчёту занятия. Цвет плитки показывает состояние занятия. Кнопка «Назначить занятие» в шапке ставит внеочередное занятие из резерва расписания группы. Стрелки листают месяцы, кнопка «Сегодня» возвращает к текущему.

![Занятие из календаря](/assets/new/edubridge/admin/calendar/02-lesson.png)

Плитка открывает занятие. Панель показывает состояние, курс, группу, номер в программе, время, длительность, преподавателя и тему. У проведённого занятия добавляются дата отчёта, число обучающихся в расчёте и ссылки на материалы. У запланированного занятия внизу панели стоят кнопки «Перенести» и «Отменить».
