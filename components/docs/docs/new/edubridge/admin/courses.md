# Курсы

Страница «Курсы» показывает курсы кооператива карточками. Карточка содержит обложку, раздел и уровень, название, расписание, преподавателя, длительность программы, взнос в месяц и взнос за весь курс со скидкой. Метка в углу показывает состояние публикации.

![Реестр курсов](/assets/new/edubridge/admin/courses/01-courses.png)

Курс в состоянии «Черновик» виден только администратору. Опубликованные курсы видны в каталоге всем посетителям. Если преподаватель не назначен, карточка так и пишет. Кнопка «Добавить курс» в шапке открывает [форму нового курса](course-create.md). Нажатие на карточку открывает [страницу курса](course.md).
