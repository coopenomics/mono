# Подключение ЦПП советом

Целевую потребительскую программу «Образование» принимает совет кооператива. Совет утверждает четыре документа. Это положение о программе, шаблон оферты ученика, шаблон оферты преподавателя и шаблон договора участия в хозяйственной деятельности. До утверждения столы ученика и преподавателя закрыты.

![Страница подключения с четырьмя вопросами совету](/assets/new/edubridge/admin/configure/01-steps.png)

Каждый вопрос показан карточкой с проектом решения. Нажмите на карточку, чтобы прочитать проект перед объявлением. Кнопка «Объявить все» выносит все четыре вопроса в совет разом.

![Подтверждение объявления вопросов](/assets/new/edubridge/admin/configure/02-announce-confirm.png)

Перед отправкой интерфейс просит подтвердить объявление. Проекты решений по вопросам направляются в совет по порядку. Совет рассматривает их на собрании.

![Вопросы в совете](/assets/new/edubridge/admin/configure/03-in-council.png)

После объявления у каждого вопроса стоит метка «В совете». Члены совета голосуют на своём столе. Председатель подписывает протокол, и документ считается утверждённым.

![Стол администратора после подключения](/assets/new/edubridge/admin/configure/04-connected.png)

После утверждения всех четырёх документов страница подключения закрывается. У председателя открываются рабочие страницы стола администратора. Первая из них — курсы. Перед курсами онлайн-школы председатель [подключает площадку](platform-setup.md).
