# Добавление курса

Форма нового курса пошаговая. Шаги идут сверху вниз. Это курс, обложка, занятия, взнос, выдача доступа, первая группа и преподаватели. Кнопка «Далее» ведёт к следующему шагу, кнопка «Назад» возвращает к предыдущему.

![Первый шаг формы](/assets/new/edubridge/admin/course-create/01-empty-form.png)

Первый шаг описывает курс. Укажите название, раздел и уровень, расписание, описание и учебную программу. Раздел и уровень берутся из справочника, новое значение можно ввести прямо в поле.

![Первый шаг заполнен](/assets/new/edubridge/admin/course-create/02-course-basics.png)

Описание и программа видны в каталоге всем посетителям. Шаг обложки по желанию. Снимок для каталога лучше готовить размером 1600 на 900.

![Шаг занятий](/assets/new/edubridge/admin/course-create/03-lessons.png)

Шаг занятий задаёт число занятий в месяц и в программе, длительность занятия и гарантийный срок на материалы в днях. Длительность программы считается сама по числу занятий.

![Шаг взноса](/assets/new/edubridge/admin/course-create/04-fee.png)

Шаг взноса задаёт плановую ставку часа и способ расчёта с преподавателем. Галочка «Взнос преподавателя за занятие исчисляется за каждого обучающегося» включает расчёт по числу обучающихся. Без галочки взнос за занятие фиксированный. Ниже форма показывает расчёт взноса ученика. Он складывается из оплаты занятий по плановой ставке и целевого членского взноса кооператива. Галочка «Принимать взнос за весь курс разом» открывает взнос за весь курс со скидкой.

![Шаг выдачи доступа](/assets/new/edubridge/admin/course-create/05-access.png)

Шаг выдачи доступа задаёт тип направления и носитель доступа. Для очных занятий выберите направление «Очное обучение», носитель «Очно» встанет сам. Для курса на площадке выберите направление «Онлайн-платформа», школу и курс в ней. Шаг первой группы по желанию. Он задаёт дату начала занятий и группу курса на площадке.

![Выбор преподавателя](/assets/new/edubridge/admin/course-create/06-teacher-pick.png)

Последний шаг назначает преподавателей. В списке пайщики с подписанным договором участия и назначенной ставкой. Курс можно сохранить без преподавателя и назначить его позже.

![Курс сохранён](/assets/new/edubridge/admin/course-create/07-course-saved.png)

Кнопка «Добавить курс» сохраняет курс черновиком и открывает его страницу. Первая группа открыта с набором. Преподаватели ещё не назначены, допуск оформляется на странице преподавателя. В каталог курс попадает после нажатия «Опубликовать».
