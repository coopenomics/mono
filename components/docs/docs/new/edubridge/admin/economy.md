# Экономика

Страница «Экономика» показывает движение денег программы. Взнос ученика проходит путь от кошелька ученика до выплаты преподавателю. Три вкладки показывают деньги, расходы и настройки.

![Вкладка «Деньги»](/assets/new/edubridge/admin/economy/01-money.png)

Плитки показывают средства программы по пути взноса. Кошельки учеников хранят остатки учеников в программе. Удержано по гарантии показывает взносы, которые ученики могут вернуть в гарантийный срок. Кошелёк программы содержит свободные средства программы. Резерв выплат показывает обязательство перед преподавателями. Ниже лента событий с датой, пайщиком и суммой.

![Вкладка «Настройки»](/assets/new/edubridge/admin/economy/02-settings.png)

Настройка одна. Это целевой членский взнос в процентах. Он задаёт часть взноса ученика, которая направляется на ведение программы, издержки и возвраты по положению о ЦПП «Образование». Значение действует на все курсы кооператива.

![Вкладка «Расходы»](/assets/new/edubridge/admin/economy/03-expenses.png)

Расход оплачивается с кошелька программы. Кнопка «Подать расход» открывает служебную записку. Решение по расходу принимает совет. После решения выплата выполняется по акту.
