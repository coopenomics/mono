# Страница курса

Страница курса собирает условия, группы, описание и преподавателей в одном месте. Сверху показаны раздел и уровень, название, состояние публикации, расписание и дата начала занятий. Кнопка «Изменить» открывает форму курса. Кнопка «Снять с публикации» убирает курс из каталога. Меню с тремя точками содержит остальные действия.

![Страница курса](/assets/new/edubridge/admin/course/01-course.png)

Плитки показывают экономику курса. Это взнос в месяц, взнос за весь курс разом, число занятий в месяц с их длительностью и число занятий в программе. Взнос в месяц складывается из оплаты занятий по плановой ставке и целевого членского взноса кооператива.

Таблица групп показывает дату начала, число обучающихся, проведённые занятия и состояние набора. Кнопка «Открыть группу» заводит новую группу с датой начала и группой курса на площадке. Условия группы закрепляются в момент открытия. Ниже расположены описание курса, учебная программа и преподаватели курса.

![Экономика и выдача доступа](/assets/new/edubridge/admin/course/02-groups.png)

Блок «Экономика» справа раскладывает взнос ученика. Это плановая ставка часа, оплата занятий по плановой ставке, целевой членский взнос и способ расчёта с преподавателем. Ниже сводка по всем группам в месяц. Это число обучающихся, взносы за них, взнос преподавателей и сумма, которая остаётся в кооперативе. Блок «Выдача доступа» показывает направление, площадку и гарантийный срок курса.
