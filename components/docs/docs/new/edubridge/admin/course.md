# Страница курса

Страница курса собирает условия, группы, календарь занятий, описание и преподавателей в одном месте. Сверху показаны раздел и уровень, название, состояние публикации, расписание с резервом и дата начала занятий. Кнопка «Изменить» открывает форму курса. Кнопка «Снять с публикации» убирает курс из каталога. Меню с тремя точками содержит остальные действия.

![Страница курса](/assets/new/edubridge/admin/course/01-course.png)

Плитки показывают взнос в месяц, взнос за весь курс разом, занятия и часы занятий в месяц и длительность программы. Таблица групп показывает дату начала, число обучающихся, проведённые занятия и состояние набора. Кнопка «Открыть группу» заводит новую группу. Условия группы закрепляются в момент открытия. Нажатие на строку группы открывает [панель группы](group.md). Ниже таблицы групп стоит календарь занятий курса с кнопкой «Назначить занятие».

![Экономика и выдача доступа](/assets/new/edubridge/admin/course/02-groups.png)

Блок «Экономика курса» справа раскладывает взнос одного обучающегося в месяц. Это стоимость часа преподавателя, стоимость часов преподавателей, целевой членский взнос и способ расчёта с преподавателем. Ниже сводка по всем группам в месяц. Это число обучающихся, взносы за них, взнос преподавателей и сумма, которая остаётся в кооперативе. Блок «Выдача доступа» показывает направление, площадку и гарантийный срок курса.
