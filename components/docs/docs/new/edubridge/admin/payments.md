# Выплаты

Выплаты по программе проходят через реестр платежей кооператива на столе совета. Кассир видит исходящие платежи по решениям совета, переводит деньги по реквизитам и подтверждает платёж. По программе «Образование» сюда приходят возвраты паевых взносов преподавателям и оплаты расходов программы.

![Реестр платежей](/assets/new/edubridge/admin/payments/01-registry.png)

Реестр показывает пайщика, тип платежа, сумму, состояние и дату. Исходящий платёж по решению совета ждёт кассира в состоянии «Ожидает обработки». Кнопка «Подтвердить» в строке означает, что деньги переведены. Отклонить такой платёж кассир не может, решение уже принял совет.

![Платёж целиком](/assets/new/edubridge/admin/payments/02-payment.png)

Нажатие на строку раскрывает платёж. Видны получатель, сумма, реквизиты и назначение платежа. Кассир переводит деньги по этим реквизитам из банка кооператива.

![Платёж подтверждён](/assets/new/edubridge/admin/payments/03-paid.png)

После подтверждения платёж переходит в состояние «Выплачено». В раскрытой строке открывается блок чека об оплате. Чек подтверждает, что перевод исполнен.

![Чек приложен](/assets/new/edubridge/admin/payments/04-proof.png)

Кассир прикладывает чек об оплате изображением или PDF. Значок чека в строке показывает, приложен ли он. У преподавателя возврат в выписке становится выплаченным.

![Второй платёж](/assets/new/edubridge/admin/payments/05-second-paid.png)

Платёж по расходу программы подтверждается так же. По оплате счёта организации в строке открыт блок закрывающих документов. Это акт, счёт-фактура или накладная. По авансу пайщику в строке открыт отчёт пайщика, кассир может отчитаться за него по чекам.
