# Выплаты

Выплаты по программе проходят через реестр платежей кооператива на столе совета. Кассир видит исходящие платежи по решениям совета, переводит деньги по реквизитам и подтверждает платёж. По программе «Образование» сюда приходят возвраты паевых взносов преподавателям и оплаты расходов программы.

![Реестр платежей](/assets/new/edubridge/admin/payments/01-registry.png)

Реестр показывает пайщика, дату, сумму, тип платежа, направление и состояние. Исходящий платёж по решению совета ждёт кассира в состоянии «Ожидает обработки». На кадре два таких платежа. Это оплата расхода по служебной записке от имени кооператива и возврат взноса преподавателю.

![Платёж целиком](/assets/new/edubridge/admin/payments/02-payment.png)

Нажатие на строку раскрывает платёж. Видны реквизиты получателя, назначение платежа и сумма к переводу. У расхода программы видно и то, что оплачивается. Кассир переводит деньги по этим реквизитам из банка кооператива. Кнопка «Подтвердить» в колонке действий означает, что деньги переведены. Отклонить такой платёж кассир не может, решение уже принял совет.

![Платёж подтверждён](/assets/new/edubridge/admin/payments/03-paid.png)

После подтверждения платёж переходит в состояние «Завершён». В раскрытой строке открываются два блока. Первый принимает чек об оплате, он подтверждает перевод. Второй принимает закрывающие документы организации. Это акт, счёт-фактура или накладная. Файлы загружаются сразу при выборе, изображением или PDF.

![Чек приложен](/assets/new/edubridge/admin/payments/04-proof.png)

Значок чека рядом с состоянием показывает, приложен ли чек. После загрузки значок становится зелёным.

![Второй платёж](/assets/new/edubridge/admin/payments/05-second-paid.png)

Возврат взноса преподавателю подтверждается так же. В раскрытой строке реквизиты СБП преподавателя, назначение платежа с номером возврата и сумма. После подтверждения у преподавателя возврат в выписке становится выплаченным. По авансу пайщику в строке вместо закрывающих документов открыт отчёт пайщика, и кассир может отчитаться за него по чекам.
