# Установка приложения

Образование — приложение цифрового кооператива. Председатель устанавливает его из каталога приложений кнопкой «Включить».

![Страница приложения «Образование» в каталоге приложений](/assets/new/edubridge/admin/install/01-install-form.png)

На странице приложения перечислены его рабочие столы и настройки. Настроек две. Первая задаёт, за сколько дней до конца оплаченного периода ученик получает напоминание. Вторая связывает приложение с Благоростом. При включённой связи столы Благороста видят только преподаватели, а его оферты при вступлении не предлагаются.

![Страница подключения ЦПП после установки](/assets/new/edubridge/admin/install/02-after-install.png)

После включения у председателя появляется стол администратора образования. Интерфейс сам открывает первую доступную страницу — [подключение ЦПП](configure.md). Установка только добавляет приложение в кооператив. Работать столы начинают после того, как совет утвердит программу.
