# Взносы преподавателей

Преподаватель передаёт кооперативу материалы занятий результатом интеллектуальной деятельности. Каждая передача оформляется взносом. Страница показывает взносы преподавателей со суммой и состоянием.

![Взносы преподавателей](/assets/new/edubridge/admin/contributions/01-contributions.png)

Сумму взноса считает контракт по ставке преподавателя и числу обучающихся на занятии. Состояние «На ответственном хранении» означает, что материалы переданы и идёт гарантийный срок курса. Состояние «На рассмотрении совета» означает, что заявление о взносе ушло в повестку. Решение о приёме совет принимает в повестке. Акт приёма-передачи председатель подписывает в запросах одобрений. Отказ совета контракт исполняет сам: материалы снимаются с хранения.
