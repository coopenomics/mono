# Взносы преподавателей

Преподаватель передаёт кооперативу материалы занятий результатом интеллектуальной деятельности. Каждая передача оформляется взносом. Страница показывает взносы преподавателей с числом обучающихся в расчёте, суммой и состоянием. Путь взноса со стороны преподавателя описан на странице [«Отчёты»](../teacher/reports.md).

![Взносы преподавателей](/assets/new/edubridge/admin/contributions/01-contributions.png)

Сумму взноса считает контракт по ставке преподавателя и числу обучающихся с оплаченным доступом на дату занятия. Состояние «На ответственном хранении» означает, что материалы переданы и идёт гарантийный срок курса. Состояние «На рассмотрении совета» означает, что заявление о взносе ушло в повестку. Решение о приёме совет принимает в повестке. Отказ совета контракт исполняет сам, материалы снимаются с хранения.

![Акт на подписи председателя](/assets/new/edubridge/admin/contributions/02-act-to-sign.png)

После решения совета преподаватель подписывает акт приёма-передачи. Акт с подписью преподавателя появляется в карточке преподавателя на странице [«Преподаватели»](teachers.md) в блоке документов на подписи. Колонка «На подписи» реестра преподавателей называет такой документ. Кнопка «Подписать» ставит подпись председателя.

![Подтверждение подписи](/assets/new/edubridge/admin/contributions/03-sign-confirm.png)

Подпись подтверждается в окне. Документ подписывается ключом председателя. Кнопка «Отклонить» возвращает документ преподавателю с причиной.

![Взнос принят](/assets/new/edubridge/admin/contributions/04-accepted.png)

После второй подписи взнос переходит в состояние «Принят». Сумма зачисляется преподавателю паевым взносом по программе. Преподаватель оформляет возврат на своём столе, решение принимает совет, выплату подтверждает кассир в [реестре платежей](payments.md).
