# Разделы и уровни

Разделы и уровни образуют каталог курсов. Раздел объединяет курсы одной предметной области. Уровень живёт внутри раздела, например класс или ступень обучения. Название и порядок меняются сразу у всех курсов раздела.

![Разделы и уровни каталога](/assets/new/edubridge/admin/sections/01-sections.png)

На странице показаны разделы кооператива и уровни внутри них. Стрелки меняют порядок разделов и уровней. Меню с тремя точками открывает действия. Это переименование, отправка в архив и возврат из архива.

![Окно нового раздела](/assets/new/edubridge/admin/sections/02-new-section.png)

Кнопка «Добавить раздел» открывает окно с одним полем. Укажите название и нажмите «Сохранить». В каталоге раздел появится вместе с первым опубликованным курсом.

![Раздел добавлен](/assets/new/edubridge/admin/sections/03-section-added.png)

Новый раздел встаёт последним в списке. Уровней у него пока нет.

![Окно нового уровня](/assets/new/edubridge/admin/sections/04-new-level.png)

Кнопка «Добавить уровень» внутри раздела открывает окно с названием уровня. В каталоге курсы разных разделов группируются по уровню при точном совпадении его названия.
