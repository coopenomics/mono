# Ученики

Страница показывает учеников кооператива, их обучающихся, подписки и выдачу доступа. Ученик подписывает оферту и записывает обучающихся на курсы. Обучающийся проходит курс. Контакты обучающихся видит только председатель.

![Реестр учеников](/assets/new/edubridge/admin/members/01-members.png)

Поиск работает по ФИО и учётному имени. В таблице у каждого ученика число обучающихся, число подписок и состояние выдачи доступа. Красная метка означает, что доступ не выдан.

![Карточка ученика](/assets/new/edubridge/admin/members/02-card.png)

Нажатие на строку открывает карточку ученика. В ней учётное имя, обучающиеся с адресами почты, подписки с оплаченным сроком и состоянием доступа. Внизу задачи выдачи доступа с датой, состоянием и последней ошибкой. Выдача на площадку идёт сама после оплаты. Если площадка ответила ошибкой, текст ошибки виден здесь.
