# НДФЛ

Страница «НДФЛ» ведёт налог, который кооператив удерживает с выплат физическим лицам. Кооператив выступает налоговым агентом: деньги остаются на расчётном счёте, долг перед бюджетом копится, затем гасится единым налоговым платежом.

![НДФЛ](/assets/new/buh/ndfl/01-page.png)

Сверху удержанный налог к перечислению. Кнопка «Отправить на оплату» заводит платёж в бюджет на накопленную сумму, кассир перечисляет его по реквизитам налоговой в реестре платежей и прикладывает чек. Расчётный период платежа совпадает с периодом уведомления об исчисленных суммах НДФЛ. Ниже список перечислений: сумма, расчётный период и чек кассира. У кооператива без выплат пайщикам список пуст.
