# Архив отчётности

Вкладка «Архив» хранит собранные отчёты.

![Архив отчётности](/assets/new/buh/archive/01-page.png)

Строка отчёта показывает тип, год, период, файл, результат проверки и дату сборки. Отборы «Тип отчёта» и «Год» сужают список. У нового кооператива архив пуст.
