# Стол бухгалтера

Стол бухгалтера ведёт учёт кооператива по документам, которые подготовили процессы платформы. Каждое действие в кооперативе, от приёма пайщика до оплаты расхода, оставляет операцию с проводками по плану счетов, и стол показывает их реестрами. Стол открыт председателю и пайщикам с ролью бухгалтера или ревизора, роли назначает председатель на странице [«Управление доступом»](../chairman/access-roles.md).

Реестры стола идут от общего к частному. [Реестр процессов](processes.md) показывает каждый процесс кооператива одной строкой. [Реестр операций](operations.md) показывает хозяйственные операции внутри процессов. [Реестр проводок](postings.md) показывает двойную запись по счетам. [Реестр кошельков](wallets-coop.md) и [реестр счетов](accounts.md) показывают остатки с двух сторон: кошельки управленческого учёта и счета бухгалтерского плана.

Отчётность собирается в разделе [«Отчётность»](calendar.md): календарь сроков, формы и архив сданного. Страница [«НДФЛ»](ndfl.md) ведёт удержанный налог с выплат пайщикам. Страница [«Реквизиты»](settings.md) хранит данные кооператива для форм.
