# Кошельки пайщиков

Вкладка «Пайщики» реестра кошельков показывает паевые взносы каждого пайщика по программам кооператива.

![Кошельки пайщиков](/assets/new/buh/wallets-participants/01-page.png)

Строка пайщика показывает ФИО с учётным именем и остаток в каждой программе: «Цифровой кошелёк», «Маркетплейс», «Генератор» и дальше по установленным приложениям. Прочерк означает, что пайщик в программе не участвует. Значок замка у суммы показывает заблокированную часть. Нижняя строка суммирует остатки по каждой программе.
