# Список форм

Вкладка «Список форм» перечисляет формы отчётности, которые кооператив сдаёт в налоговую и фонды.

![Список форм](/assets/new/buh/forms/01-page.png)

Строка формы показывает название, периодичность и срок сдачи. Бухгалтерский баланс сдаётся раз в год до 31 марта. 6-НДФЛ, расчёт по страховым взносам и ЕФС-1 сдаются ежеквартально до 25 числа месяца после квартала. Персонифицированные сведения сдаются ежемесячно. Из строки формы собирается отчёт за период, готовый файл попадает в архив.
