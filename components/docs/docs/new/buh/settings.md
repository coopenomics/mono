# Реквизиты

Страница «Реквизиты» хранит данные кооператива для форм отчётности.

![Реквизиты отчётности](/assets/new/buh/settings/01-page.png)

Блок «Реквизиты организации» показывает ИНН, КПП, ОГРН, наименование, адрес, телефон и ФИО подписанта. Эти данные приходят из карточки кооператива, страница их только показывает. Блок «Классификаторы» заполняет бухгалтер: ОКВЭД, ОКФС, ОКОПФ, ОКТМО и ОКПО нужны большинству форм. Кнопка «Сохранить реквизиты» записывает классификаторы.
