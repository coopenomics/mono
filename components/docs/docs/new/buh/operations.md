# Реестр операций

Реестр операций показывает хозяйственные операции кооператива. Операция — одно движение денег или имущества внутри процесса, у неё свой номер и свои проводки.

![Реестр операций](/assets/new/buh/operations/01-page.png)

Строка операции показывает номер, номер процесса, дату и название операции. На кадре операции приёма пайщиков: вступительный взнос и минимальный паевой взнос при регистрации, по две на каждого пайщика. Поиск ищет по номеру операции, отбор по датам сужает период. Переключатель «Только корректировки» оставляет операции, которыми бухгалтер исправлял учёт. Стрелка слева раскрывает операцию с её проводками и документом-основанием.
