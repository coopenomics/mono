# Реестр процессов

Реестр процессов показывает каждый процесс кооператива одной строкой. Процесс объединяет операции, проводки и документы одного дела: приёма пайщика, паевого взноса, возврата, расхода.

![Реестр процессов](/assets/new/buh/processes/01-page.png)

Строка процесса показывает тип, идентификатор, пайщика, сумму и дату создания. На кадре шесть процессов приёма пайщиков с их вступительными и паевыми взносами. Отбор «Тип процесса» оставляет процессы одного типа, поиск находит процессы пайщика. Стрелка слева раскрывает процесс: его операции, проводки и документы в порядке хода.
