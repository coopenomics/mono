# Реестр счетов

Реестр счетов показывает план счетов кооператива с оборотами и сальдо. Это бухгалтерская сторона тех же денег, что лежат в кошельках.

![Реестр счетов](/assets/new/buh/accounts/01-page.png)

Строка счёта показывает номер, наименование, оборот по дебету, оборот по кредиту, сальдо и тип счёта. На кадре три счёта после приёма пайщиков: расчётный счёт 51 с двумя тысячами рублей, паевой фонд 80 с полутора тысячами и целевое финансирование 86 с пятьюстами. Стрелка слева раскрывает проводки по счёту.
