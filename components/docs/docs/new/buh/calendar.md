# Календарь отчётности

Раздел «Отчётность» собирает формы для налоговой и фондов. Первая вкладка, «Календарь», показывает сроки их сдачи по месяцам года.

![Календарь отчётности](/assets/new/buh/calendar/01-page.png)

Строка календаря — одна форма с её периодичностью: годовая бухгалтерская отчётность, квартальные 6-НДФЛ, РСВ и ЕФС-1, ежемесячные персонифицированные сведения, уведомления об НДФЛ дважды в месяц. Клетка на пересечении формы и месяца показывает период и состояние отчёта за него. Стрелки у года переключают год. Вторая вкладка, [«Список форм»](forms.md), перечисляет формы, третья, [«Архив»](archive.md), хранит сданное.
