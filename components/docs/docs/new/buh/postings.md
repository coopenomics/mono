# Реестр проводок

Реестр проводок показывает двойную запись по плану счетов кооператива. Каждая операция даёт одну или несколько проводок: дебет одного счёта, кредит другого, сумма.

![Реестр проводок](/assets/new/buh/postings/01-page.png)

Строка проводки показывает дату, номер проводки, номер процесса, операцию, счёт дебета, счёт кредита и сумму. На кадре проводки по взносам при регистрации: деньги приходят на расчётный счёт 51 с кредита паевого фонда или целевого финансирования. Поиск ищет по номеру проводки, отбор по датам сужает период.
