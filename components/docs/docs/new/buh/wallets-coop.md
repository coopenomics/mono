# Кошельки кооператива

Реестр кошельков показывает деньги кооператива в управленческом учёте. Кошелёк — остаток с назначением: вступительные взносы, минимальные паевые взносы, кошельки программ. Остатки кошельков меняют процессы платформы по своим правилам, ниже нуля остаток кошелька не опускается.

![Кошельки кооператива](/assets/new/buh/wallets-coop/01-page.png)

Вкладка «Кооператив» перечисляет кошельки кооператива: идентификатор, наименование и доступный остаток. На кадре вступительные взносы и минимальные паевые взносы шести пайщиков. Стрелка слева раскрывает историю движения по кошельку. Кошельки пайщиков показаны на [второй вкладке](wallets-participants.md).
