# Расходы

Страница «Расходы» показывает служебные записки кооператива по этапам выплаты. Строка открывает записку, оплату по записке кассир подтверждает в реестре платежей.

![Расходы](/assets/new/cashier/expenses/01-to-pay.png)

Четыре вкладки ведут записку по пути. «К оплате» — записки после решения совета, по их строкам заведены платежи. «Ждут отчёта» — аванс выдан, пайщик ещё не отчитался. «На утверждении» — отчёты по всем строкам поданы, записку пора закрыть. «Закрытые» — расход закрыт. Счётчики у вкладок считают записки на каждом этапе.

![Ждут отчёта](/assets/new/cashier/expenses/02-awaiting-report.png)

Строка записки показывает назначение, автора, дату, сумму по плану и сумму по факту. На кадре записка на аренду зала: аванс в полторы тысячи рублей выдан, по факту выплачено столько же, записка ждёт отчёта пайщика.

![Служебная записка](/assets/new/cashier/expenses/03-proposal.png)

Нажатие на строку открывает записку. Сверху состояние, на кадре «Частично оплачен». Сводка показывает автора, кошелёк-источник, суммы и даты. Ниже документы записки: подписанная служебная записка и протокол решения совета. Дальше строки расходов и платежи по ним. Когда отчёты по всем строкам поданы, на этой странице у кассира и председателя появляется кнопка «Закрыть расход».
