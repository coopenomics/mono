# Авансы

Страница «Авансы» собирает выданные авансы под отчёт по всему кооперативу. Аванс появляется здесь после выплаты в реестре платежей.

![Авансы](/assets/new/cashier/advances/01-advances.png)

Строка аванса показывает получателя, назначение с датой выдачи, сумму аванса, потраченное по отчёту и состояние. Состояние «Ждёт отчёта» означает, что пайщик ещё не отчитался чеками. Вкладки отбирают авансы по состоянию: «Все», «Ждёт отчёта», «Отчёт принят», «Возврат или доплата».

![Отчёт принят](/assets/new/cashier/advances/02-reported.png)

Во вкладке «Отчёт принят» — авансы, по которым отчёт сдан и потраченная сумма записана. Во вкладке «Возврат или доплата» — авансы, где потрачено меньше или больше выданного и в реестре платежей ждёт платёж расчёта разницы. Отчёт за получателя и расчёт разницы кассир проводит в реестре платежей.

![Записка аванса](/assets/new/cashier/advances/03-proposal.png)

Нажатие на строку открывает служебную записку, из которой выдан аванс.
