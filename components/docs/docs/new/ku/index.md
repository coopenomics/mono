# Кооперативный участок

Кооперативный участок — приложение самоорганизации пайщиков по месту.
Участок объединяет пайщиков одного города или района, имеет председателя
и доверенных лиц. Пайщики учреждают участок сами на собрании, совет
кооператива утверждает решение собрания, и участок появляется в реестре.

Собрание пайщиков объявляет любой пайщик. Участники присоединяются по
заявлению, голосуют бюллетенями по вопросам повестки, председатель собрания
утверждает протокол одной подписью. Собрание об учреждении участка
заканчивается заявлением в совет. Доверенное лицо участка принимает
имущество кооператива по договору о полной материальной ответственности.

Приложение добавляет один рабочий стол. Он открыт каждому пайщику, а
председатель кооператива и председатель участка видят на нём свои действия.
