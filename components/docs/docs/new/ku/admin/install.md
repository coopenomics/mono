# Установка приложения

Кооперативный участок — приложение цифрового кооператива. Председатель устанавливает его из каталога приложений кнопкой «Включить». Настроек у приложения нет.

![Страница приложения в каталоге](/assets/new/ku/admin/install/01-install-form.png)

Страница приложения называет его рабочий стол. Стол один, он так и называется «Кооперативный участок». После включения стол открыт каждому пайщику кооператива.

![Стол после установки](/assets/new/ku/admin/install/02-after-install.png)

Стол содержит три раздела. Это «Кооперативные участки», «Собрания» и «Мой участок». Сверху раздела участков показана система управления кооперативом. Пока участков меньше трёх, все пайщики участвуют в общем собрании напрямую. С третьего участка система управления становится мажоритарной, и общие собрания проходят через участки.
