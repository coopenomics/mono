# Участки

Раздел «Кооперативные участки» показывает участки кооператива. Участок объединяет пайщиков по месту, у него есть председатель, адрес, контакты и доверенные лица. Новый участок учреждается собранием пайщиков в разделе «Собрания».

![Реестр участков](/assets/new/ku/admin/branches/01-branches.png)

Таблица показывает наименование и адрес участка, председателя, доверенных лиц и число пайщиков участка. Сверху состояние мажоритарной системы управления. При трёх и более участках она включена, и пайщики участвуют в общих собраниях через участки. Нажатие на строку открывает карточку участка.

![Карточка участка](/assets/new/ku/admin/branches/02-branch.png)

Карточка показывает адрес, почту и телефон участка. Ниже председатель участка. Справа число пайщиков участка, они делегировали председателю свой голос на общих собраниях. Блок «Доверенные лица» перечисляет доверенных с их учётными именами. Кнопка «Стать доверенным лицом» открывает заявку, её путь описан на странице [«Заявка в доверенные лица»](../member/trusted.md).
