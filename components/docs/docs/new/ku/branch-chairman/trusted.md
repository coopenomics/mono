# Одобрение доверенного лица

Председатель участка рассматривает заявки в доверенные лица своего участка. Заявки стоят в разделе «Мой участок».

![Заявки на доверенных](/assets/new/ku/branch-chairman/trusted/01-requests.png)

Таблица показывает заявителя, состояние, документы и действия. Кнопка «Одобрить» ставит встречную подпись председателя на договоре и доверенности. Кнопка «Отклонить» закрывает заявку с причиной.

![Договор заявителя](/assets/new/ku/branch-chairman/trusted/02-contract.png)

Ссылка «Договор» открывает договор о полной материальной ответственности с подписью заявителя. Ссылка «Доверенность» открывает доверенность.

![Доверенное лицо принято](/assets/new/ku/branch-chairman/trusted/03-approved.png)

После встречной подписи пайщик появляется в блоке «Доверенные лица» участка. Заявка переходит в состояние «Рассмотрена».
