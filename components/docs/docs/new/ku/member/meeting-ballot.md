# Бюллетень участника

Участник голосует бюллетенем, пока открыто голосование. Бюллетень содержит ответы по всем вопросам повестки и подписывается участником.

![Собрание в голосовании](/assets/new/ku/member/meeting-ballot/01-voting.png)

В состоянии «Голосование» страница собрания показывает наименование, адрес, почту и телефон будущего участка и его председателя. Ниже время, до которого открыто голосование, и число поданных бюллетеней. Участник выбирает ответ у каждого вопроса и нажимает «Подписать бюллетень».

![Бюллетень подписан](/assets/new/ku/member/meeting-ballot/02-voted.png)

После подписи у вопросов видны итоги голосования. Это число голосов «За», «Против» и «Воздержались». Число поданных бюллетеней выросло на один. Повторный бюллетень не принимается.
