# Участие в собрании

Пайщик присоединяется к объявленному собранию по заявлению. Заявление подписывается одной кнопкой на странице собрания. Участвовать можно, пока собрание собирает участников.

![Собрание глазами пайщика](/assets/new/ku/member/meeting-join/01-meeting.png)

Страница собрания показывает место, время, председателя собрания, участников и повестку. Кнопка «Участвовать» в шапке подписывает заявление на участие.

![Пайщик в списке участников](/assets/new/ku/member/meeting-join/02-joined.png)

После подписи пайщик появляется в списке участников. Голосовать он сможет после того, как председатель собрания откроет голосование. К открытому голосованию присоединиться уже нельзя.
