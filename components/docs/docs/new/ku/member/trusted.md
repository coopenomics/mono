# Заявка в доверенные лица

Доверенное лицо участка принимает имущество кооператива и отвечает за него. Пайщик участка подаёт заявку сам, председатель участка одобряет её встречной подписью. У участка не больше трёх доверенных лиц.

![Карточка участка](/assets/new/ku/member/trusted/01-branch.png)

Пайщик открывает карточку участка в разделе «Кооперативные участки». Кнопка «Стать доверенным лицом» стоит в блоке доверенных лиц.

![Документы заявки](/assets/new/ku/member/trusted/03-preview.png)

Заявка состоит из двух документов. Это договор о полной материальной ответственности и доверенность. Данные пайщика и председателя участка подставлены. Для договора нужны паспортные данные, без них стол запросит их отдельным окном и сохранит в профиле. Кнопка «Подписать и подать заявку» подписывает оба документа.

![Заявка подана](/assets/new/ku/member/trusted/04-submitted.png)

Заявка появилась в блоке «Заявки на доверенных» в состоянии «На рассмотрении». Договор и доверенность открываются по ссылкам в строке. Решение принимает председатель участка.
