# Открытие голосования

Голосование открывает организатор собрания. Для собрания об учреждении участка он называет будущий участок и его председателя. Голосование длится 15 минут, участники получают уведомление.

![Открытие голосования](/assets/new/ku/member/meeting-vote/01-start-dialog.png)

Окно просит наименование, адрес, почту и телефон будущего участка. Председателя участка организатор выбирает из участников собрания, это физическое лицо. Кнопка «Добавить вопрос в повестку» дополняет повестку вопросами, внесёнными прямо на собрании. Кнопка «Открыть» запускает голосование.

![Бюллетень организатора](/assets/new/ku/member/meeting-vote/02-ballot.png)

Наименование и адрес участка встали в вопросы повестки. У каждого вопроса стоит выбор «За», «Против» или «Воздержался». Кнопка «Подписать бюллетень» подписывает ответы по всем вопросам разом. Организатор голосует как обычный участник.
