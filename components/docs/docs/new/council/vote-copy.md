
# Копирование голосов

## Что это

Сервис копирования голосов позволяет членам совета кооператива автоматизировать процесс голосования. Член совета может указать, чей голос он хочет автоматически копировать. Когда указанный член совета голосует — система автоматически повторяет его голос от имени копирующего.

!!! tip "Когда это полезно"
    - Член совета временно отсутствует, но доверяет решениям конкретного коллеги
    - Технический состав совета, где один эксперт принимает решения по определённому типу вопросов
    - Ускорение принятия решений при большом количестве вопросов

## Как настроить

### 1. Перейти на страницу копирования

В меню **Стол совета** → **Копирование голосов**.

### 2. Добавить настройку

Нажмите «Добавить» и укажите username члена совета, чей голос вы хотите копировать.

### 3. Управление настройками

На странице отображаются:

- **Я копирую голоса** — список членов совета, чьи голоса вы копируете
- **Мои голоса копируют** — кто из членов совета копирует ваши голоса

Для каждой настройки доступны действия:

| Действие | Описание |
|----------|----------|
| Приостановить | Временно отключить копирование (можно включить позже) |
| Удалить | Полностью удалить настройку копирования |

## Как работает

```
1. Член совета A настраивает: «копировать голос B»
2. На повестку выносится вопрос (decision_id = 42)
3. Член совета B голосует ЗА по вопросу 42
4. Система видит событие голосования B
5. Система автоматически голосует ЗА от имени A по вопросу 42
```

### Безопасность

- Копирование доступно **только членам совета** (role: `member` или `chairman`)
- Копировать можно **только голос другого члена совета**
- Нельзя копировать собственный голос
- Для подписи голоса используется специальное разрешение `copyvote`
- Ключи хранятся в зашифрованном хранилище (Vault)

### Ограничения

- При деактивации настройки — копирование прекращается мгновенно
- Если копируемый член совета исключён из совета — копирование автоматически прекращается
- При одновременном голосовании нескольких членов совета — копирование происходит для каждого события отдельно

## Для разработчиков

### GraphQL API

**Queries:**

```graphql
# Мои настройки копирования
query {
  getMyVoteCopySettings {
    id
    source_username
    decision_types
    is_active
    copyvote_public_key
    created_at
  }
}

# Кто копирует мои голоса
query {
  getWhoCopiesToMe {
    id
    copier_username
    is_active
  }
}

# Все настройки (только chairman)
query {
  getAllVoteCopySettings {
    id
    copier_username
    source_username
    is_active
  }
}
```

**Mutations:**

```graphql
# Создать настройку копирования
mutation {
  createVoteCopy(data: {
    source_username: "board_member_2"
    decision_types: []  # пусто = все типы
  }) {
    id
    is_active
  }
}

# Приостановить копирование
mutation {
  deactivateVoteCopy(id: "setting-uuid") {
    is_active
  }
}

# Удалить настройку
mutation {
  deleteVoteCopy(id: "setting-uuid")
}
```

### Обработка событий

Система автоматически слушает события блокчейна:

- `action::soviet::votefor` — голос ЗА
- `action::soviet::voteagainst` — голос ПРОТИВ

При обнаружении голоса — находит всех активных копирующих и автоматически повторяет голос.
