# Реестр расходов

Реестр расходов на столе совета показывает служебные записки на расход по всему кооперативу. Записку подаёт член совета, совет решает по ней в повестке, кассир выплачивает по строкам. Путь записки целиком описан в приложении [«Расходы»](../expenses/index.md).

![Реестр расходов](/assets/new/council/expenses/01-registry.png)

Строка записки показывает назначение и под ним кошелёк-источник, пайщика-автора с учётным именем, дату, сумму по плану и сумму по факту. На кадре записка на бумагу и картриджи для офиса из пула расходов программы «Благорост».

![Служебная записка](/assets/new/council/expenses/02-expense.png)

Нажатие на строку открывает записку. Сверху состояние, на кадре «Подан». Сводка повторяет автора, кооператив, кошелёк, суммы, даты и хэш записки. Блок «Документы» показывает подписанную служебную записку. Ниже строки расходов с получателем, способом оплаты и суммой.
