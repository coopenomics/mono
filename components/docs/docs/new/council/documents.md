# Реестр документов

Реестр документов хранит все подписанные документы кооператива. Вторая вкладка раздела, «Шаблоны документов», показывает редакции, по которым платформа собирает документы, и их утверждение советом.

![Реестр документов](/assets/new/council/documents/01-registry.png)

Вкладка «Документы» перечисляет документы по дате: согласия пайщиков с условиями программ и положений, протоколы решений совета, заявления и служебные записки. У документа заголовок, дата и подписант. Значок справа скачивает пакет документов процесса целиком. Поиск в шапке ищет по тексту.

![Документ](/assets/new/council/documents/02-document.png)

Нажатие на документ открывает его текст в том виде, в каком его подписал пайщик. На кадре положение о целевой потребительской программе «Цифровой кошелёк» с грифом утверждения протоколом совета.

## Шаблоны документов

![Шаблоны документов](/assets/new/council/documents/03-templates.png)

Вкладка «Шаблоны документов» показывает все шаблоны, которыми пользуется кооператив: базовый набор и документы установленных приложений, по группам. У каждого шаблона две редакции. «Утверждена советом» называет редакцию, по которой кооператив работает, с номером протокола решения. «Выпущена оператором» называет последнюю редакцию оператора платформы. Когда они совпадают, состояние «Утверждён». Счётчик у вкладки считает шаблоны, которые ждут решения совета.

![Текст шаблона](/assets/new/council/documents/04-template-text.png)

Кнопка «Открыть текст» показывает редакцию бланком. На месте данных пайщика и протокола пустые места, остальной текст такой же, каким его увидит пайщик при подписи.

![Новая редакция](/assets/new/council/documents/05-new-edition.png)

У шаблона на кадре в колонке «Утверждена советом» стоит «ещё не утверждалась», состояние «Не утверждён». Пайщикам предъявляется только утверждённая редакция, поэтому председатель выносит редакцию на совет кнопкой «Вынести на совет». Так же выглядит шаблон, у которого оператор выпустил редакцию новее утверждённой.

![Вынесено на совет](/assets/new/council/documents/06-proposed.png)

После выноса состояние «В повестке», действие «На рассмотрении», ссылка «К повестке» ведёт к вопросу. Совет голосует, председатель утверждает решение, и утверждённая редакция меняется на новую. С этого момента пайщики подписывают документы по ней. До решения кооператив работает по прежней редакции.
