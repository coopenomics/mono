# Реестр кооперативов

Реестр кооперативов показывает кооперативы, которые подключились к платформе через этот кооператив. Раздел виден кооперативу, который ведёт такие подключения.

![Реестр кооперативов](/assets/new/council/cooperatives/01-registry.png)

Строка кооператива показывает учётное имя, сайт, состояние подключения и дату заявки. Меню «действия» управляет подключением. Кнопка со знаком плюс слева добавляет кооператив в реестр.

## Индивидуальные цены

Вкладка «Индивидуальные цены» на карточке кооператива показывает услуги, за которые кооператив платит не по прейскуранту. В строке стоят услуга, цена по прейскуранту и цена кооператива. Цена указана за месяц. Ноль означает, что услуга для кооператива бесплатна.

Кнопка «Назначить цену» открывает панель справа. Председатель выбирает услугу из списка услуг кооператива, вводит цену в месяц и основание. После сохранения витрина подключения и каталог приложений кооператива показывают новую цену. Новая подписка кооператива на эту услугу создаётся по этой цене. Действующая подписка переходит на новую цену сразу, следующее списание идёт по ней.

Строка открывает панель с составом записи. Кнопка «Изменить» меняет цену. Кнопка «Снять» возвращает кооператив на цену тарифа или прейскуранта.

Индивидуальная цена привязана к кооперативу и услуге, а не к тарифу. При смене тарифа объём документооборота идёт по новому тарифу, а цена услуги с индивидуальной ценой остаётся прежней. На вкладке «Подписки» такая строка тарифа показывает цену кооператива, цена по прейскуранту стоит рядом зачёркнутой.
