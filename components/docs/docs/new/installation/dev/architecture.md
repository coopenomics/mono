
## Архитектура платформы

### Как это работает

Платформа «Цифровой Кооператив» — это распределённая система, состоящая из трёх слоёв:

```
┌──────────────────────────────────────────────┐
│             Десктоп (Vue + Quasar)           │  ← Пользователь взаимодействует здесь
├──────────────────────────────────────────────┤
│             Контроллер (NestJS)              │  ← Бизнес-логика, авторизация, документы
├──────────────────────────────────────────────┤
│             Блокчейн (EOSIO)                 │  ← Финансы, голосования, смарт-контракты
└──────────────────────────────────────────────┘
```

**Десктоп** — SPA-приложение на Vue 3 + Quasar. Через него пайщики, члены совета и председатель управляют кооперативом. Десктоп общается с контроллером через GraphQL API.

**Контроллер** — сервер на NestJS. Обрабатывает запросы, генерирует документы, управляет авторизацией, хранит карточки товаров и настройки в PostgreSQL. Для операций с финансами и голосованиями — отправляет транзакции в блокчейн.

**Блокчейн** — EOSIO-нода. Хранит неизменяемые данные: балансы кошельков, решения совета, статусы поставок. Гарантирует, что средства не могут быть потеряны при сбое сервера.

### Принцип разделения ответственности

| Что | Где хранится | Почему |
|-----|-------------|--------|
| Карточки товаров | PostgreSQL (контроллер) | Часто редактируются, проходят модерацию |
| Настройки маркетплейса | PostgreSQL (контроллер) | Управляются председателем |
| Заявки на поставку | Блокчейн | Блокировка средств — дело смарт-контракта |
| Решения совета | Блокчейн | Неизменяемость, юридическая значимость |
| Документы (PDF) | Генерируются контроллером | Подписываются ключами пользователей |
| Балансы кошельков | Блокчейн | Финансовая безопасность |

### Поток данных

```
Пользователь → Десктоп → GraphQL API → Контроллер → Блокчейн
                                            ↓
                                        PostgreSQL
                                        MongoDB
```

1. Пользователь нажимает кнопку в десктопе
2. Десктоп формирует GraphQL-запрос
3. Контроллер проверяет JWT-токен, роль, права
4. Контроллер выполняет бизнес-логику (генерация документа, валидация)
5. Если нужна финансовая операция — контроллер отправляет транзакцию в блокчейн
6. Парсер (отдельный сервис) слушает блокчейн и синхронизирует состояние в БД

### Расширения

Функциональность платформы расширяется через **расширения** (extensions):

| Расширение | Тип | Что делает |
|------------|-----|------------|
| `cooplace` | Бэкенд | Маркетплейс: карточки, поставки, кошельки |
| `marketplace` | Фронтенд | Витрина товаров |
| `capital` | Бэкенд + Фронтенд | Благорост: интеллектуальные вклады |
| `reports` | Бэкенд + Фронтенд | Генерация отчётов ФНС |
| `chairman` | Фронтенд | Стол председателя |
| `participant` | Фронтенд | Стол пайщика |

Расширение на бэкенде — это NestJS-модуль с GraphQL-резолверами. Расширение на фронтенде — Vue-компоненты с маршрутами. Расширения устанавливаются через магазин приложений.

### Смарт-контракты

Блокчейн содержит набор смарт-контрактов:

| Контракт | Назначение |
|----------|-----------|
| `registrator` | Регистрация кооперативов и аккаунтов |
| `soviet` | Голосования совета, решения |
| `marketplace` | Обмен имуществом, поставки |
| `capital` | Целевые программы, вклады |
| `gateway` | Платёжный шлюз |
| `fund` | Фонды кооператива |
| `wallet` | Цифровые кошельки |
| `ledger` | Бухгалтерский учёт |

### Авторизация

Три роли: `chairman` (полный доступ), `member` (совет), `user` (пайщик). Авторизация — через цифровую подпись EOSIO-ключом. JWT-токены для сессий.

### Документооборот

Все юридически значимые действия сопровождаются документами: заявления, решения, акты. Документы генерируются контроллером (PDF через WeasyPrint), подписываются ключами участников, хранятся в блокчейне по хешу.
