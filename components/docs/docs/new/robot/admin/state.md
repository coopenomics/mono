# Состояние робота

Страница «Состояние робота» открыта председателю. Она показывает, что члены совета доверили роботу, и застрявшие решения.

![Состояние робота](/assets/new/robot/admin/state/01-state.png)

Таблица «Что члены совета доверили роботу» идёт по членам совета. Для каждого видно режим голоса с перечнем типов решений, подпись протоколов у председателя, состояние ключа и дата его передачи. Состояние «Робот голосует» означает, что ключ передан и робот подаёт голоса. Ключ роботу передаёт сам член совета на странице «Действия автоматизации». Ниже таблица застрявших решений с кнопкой повтора. Пустая таблица означает, что робот справляется сам.
