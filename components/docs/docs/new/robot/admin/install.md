# Установка приложения

Робот совета — приложение цифрового кооператива. Председатель устанавливает его из каталога приложений.

![Страница приложения в каталоге](/assets/new/robot/admin/install/01-install-form.png)

На странице приложения четыре настройки. Число попыток на одно решение задаёт, сколько раз робот повторяет застрявшее решение до ручного повтора. Пауза между попытками растёт с номером попытки. Две настройки ниже задают число сборок протокола и паузу между ними. Голоса робота попадают в историю действий с небольшой задержкой, и протокол собирается повторно в том же проходе. Значений по умолчанию хватает обычному кооперативу.
