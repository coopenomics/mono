# Робот совета

Робот совета принимает типовые решения совета за секунды по правилам,
которые члены совета задали заранее. Член совета доверяет роботу свой
голос по выбранным типам решений, председатель доверяет подпись протокола.
Каждый голос и каждый протокол остаются подписью конкретного члена совета.
Их ставит ключ отдельного разрешения его аккаунта. Разрешение выпущено
только для робота.

Робот нужен там, где решение совета стоит на пути пайщика. Это приём в
кооператив, выдача имущества со Стола заказов, гарантийный возврат,
списание, выход пайщика. Без робота пайщик ждёт голосов людей, с роботом
решение исполняется сразу после подачи заявления.

Стол «Робот совета» видят члены совета. Председатель дополнительно видит
состояние робота. Устройство делегирования, кворума и журнала описано в
разделе [Платформа → Робот совета](/platform/council/robot/).
