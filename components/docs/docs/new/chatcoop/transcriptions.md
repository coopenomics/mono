# Транскрипции звонков

Транскрипции хранят распознанную речь из звонков в комнатах кооператива.

![Транскрипции звонков](/assets/new/chatcoop/transcriptions/01-page.png)

Строка звонка показывает название, начало, длительность, число участников и состояние. На кадре завершённое заседание совета на двадцать пять минут с тремя участниками. Пайщик видит звонки тех комнат, в которых он состоит.

![Транскрипция звонка](/assets/new/chatcoop/transcriptions/02-row.png)

Нажатие на строку открывает транскрипцию. Сверху начало, окончание, длительность и участники. Поле «Заметка о звонке» принимает итоги: первая строка — одно предложение-резюме, кнопка «Сохранить» записывает заметку. Ниже текст звонка репликами: участник, время и сказанное.
