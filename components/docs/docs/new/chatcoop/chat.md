# Быстрый клиент

Быстрый клиент открывает переписку мессенджера прямо в рабочем столе.

![Быстрый клиент](/assets/new/chatcoop/chat/01-page.png)

При первом входе пайщик заводит учётную запись мессенджера: почта подставлена из профиля, пайщик задаёт имя пользователя и пароль. Кнопка «Продолжить» создаёт запись, после этого открываются комнаты кооператива и переписка. Той же учётной записью пайщик входит в мобильный клиент.
