# Комнаты секретаря

Комнаты секретаря — комнаты для звонков, в которых секретарь подключается сразу и ведёт транскрипцию.

![Комнаты секретаря](/assets/new/chatcoop/secretary-rooms/01-page.png)

Строка комнаты показывает название, тип и секретаря. Комнаты совета и пайщиков заводит кооператив, они показаны для справки. Кнопка «Создать комнату» заводит комнату секретаря, кнопка «Удалить» в строке убирает её. Запись звонка из такой комнаты попадает в [транскрипции](transcriptions.md).
