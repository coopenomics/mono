# Календарь событий

Календарь событий ведёт заседания совета, общие собрания и встречи кооператива по комнатам мессенджера.

![Календарь событий](/assets/new/chatcoop/calendar/01-page.png)

Строка события показывает название, комнату, начало и окончание в местном времени устройства. На кадре заседание совета в комнате совета и общее собрание пайщиков в комнате пайщиков. Кнопка «Новое событие» заводит событие: комната, название, описание, время. Значки в строке открывают комнату, правят событие и удаляют его.

![Событие календаря](/assets/new/chatcoop/calendar/02-row.png)

Кнопка «Установить» выдаёт персональную ссылку подписки на календарь. Ссылка добавляется в календарь телефона или компьютера, события кооператива появляются там сами. Кнопка «Обновить» перечитывает события.
