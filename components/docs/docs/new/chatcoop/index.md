# Стол связи

Стол связи — кооперативный мессенджер: групповые чаты, личные сообщения, голосовые и видеозвонки на зашифрованном протоколе с открытым кодом. Каждый пайщик получает доступ к чату пайщиков своего кооператива и общему чату кооперативной экономики, каждый член совета добавляется в закрытый чат совета.

Мессенджер работает в рабочем столе и на телефоне. [Быстрый клиент](chat.md) открывает переписку прямо на столе, [мобильный клиент](mobile.md) подключает приложение на телефоне. [Календарь событий](calendar.md) ведёт заседания и собрания по комнатам. [Транскрипции звонков](transcriptions.md) хранят распознанную речь из звонков, [комнаты секретаря](secretary-rooms.md) заводят комнаты, в которых секретарь ведёт запись. Стол ставит председатель из [каталога приложений](install.md).
