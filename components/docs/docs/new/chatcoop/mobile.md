# Мобильный клиент

Мобильный клиент — приложение мессенджера для телефона, Element X.

![Мобильный клиент](/assets/new/chatcoop/mobile/01-page.png)

Для подключения нужна учётная запись мессенджера. Пока её нет, страница предлагает перейти к регистрации в [быстром клиенте](chat.md). После регистрации страница даёт инструкцию для мобильного приложения и данные для входа.
