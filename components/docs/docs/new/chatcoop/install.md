# Установка

Стол связи ставится из каталога приложений на столе председателя.

![Стол связи в каталоге](/assets/new/chatcoop/install/01-extension.png)

Страница приложения перечисляет возможности и один рабочий стол, «Стол связи». После установки переключатель «включено» открывает стол пайщикам, кооператив заводит комнаты совета и пайщиков. Кнопка «Настройки» задаёт интервал, с которым история переписки из открытых комнат подтягивается в кооператив.
