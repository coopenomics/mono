# Касса

Касса ведёт служебные записки после решения совета: выплаты по строкам, ожидание отчётов и закрытие. Платежи кассир подтверждает в реестре платежей стола совета, касса показывает, где записка сейчас.

![К оплате](/assets/new/expenses/cashier/01-to-pay.png)

Вкладка «К оплате» показывает записки, которые совет утвердил. Строка показывает автора, дату, план, факт и хэш записки, ссылка «Открыть» ведёт к записке. Счётчики у вкладок считают записки на каждой стадии.

![Платежи по записке](/assets/new/expenses/cashier/02-payments.png)

После решения совета по каждой строке записки в реестре платежей появляется исходящий платёж в состоянии «Ожидает обработки». На кадре два платежа: шесть тысяч рублей организации и полторы тысячи пайщику. Тип платежа у обоих «Оплата расхода по служебной записке».

![Платёж организации](/assets/new/expenses/cashier/03-org-payment.png)

Нажатие на строку раскрывает платёж организации: реквизиты получателя, что оплачивается, назначение платежа и сумма к переводу. Кассир переводит деньги по этим реквизитам из банка кооператива и нажимает «Подтвердить».

![Счёт оплачен](/assets/new/expenses/cashier/04-org-proof.png)

После подтверждения состояние «Завершён». В раскрытой строке открывается шаг «Подтвердите оплату»: кассир прикладывает чек об оплате изображением или PDF, файл уходит сразу. По оплате счёта организации кассир сам прикладывает закрывающие документы: акт, накладную или счёт-фактуру. Отчёт по такой строке сдаёт кассир.

![Платёж аванса](/assets/new/expenses/cashier/05-advance-payment.png)

Аванс под отчёт кассир подтверждает так же. В раскрытой строке телефон пайщика для перевода по системе быстрых платежей, назначение «Аванс под отчёт» и сумма.

![Ждут отчёта](/assets/new/expenses/cashier/06-awaiting-report.png)

После выплаты аванса записка переходит на вкладку «Ждут отчёта». Пайщик отчитывается чеками сам на своём столе, либо кассир отчитывается за него, получив чеки лично.

![Отчёт за пайщика](/assets/new/expenses/cashier/07-report.png)

В раскрытой строке аванса после оплаты открыт шаг «Отчёт пайщика». Кассир указывает фактически потраченную сумму и прикладывает чек. Сумма меньше аванса заводит платёж возврата разницы кооперативу, сумма больше аванса заводит платёж доплаты пайщику. Кнопка «Отчитаться за пайщика» подаёт отчёт от его имени.

![Отчёт подан](/assets/new/expenses/cashier/08-reported.png)

Отчёт подан, оба платежа по записке завершены. Значок у состояния показывает приложенный чек. Записка переходит на вкладку «На авторизации» и ждёт закрытия.

![Закрытые](/assets/new/expenses/cashier/09-closed.png)

Вкладка «Закрытые» показывает записки, по которым выплаты сделаны и отчёты приняты. Фактическая сумма расхода после закрытия учтена в кошельке-источнике.
