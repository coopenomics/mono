# Выплаты по записке

После решения совета кассир выплачивает строки записки в реестре платежей своего стола. Оплату счёта организации он подтверждает и прикладывает закрывающие документы, аванс выдаёт пайщику.

![Платежи по записке](/assets/new/expenses/cashier/02-payments.png)

По каждой строке записки в реестре платежей появляется исходящий платёж в состоянии «Ожидает обработки» с кнопкой «Подтвердить». На кадре два платежа: шесть тысяч рублей организации и полторы тысячи пайщику. Тип платежа у обоих «Оплата расхода по служебной записке».

![Платёж организации](/assets/new/expenses/cashier/03-org-payment.png)

Нажатие на строку раскрывает платёж организации: реквизиты получателя, что оплачивается, назначение платежа и сумма к переводу. Кассир переводит деньги по этим реквизитам из банка кооператива и нажимает «Подтвердить».

![Счёт оплачен](/assets/new/expenses/cashier/04-org-proof.png)

После подтверждения состояние «Завершён». В раскрытой строке открывается шаг «Подтвердите оплату»: кассир прикладывает чек об оплате изображением или PDF, файл загружается сразу и появляется в списке над загрузчиком. По оплате счёта организации кассир сам прикладывает закрывающие документы: акт, накладную или счёт-фактуру. Отчёт по такой строке сдаёт кассир.

![Платёж аванса](/assets/new/expenses/cashier/05-advance-payment.png)

Аванс под отчёт кассир подтверждает так же. В раскрытой строке телефон пайщика для перевода по системе быстрых платежей, назначение «Аванс под отчёт» и сумма.

![Отчёт за пайщика](/assets/new/expenses/cashier/07-report.png)

После выдачи аванса в раскрытой строке открыт шаг «Отчёт пайщика». Если пайщик принёс чеки лично, кассир указывает фактически потраченную сумму и прикладывает чек, отчёт подаётся от имени пайщика. Сумма заполнена выданным авансом. Сумма меньше аванса заводит платёж возврата разницы кооперативу, сумма больше аванса заводит платёж доплаты пайщику. Обычно пайщик [отчитывается сам](advances.md) на своём столе.
