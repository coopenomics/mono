# Реестр расходов

Реестр расходов на столе совета показывает все служебные записки кооператива. Член совета и председатель видят здесь, на какой стадии каждая записка.

![Реестр расходов](/assets/new/expenses/registry/01-registry.png)

Строка записки показывает назначение и под ним кошелёк-источник, пайщика-автора с учётным именем, дату создания, сумму по плану и сумму по факту. На кадре записка члена совета на аренду зала к общему собранию из пула расходов программы «Благорост» на семь с половиной тысяч рублей.

![Служебная записка](/assets/new/expenses/registry/02-proposal.png)

Нажатие на строку открывает записку. Сверху состояние, на кадре «Подан»: записка ждёт решения совета. Сводка повторяет автора, кооператив, кошелёк, суммы по плану и по факту, даты и хэш записки. Блок «Документы» показывает подписанную служебную записку. Ниже строки расходов: у записки на кадре это оплата счёта организации за аренду зала и аванс под отчёт пайщику на воду и бумагу к собранию. Дальше по странице документы по строкам и история состояний.

Совет голосует по записке в [повестке совета](../council/agenda.md), председатель утверждает решение. После утверждения к документам записки добавляется протокол решения, по каждой строке заводится платёж в реестр платежей, и записка появляется на [столе кассира](../cashier/expenses.md) во вкладке «К оплате».
