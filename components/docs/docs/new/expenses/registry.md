# Реестр расходов

Реестр расходов показывает все служебные записки кооператива. Член совета и председатель видят здесь, на какой стадии каждая записка.

![Реестр расходов](/assets/new/expenses/registry/01-registry.png)

Строка записки показывает назначение, пайщика-автора с учётным именем, кошелёк-источник, дату создания, сумму по плану и сумму по факту. На кадре записка члена совета на аренду зала к общему собранию из пула расходов программы «Благорост» на семь с половиной тысяч рублей.

![Служебная записка](/assets/new/expenses/registry/02-proposal.png)

Нажатие на строку открывает записку. Сверху состояние, на кадре «Подан». Сводка повторяет автора, кооператив, кошелёк, суммы по плану и по факту, даты и хэш записки. Блок «Документы» показывает подписанную служебную записку. Ниже строки расходов: у записки на кадре это оплата счёта организации за аренду зала и аванс под отчёт пайщику на воду и бумагу к собранию. Дальше по странице документы по строкам и история состояний.

![На одобрение председателя](/assets/new/expenses/registry/03-approve-queue.png)

Страница «На одобрение председателя» показывает записки в состоянии «Подан»: они ждут решения совета. Строка показывает автора, дату, сумму по плану и хэш, ссылка «Открыть» ведёт к записке. Совет голосует по записке в [повестке совета](../council/agenda.md), председатель утверждает решение. После утверждения по каждой строке записки заводится платёж в реестр платежей, и записка появляется в кассе.
