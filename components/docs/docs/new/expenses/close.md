# Закрытие расхода

Расход закрывает кассир или председатель на странице служебной записки. Закрытие возможно, когда отчёты по всем строкам поданы.

![Отчёт подан](/assets/new/expenses/close/01-report-submitted.png)

Состояние записки «Отчёт подан», сумма по факту равна выплаченному. В шапке страницы кнопка «Закрыть расход». У члена совета без роли кассира этой кнопки нет: он читает записку.

![Расход закрыт](/assets/new/expenses/close/02-closed.png)

После нажатия состояние «Закрыт». Фактическая сумма расхода учтена в кошельке-источнике, записка на столе кассира переходит во вкладку «Закрытые». В документах записки лежат подписанная записка и протокол решения совета.
