# Отчёт по авансу

Пайщик отчитывается по авансу на странице «Платежи» своего стола. Отчёт — потраченная сумма и чек.

![Аванс в платежах пайщика](/assets/new/expenses/advances/03-my-payments.png)

Аванс виден исходящим платежом кооператива с типом «Оплата расхода по служебной записке» и состоянием «Завершён» после выплаты.

![Форма отчёта](/assets/new/expenses/advances/04-report-form.png)

Нажатие на строку раскрывает аванс. Видны телефон, на который пришли деньги, что оплачивается, назначение и сумма. Ниже выданный аванс, поле «Фактически потрачено по чекам» с суммой аванса и загрузчик чека. Пайщик правит сумму, если потратил иначе, прикладывает чек и нажимает «Отчитаться по авансу». Сумма меньше аванса заводит платёж возврата разницы кооперативу, пайщик оплачивает его по реквизитам кооператива. Сумма больше аванса заводит платёж доплаты, кооператив выплачивает разницу.

![Отчёт принят](/assets/new/expenses/advances/05-reported.png)

После отчёта у платежа вторая отметка, «Отчёт принят». Строка записки отчитана, на столе кассира аванс переходит во вкладку «Отчёт принят». Когда отчитаны все строки, записку [закрывают](close.md).
