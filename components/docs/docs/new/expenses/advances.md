# Мои авансы

Страница «Мои авансы» на столе пайщика показывает служебные записки, по которым пайщик получил аванс под отчёт. Пайщик отчитывается по авансу чеками на странице своих платежей.

![Мои авансы](/assets/new/expenses/advances/01-my-advances.png)

Строка записки показывает сумму аванса и состояние. У пайщика без авансов страница пуста.

![Платёж аванса](/assets/new/expenses/advances/03-my-payments.png)

В платежах пайщика аванс виден исходящим платежом с типом «Оплата расхода по служебной записке» и состоянием «Завершён» после выплаты. Нажатие на строку раскрывает платёж, в нём пайщик указывает фактически потраченную сумму, прикладывает чек и подаёт отчёт. Сумма меньше аванса заводит платёж возврата разницы кооперативу, пайщик оплачивает его по реквизитам кооператива. Сумма больше аванса заводит платёж доплаты, кооператив выплачивает разницу.
