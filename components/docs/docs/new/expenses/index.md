# Расходы

Приложение «Расходы» ведёт служебные записки на расход денег кооператива. Записка проходит путь от подачи до закрытия: член совета подаёт её, совет принимает решение в повестке, кассир выплачивает строки записки, получатель аванса отчитывается чеками, после отчёта записка закрывается.

Служебная записка называет кошелёк, из которого идут деньги, и строки расходов. Строка бывает двух видов. Оплата по счёту организации идёт получателю по реквизитам, закрывающие документы прикладывает кассир. Аванс под отчёт идёт пайщику на его способ получения, пайщик отвечает за него отчётом с чеками. Записку подаёт член совета из приложения, которому нужен расход: Благорост, Образование и другие приложения дают кнопку подачи на своих страницах экономики.

Страницы приложения живут на столах совета и председателя. [Реестр расходов](registry.md) показывает все записки кооператива и очередь на одобрение. [Касса](cashier.md) ведёт выплаты, ожидание отчётов и закрытие. [Мои авансы](advances.md) показывает пайщику записки, по которым он получил аванс.
