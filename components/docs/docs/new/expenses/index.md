# Расходы

Расход денег кооператива идёт по служебной записке. Член совета подаёт записку, совет принимает решение в повестке, кассир выплачивает строки записки, получатель аванса отчитывается чеками, кассир или председатель закрывает расход. Каждый шаг оставляет документ: подписанную записку, протокол решения, платежи с чеками.

Служебная записка называет кошелёк, из которого идут деньги, и строки расходов. Строка бывает двух видов. Оплата по счёту организации идёт получателю по реквизитам, закрывающие документы прикладывает кассир. Аванс под отчёт идёт пайщику на его способ получения, пайщик отвечает за него отчётом с чеками. Записку подаёт член совета из приложения, которому нужен расход: Благорост, Образование и другие приложения дают кнопку подачи на своих страницах экономики.

Путь записки проходит по трём столам. [Реестр расходов](registry.md) на столе совета показывает записку с подачи и до закрытия. [Выплаты](cashier.md) кассир проводит в реестре платежей своего стола. [Отчёт по авансу](advances.md) пайщик сдаёт на странице «Платежи» своего стола. [Закрытие расхода](close.md) делает кассир или председатель на странице записки. Страницы стола кассира описаны в разделе [«Стол кассира»](../cashier/index.md).
