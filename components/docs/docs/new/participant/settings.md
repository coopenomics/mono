# Настройки

Настройки ведут вход пайщика: пароль, подтверждение входа и сессии на устройствах.

![Настройки пайщика](/assets/new/participant/settings/01-page.png)

Блок «Пароль для входа» показывает, настроен ли вход по паролю вместо ключа, кнопка «Сменить пароль» меняет его. Блок «Подтверждение входа» добавляет второй шаг: код из приложения-аутентификатора, кнопка «Подключить» привязывает приложение, либо одноразовый код на почту, его включает переключатель. Блок «Активные сессии и устройства» перечисляет, где выполнен вход, с браузером, адресом и временем активности. Незнакомую сессию кнопка «Завершить» закрывает.
