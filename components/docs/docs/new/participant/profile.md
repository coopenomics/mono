# Удостоверение

Удостоверение показывает пайщика таким, каким его видит кооператив и платформа: кто он, чьими подписями подтверждён и какие данные о нём хранятся. Изменить данные удостоверения можно через кооператив, контакты на странице [«Контакты»](contacts.md).

![Удостоверение пайщика](/assets/new/participant/profile/01-page.png)

Карточка удостоверения показывает ФИО, роль в кооперативе и цепочку подписей: якорь доверия сети подтверждает оператора платформы, оператор подтверждает кооператив, кооператив подтверждает пайщика. Звенья названы публичными названиями, как их записал заверивший: «АНО Кооперативная Экономика → ПК «Восход» → ПК «Партнёр-1» → Вы». Уровень верификации «Начальный» означает, что личность подтверждена платежом с банковского счёта пайщика. Код справа предъявляется при личной сверке и на встречах, кнопка «Показать» открывает его крупно. Блок «Учётная запись» показывает имя аккаунта и публичный ключ, которым пайщик подписывает документы. Блок «Личные данные» показывает почту с отметкой подтверждения, телефон, дату рождения и адрес. Ниже документы и реквизиты пайщика.
