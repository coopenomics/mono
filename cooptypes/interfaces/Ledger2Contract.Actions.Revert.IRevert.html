    mirror_wallet_op

    mirror_wallet_op: number

    0=ISSUE, 1=TRANSFER, 4=BURN. 2=BLOCK / 3=UNBLOCK не разрешены — они симметричны сами себе. Для зеркала ISSUE используется BURN; различие «штатное сжигание» vs «mirror revert» фиксируется через operation_code (o.adj.rev). Для зеркала без бухпроводок mirror_debit_account_id и mirror_credit_account_id оба == 0.
